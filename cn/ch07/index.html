    引言¶

    微分（differentiation）是微积分的两大核心运算之一。它的任务是量化变化——具体来说，是量化函数在任意一点上的瞬时变化率。

    想象你正开车行驶在一条蜿蜒的公路上。速度表上显示的数值就是瞬时速度——它告诉你在这一刹那车子变化得有多快。微分所做的，正是为任何函数计算出这种"瞬时速度"。在几何上，导数给出的是曲线在某一点的切线斜率，也就是曲线在该点"有多陡"。

    为什么要学微分？因为自然界中几乎一切都在变化：物体的运动、人口的增减、温度的升降、利润的涨落。微分给了我们一把精确描述这些变化的数学工具。掌握了微分，后续的积分（求累积量）、最优化（求最佳方案）、运动学分析等问题都将迎刃而解。

    本章将从导数的基本概念出发，依次学习积法则与商法则、基本求导公式、链式法则，然后将这些工具应用于切线与法线、极值判断、相关变化率以及实际最值问题。每个知识点配有丰富的例题和练习题，帮助你完全掌握。

    7.1 导数概念与记号¶

    7.1.1 从平均变化率到瞬时变化率¶

    变化率是一个我们非常熟悉的概念。例如，一辆汽车在 2 小时内行驶了 120 公里，那么它的平均速度就是：

    \[ \text{平均速度} = \frac{120}{2} = 60 \text{ km/h} \]

    但这个平均速度掩盖了细节——汽车可能在有些时刻开得快，有些时刻开得慢。如果我们想知道在某个精确时刻的速度，就需要瞬时变化率。（虽然这些可能有点难记，但是计算的（大多）时候就是：变化率的变化率）

    设函数 \(y = f(x)\)。考虑从 \(x\) 到 \(x + \delta x\) 的一个小区间（其中 \(\delta x\) 读作 "delta x"，表示 \(x\) 的一个微小变化量）。在这个区间上，函数的平均变化率为：

    \[ \frac{\text{函数值的变化量}}{\text{自变量的变化量}} = \frac{f(x + \delta x) - f(x)}{\delta x} \]
    \[ \lim_{x_2 \to 0} \frac{f(x_1 - x_2) - f(x_1)}{f(x_2)} = \frac{f(\Delta x)}{x_{\text{original}}} \]

    当 \(\delta x\) OR \(x_2\) 趋近于 \(0\) 时，这个平均变化率就会趋近于一个极限值——这就是函数在点 \(x\) 处的导数：

    \[ \boxed{f'(x) = \lim_{\delta x \to 0} \frac{f(x + \delta x) - f(x)}{\delta x}} \]
    \[ \lim_{x_2 \to 0} \frac{f(\Delta x) - f(x_1)}{f(x_2)} = \frac{f(\Delta x)}{x_{\text{original}}} \]

    这里 \(\lim_{\delta x \to 0}\) OR \(\lim_{x_2 \to 0}\) 表示"当 \(\delta x\) OR \(x_2\) 无限趋近于 0 时"。这个极限的存在性（即导数是否存在）取决于函数在该点是否"光滑"。

    7.1.2 导数的几何意义¶

    从几何角度看，导数 \(f'(a)\) 就是曲线 \(y = f(x)\) 在点 \((a, f(a))\) 处切线的斜率。

    • 如果 \(f'(a) > 0\)，曲线在该点上升（切线向右上方倾斜）。
    • 如果 \(f'(a) < 0\)，曲线在该点下降（切线向右下方倾斜）。
    • 如果 \(f'(a) = 0\)，曲线在该点水平（可能是极大值、极小值或鞍点）。

    7.1.3 记号¶

    导数的记号有多种，考试中常见的有：

    记号 名称 示例
    \(f'(x)\) 拉格朗日记法 \(f'(x) = 2x\)
    \(\frac{dy}{dx}\) 莱布尼茨记法 \(\frac{dy}{dx} = 2x\)
    \(\frac{d}{dx}f(x)\) 算子记法 \(\frac{d}{dx}(x^2) = 2x\)
    \(f''(x)\), \(\frac{d^2y}{dx^2}\) 二阶导数 导数的导数

    ⚠️ 重要理解：记号 \(\frac{dy}{dx}\) 并不是一个分数，而是一个整体符号——它表示"对 \(x\) 求导"这个运算的结果。但在微小增量近似中，我们可以把它当作一个"比值"来使用（\(\delta y \approx \frac{dy}{dx} \cdot \delta x\)），这在线性近似中非常有效。

    7.1.4 极限的直观理解¶

    在求导过程中，我们经常碰到 \(\frac{0}{0}\) 型的不定式。处理方法通常是因式分解后约分再代入。

    示例：求 \(\lim_{x \to 2} \frac{x^2 - 4}{x - 2}\)。

    当 \(x = 2\) 时，分子分母都是 \(0\)，但我们可以这样做：

    \[ \lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} \frac{(x-2)(x+2)}{x-2} = \lim_{x \to 2} (x+2) = 4 \]

    注意：\(x\) 趋近于 \(2\)，但从不等于 \(2\)，所以约分 \(x-2\) 是合法的。

    例题 5.1A（导数概念的直观理解）¶

    已知 \(f(x) = x^2\)，用极限定义求 \(f'(2)\)。

    解：

    \[ f'(2) = \lim_{\delta x \to 0} \frac{f(2 + \delta x) - f(2)}{\delta x} = \lim_{\delta x \to 0} \frac{(2 + \delta x)^2 - 4}{\delta x} \]

    展开 \((2 + \delta x)^2 = 4 + 4\delta x + (\delta x)^2\)，代入：

    \[ f'(2) = \lim_{\delta x \to 0} \frac{4 + 4\delta x + (\delta x)^2 - 4}{\delta x} = \lim_{\delta x \to 0} \frac{4\delta x + (\delta x)^2}{\delta x} = \lim_{\delta x \to 0} (4 + \delta x) \]

    当 \(\delta x \to 0\) 时，\(4 + \delta x \to 4\)，所以 \(f'(2) = 4\)。

    几何意义：抛物线 \(y = x^2\) 在点 \((2, 4)\) 处的切线斜率为 \(4\)。

    例题 5.1B（平均变化率与瞬时变化率的对比）¶

    物体自由落体的位移函数为 \(s(t) = 5t^2\)（\(s\) 以米为单位，\(t\) 以秒为单位）。 (a) 求 \(t = 2\) 到 \(t = 2.1\) 之间的平均速度。 (b) 求 \(t = 2\) 时的瞬时速度。

    解：

    (a) 平均速度：

    \[ \text{平均速度} = \frac{s(2.1) - s(2)}{0.1} = \frac{5(4.41) - 5(4)}{0.1} = \frac{22.05 - 20}{0.1} = \frac{2.05}{0.1} = 20.5 \text{ m/s} \]

    (b) 瞬时速度。先求导数的一般形式：

    \[ s'(t) = \lim_{\delta t \to 0} \frac{5(t + \delta t)^2 - 5t^2}{\delta t} = \lim_{\delta t \to 0} \frac{5(t^2 + 2t\delta t + (\delta t)^2) - 5t^2}{\delta t} \]
    \[ = \lim_{\delta t \to 0} \frac{10t\delta t + 5(\delta t)^2}{\delta t} = \lim_{\delta t \to 0} (10t + 5\delta t) = 10t \]

    代入 \(t = 2\)：\(s'(2) = 10 \times 2 = 20\) m/s。

    注意：平均速度 20.5 m/s 非常接近瞬时速度 20 m/s——区间越小，两者越接近。

    例题 5.1C（导数值与切线斜率的关系）¶

    曲线 \(y = \frac{1}{x}\) 在点 \((2, \frac{1}{2})\) 处的切线斜率是多少？曲线在该点是上升还是下降？

    解：

    \[ f'(x) = \lim_{\delta x \to 0} \frac{\frac{1}{x + \delta x} - \frac{1}{x}}{\delta x} = \lim_{\delta x \to 0} \frac{\frac{x - (x + \delta x)}{x(x + \delta x)}}{\delta x} = \lim_{\delta x \to 0} \frac{-\delta x}{x(x + \delta x)\delta x} \]
    \[ = \lim_{\delta x \to 0} \frac{-1}{x(x + \delta x)} = -\frac{1}{x^2} \]

    代入 \(x = 2\)：\(f'(2) = -\frac{1}{4}\)。

    斜率为负，说明曲线在 \(x = 2\) 处下降（随着 \(x\) 增大，\(y\) 减小）。

    例题 5.1D（极限计算——约分法）¶

    求 \(\lim_{x \to 3} \frac{x^2 - 2x - 3}{x - 3}\)。

    解：

    当 \(x = 3\) 时，分子 \(3^2 - 2(3) - 3 = 9 - 6 - 3 = 0\)，分母也为 \(0\)。因式分解分子：

    \[ x^2 - 2x - 3 = (x - 3)(x + 1) \]

    所以：

    \[ \lim_{x \to 3} \frac{x^2 - 2x - 3}{x - 3} = \lim_{x \to 3} \frac{(x - 3)(x + 1)}{x - 3} = \lim_{x \to 3} (x + 1) = 4 \]

    7.2 积法则与商法则¶

    当两个函数相乘或相除时，它们的导数不能简单地对每个部分分别求导再相乘或相除。这时需要专门的法则。

    7.2.1 积法则（Product Rule）¶

    设 \(y = u \cdot v\)，其中 \(u\) 和 \(v\) 都是 \(x\) 的函数，则：

    \[ \boxed{\frac{dy}{dx} = u\frac{dv}{dx} + v\frac{du}{dx}} \]

    或简记为：\((uv)' = uv' + vu'\)

    记忆口诀："前导后不导 + 后导前不导"——第一个函数求导乘以第二个函数不动，加上第二个函数求导乘以第一个函数不动。

    积法则的详细推导：

    从导数的极限定义出发：

    \[ (uv)' = \lim_{\delta x \to 0} \frac{u(x+\delta x)v(x+\delta x) - u(x)v(x)}{\delta x} \]

    在分子中巧妙地加减 \(u(x+\delta x)v(x)\)：

    \[ = \lim_{\delta x \to 0} \frac{u(x+\delta x)v(x+\delta x) - u(x+\delta x)v(x) + u(x+\delta x)v(x) - u(x)v(x)}{\delta x} \]
    \[ = \lim_{\delta x \to 0} \left[ u(x+\delta x) \cdot \frac{v(x+\delta x) - v(x)}{\delta x} + v(x) \cdot \frac{u(x+\delta x) - u(x)}{\delta x} \right] \]

    当 \(\delta x \to 0\) 时，\(u(x+\delta x) \to u(x)\)，于是：

    \[ (uv)' = u(x) \cdot v'(x) + v(x) \cdot u'(x) = uv' + vu' \]

    7.2.2 商法则（Quotient Rule）¶

    设 \(y = \frac{u}{v}\)，其中 \(u\) 和 \(v\) 都是 \(x\) 的函数，且 \(v \neq 0\)，则：

    \[ \boxed{\frac{dy}{dx} = \frac{v\frac{du}{dx} - u\frac{dv}{dx}}{v^2}} \]

    或简记为：\(\left(\frac{u}{v}\right)' = \frac{vu' - uv'}{v^2}\)

    记忆口诀："上导下不导减下导上不导，除以分母的平方"。

    商法则的推导（从积法则导出）：

    将 \(\frac{u}{v}\) 写成 \(u \cdot v^{-1}\)，然后用积法则和链式法则：

    \[ \frac{d}{dx}\left(\frac{u}{v}\right) = \frac{d}{dx}(u \cdot v^{-1}) = u \cdot \frac{d}{dx}(v^{-1}) + v^{-1} \cdot \frac{du}{dx} \]
    \[ = u \cdot (-1)v^{-2} \cdot \frac{dv}{dx} + \frac{1}{v} \cdot \frac{du}{dx} = -\frac{u}{v^2}\frac{dv}{dx} + \frac{1}{v}\frac{du}{dx} \]

    通分：

    \[ = \frac{v\frac{du}{dx} - u\frac{dv}{dx}}{v^2} \]

    例题 5.2A（积法则基础）¶

    求下列函数的导数： (a) \(y = (x^2 + 1)(x^3 - 2x)\) (b) \(y = x\sin x\) © \(y = e^x \cos x\) (d) \(y = x^2\ln x\)

    解：

    (a) 设 \(u = x^2 + 1\)，\(v = x^3 - 2x\)。

    则 \(u' = 2x\)，\(v' = 3x^2 - 2\)。

    \[ y' = uv' + vu' = (x^2 + 1)(3x^2 - 2) + (x^3 - 2x)(2x) \]

    展开：

    \[ = 3x^4 - 2x^2 + 3x^2 - 2 + 2x^4 - 4x^2 = 5x^4 - 3x^2 - 2 \]

    （也可先展开原式再求导来验证）

    (b) 设 \(u = x\)，\(v = \sin x\)，则 \(u' = 1\)，\(v' = \cos x\)。

    \[ y' = x\cos x + \sin x \cdot 1 = x\cos x + \sin x \]

    © 设 \(u = e^x\)，\(v = \cos x\)，则 \(u' = e^x\)，\(v' = -\sin x\)。

    \[ y' = e^x \cdot (-\sin x) + \cos x \cdot e^x = e^x(\cos x - \sin x) \]

    (d) 设 \(u = x^2\)，\(v = \ln x\)，则 \(u' = 2x\)，\(v' = \frac{1}{x}\)。

    \[ y' = x^2 \cdot \frac{1}{x} + \ln x \cdot 2x = x + 2x\ln x \]

    例题 5.2B（商法则基础）¶

    求下列函数的导数： (a) \(y = \frac{x}{x+1}\) (b) \(y = \frac{x^2}{\sin x}\) © \(y = \frac{e^x}{x^2 + 1}\) (d) \(y = \frac{\ln x}{x}\)

    解：

    (a) 设 \(u = x\)，\(v = x+1\)，则 \(u' = 1\)，\(v' = 1\)。

    \[ y' = \frac{vu' - uv'}{v^2} = \frac{(x+1)(1) - x(1)}{(x+1)^2} = \frac{x+1-x}{(x+1)^2} = \frac{1}{(x+1)^2} \]

    (b) 设 \(u = x^2\)，\(v = \sin x\)，则 \(u' = 2x\)，\(v' = \cos x\)。

    \[ y' = \frac{(\sin x)(2x) - (x^2)(\cos x)}{\sin^2 x} = \frac{2x\sin x - x^2\cos x}{\sin^2 x} \]

    © 设 \(u = e^x\)，\(v = x^2 + 1\)，则 \(u' = e^x\)，\(v' = 2x\)。

    \[ y' = \frac{(x^2+1)e^x - e^x(2x)}{(x^2+1)^2} = \frac{e^x(x^2 + 1 - 2x)}{(x^2+1)^2} = \frac{e^x(x-1)^2}{(x^2+1)^2} \]

    (d) 设 \(u = \ln x\)，\(v = x\)，则 \(u' = \frac{1}{x}\)，\(v' = 1\)。

    \[ y' = \frac{x \cdot \frac{1}{x} - \ln x \cdot 1}{x^2} = \frac{1 - \ln x}{x^2} \]

    例题 5.2C（积法则与商法则综合）¶

    (a) 已知 \(y = (x^2 + 1)\ln x\)，求 \(\frac{dy}{dx}\)。 (b) 已知 \(y = \frac{\sin x}{e^x}\)，求 \(\frac{dy}{dx}\)。 © 已知 \(y = \tan x\)，用 \(\tan x = \frac{\sin x}{\cos x}\) 及商法则验证 \(\frac{d}{dx}(\tan x) = \sec^2 x\)。 (d) 求 \(y = \frac{2x-1}{x^2+3}\) 的导数。

    解：

    (a) 积法则。设 \(u = x^2 + 1\)，\(v = \ln x\)，则 \(u' = 2x\)，\(v' = \frac{1}{x}\)。

    \[ \frac{dy}{dx} = (x^2+1)\cdot\frac{1}{x} + \ln x \cdot 2x = \frac{x^2+1}{x} + 2x\ln x = x + \frac{1}{x} + 2x\ln x \]

    (b) 商法则。设 \(u = \sin x\)，\(v = e^x\)，则 \(u' = \cos x\)，\(v' = e^x\)。

    \[ \frac{dy}{dx} = \frac{e^x\cos x - \sin x \cdot e^x}{(e^x)^2} = \frac{e^x(\cos x - \sin x)}{e^{2x}} = \frac{\cos x - \sin x}{e^x} \]

    © 设 \(u = \sin x\)，\(v = \cos x\)，则 \(u' = \cos x\)，\(v' = -\sin x\)。

    \[ \frac{d}{dx}\left(\frac{\sin x}{\cos x}\right) = \frac{\cos x \cdot \cos x - \sin x \cdot (-\sin x)}{\cos^2 x} = \frac{\cos^2 x + \sin^2 x}{\cos^2 x} \]

    由三角恒等式 \(\sin^2 x + \cos^2 x = 1\)：

    \[ \frac{d}{dx}(\tan x) = \frac{1}{\cos^2 x} = \sec^2 x \]

    验证完毕。

    (d) 设 \(u = 2x-1\)，\(v = x^2+3\)，则 \(u' = 2\)，\(v' = 2x\)。

    \[ y' = \frac{(x^2+3)(2) - (2x-1)(2x)}{(x^2+3)^2} = \frac{2x^2+6 - 4x^2 + 2x}{(x^2+3)^2} = \frac{-2x^2 + 2x + 6}{(x^2+3)^2} = \frac{-2(x^2 - x - 3)}{(x^2+3)^2} \]

    7.3 基本求导公式¶

    有了导数的概念，我们现在需要一套高效的求导工具，而不是每次都用极限定义来计算。以下是最基本的求导公式，必须熟练掌握。

    7.3.1 幂函数求导公式的推导¶

    对于 \(f(x) = x^n\)，其中 \(n\) 为正整数，我们先用二项式定理来推导。

    由导数定义：

    \[ f'(x) = \lim_{\delta x \to 0} \frac{(x + \delta x)^n - x^n}{\delta x} \]

    根据二项式定理：

    \[ (x + \delta x)^n = x^n + nx^{n-1}\delta x + \frac{n(n-1)}{2}x^{n-2}(\delta x)^2 + \cdots + (\delta x)^n \]

    代入：

    \[ f'(x) = \lim_{\delta x \to 0} \frac{nx^{n-1}\delta x + \frac{n(n-1)}{2}x^{n-2}(\delta x)^2 + \cdots + (\delta x)^n}{\delta x} \]
    \[ = \lim_{\delta x \to 0} \left[ nx^{n-1} + \frac{n(n-1)}{2}x^{n-2}\delta x + \cdots + (\delta x)^{n-1} \right] \]

    当 \(\delta x \to 0\) 时，除第一项外所有项都趋于 \(0\)，因此：

    \[ \boxed{\frac{d}{dx}(x^n) = n x^{n-1}} \]

    这个公式不仅对正整数成立，对任意有理数 \(n\) 都成立。这是考纲明确要求的。

    下表展示了常见情形：

    \(f(x)\) 改写为 \(x^n\) 形式 \(f'(x)\) 说明
    \(x^2\) \(x^2\) \(2x\) \(n=2\)
    \(x^3\) \(x^3\) \(3x^2\) \(n=3\)
    \(x\) \(x^1\) \(1\) \(n=1\)
    \(1\) \(x^0\) \(0\) \(n=0\)
    \(\sqrt{x}\) \(x^{1/2}\) \(\frac{1}{2}x^{-1/2} = \frac{1}{2\sqrt{x}}\) \(n = \frac{1}{2}\)
    \(\frac{1}{x}\) \(x^{-1}\) \(-x^{-2} = -\frac{1}{x^2}\) \(n = -1\)
    \(\frac{1}{x^2}\) \(x^{-2}\) \(-2x^{-3} = -\frac{2}{x^3}\) \(n = -2\)
    \(\sqrt[3]{x}\) \(x^{1/3}\) \(\frac{1}{3}x^{-2/3} = \frac{1}{3\sqrt[3]{x^2}}\) \(n = \frac{1}{3}\)

    7.3.2 常数倍与和/差法则¶

    函数的线性组合求导非常简单：

    • 常数倍法则：\(\frac{d}{dx}[c \cdot f(x)] = c \cdot f'(x)\)

    • 推导：\(\lim_{\delta x \to 0} \frac{c f(x+\delta x) - c f(x)}{\delta x} = c \cdot \lim_{\delta x \to 0} \frac{f(x+\delta x) - f(x)}{\delta x} = c f'(x)\)

    • 和法则：\(\frac{d}{dx}[f(x) + g(x)] = f'(x) + g'(x)\)

    • 推导：\(\lim_{\delta x \to 0} \frac{[f(x+\delta x)+g(x+\delta x)] - [f(x)+g(x)]}{\delta x} = \lim_{\delta x \to 0} \frac{f(x+\delta x)-f(x)}{\delta x} + \lim_{\delta x \to 0} \frac{g(x+\delta x)-g(x)}{\delta x} = f'(x) + g'(x)\)

    • 差法则：\(\frac{d}{dx}[f(x) - g(x)] = f'(x) - g'(x)\)

    示例：\(f(x) = 3x^2 - 4x + 5\)

    \[ f'(x) = 3 \cdot (2x) - 4 \cdot (1) + 0 = 6x - 4 \]

    7.3.3 三角函数的导数¶

    核心条件：所有三角函数的角度必须使用弧度制。

    为什么必须用弧度？因为在弧度制下，\(\lim_{\theta \to 0} \frac{\sin\theta}{\theta} = 1\)。这个极限是三角函数求导的基础。如果使用角度制，这个极限会多出一个因子 \(\frac{\pi}{180}\)，导数公式就不再简洁了。

    \(\sin x\) 导数的推导：

    \[ \frac{d}{dx}(\sin x) = \lim_{\delta x \to 0} \frac{\sin(x+\delta x) - \sin x}{\delta x} \]

    使用三角恒等式 \(\sin(A+B) = \sin A\cos B + \cos A\sin B\)：

    \[ = \lim_{\delta x \to 0} \frac{\sin x\cos(\delta x) + \cos x\sin(\delta x) - \sin x}{\delta x} \]
    \[ = \lim_{\delta x \to 0} \left[ \sin x \cdot \frac{\cos(\delta x) - 1}{\delta x} + \cos x \cdot \frac{\sin(\delta x)}{\delta x} \right] \]

    利用两个重要极限：\(\lim_{\theta \to 0} \frac{\sin\theta}{\theta} = 1\) 和 \(\lim_{\theta \to 0} \frac{\cos\theta - 1}{\theta} = 0\)，得到：

    \[ \frac{d}{dx}(\sin x) = \sin x \cdot 0 + \cos x \cdot 1 = \cos x \]

    类似地可以推导 \(\frac{d}{dx}(\cos x) = -\sin x\)。

    对于 \(\tan x\)，我们利用 \(\tan x = \frac{\sin x}{\cos x}\) 和商法则推导（见 7.2 节）。

    标准公式汇总：

    \[ \boxed{\frac{d}{dx}(\sin x) = \cos x} \]
    \[ \boxed{\frac{d}{dx}(\cos x) = -\sin x} \]
    \[ \boxed{\frac{d}{dx}(\tan x) = \sec^2 x} \]

    7.3.4 指数函数与对数函数的导数¶

    \[ \boxed{\frac{d}{dx}(e^x) = e^x} \]

    这是微积分中最优美的公式之一——\(e^x\) 的导数就是它本身。从几何上看，这意味着曲线 \(y = e^x\) 在任意一点处的切线斜率都等于该点的函数值。

    对于一般的指数函数 \(a^x\)（\(a > 0, a \neq 1\)）：

    \[ \frac{d}{dx}(a^x) = a^x \ln a \]

    推导过程：将 \(a^x\) 写成 \(e^{\ln(a^x)} = e^{x\ln a}\)，然后使用链式法则：

    \[ \frac{d}{dx}(a^x) = \frac{d}{dx}(e^{x\ln a}) = e^{x\ln a} \cdot \ln a = a^x \ln a \]

    第 1 步：利用恒等式改写底数¶

    任何正数 \(a\) 都可以写成自然对数 \(e\) 的指数形式： $$ a = e^{\ln a} $$

    第 2 步：代入原函数¶

    将上式两边同时取 \(x\) 次方： $$ a^x = (e^{\ln a})^x $$

    第 3 步：化简指数（幂的运算法则）¶

    根据 \((e^{m})^n = e^{m \cdot n}\)，将指数相乘： $$ (e^{\ln a})^x = e^{x \cdot \ln a} $$ 此时原函数变为： $$ y = e^{x \ln a} $$

    第 4 步：设定中间变量（为链式法则做准备）¶

    令： $$ u = x \cdot \ln a $$ 注意：因为 \(a\) 是常数，所以 \(\ln a\) 也是常数。

    则原函数变为： $$ y = e^{u} $$

    第 5 步：分别求导¶

    （1）对 \(u\) 关于 \(x\) 求导（\(\ln a\) 是常数系数）： $$ \frac{du}{dx} = \ln a $$

    （2）对 \(y\) 关于 \(u\) 求导（指数函数的导数等于它本身）： $$ \frac{dy}{du} = e^{u} $$

    第 6 步：应用链式法则¶

    链式法则公式为： $$ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} $$ 将第 5 步的结果代入： $$ \frac{dy}{dx} = e^{u} \cdot (\ln a) $$

    第 7 步：代回并还原¶

    将 \(u = x \ln a\) 代回表达式： $$ \frac{dy}{dx} = e^{x \ln a} \cdot \ln a $$ 因为第 3 步已知 \(e^{x \ln a} = a^x\)，所以最终化简为： $$ \boxed{\frac{d}{dx}(a^x) = a^x \ln a} $$

    对于自然对数：

    \[ \boxed{\frac{d}{dx}(\ln x) = \frac{1}{x}} \]

    对于一般底数的对数：

    \[ \frac{d}{dx}(\log_a x) = \frac{1}{x \ln a} \]

    \(\ln x\) 导数的推导：

    设 \(y = \ln x\)，则 \(e^y = x\)。两边对 \(x\) 求导（隐函数微分）：

    \[ e^y \cdot \frac{dy}{dx} = 1 \quad \Rightarrow \quad \frac{dy}{dx} = \frac{1}{e^y} = \frac{1}{x} \]

    例题 5.3A（多项式求导）¶

    求下列函数的导数： (a) \(f(x) = 2x^5 - 3x^3 + 7x - 10\) (b) \(g(x) = \frac{1}{3}x^6 + \frac{4}{x^2} - \sqrt{x}\) © \(h(x) = (x+1)(x-2)\)（先展开再求导） (d) \(p(x) = 5x^4 + 2x^{-3} - 3x^{1/2} + 8\)

    \[ g(x) = \frac{1}{3}x^6 + 4x^{-2} - x^{1/2} \]
    \[ g'(x) = \frac{1}{3} \cdot 6x^5 + 4 \cdot (-2)x^{-3} - \frac{1}{2}x^{-1/2} = 2x^5 - 8x^{-3} - \frac{1}{2}x^{-1/2} \]

    化为分数形式：

    \[ g'(x) = 2x^5 - \frac{8}{x^3} - \frac{1}{2\sqrt{x}} \]

    © 先展开：\((x+1)(x-2) = x^2 - x - 2\)，然后求导：

    \[ h'(x) = 2x - 1 \]

    (d)

    \[ p'(x) = 5 \cdot 4x^3 + 2 \cdot (-3)x^{-4} - 3 \cdot \frac{1}{2}x^{-1/2} + 0 = 20x^3 - 6x^{-4} - \frac{3}{2}x^{-1/2} \]

    © 先求导：\(f'(x) = \cos x + \sin x\)

    代入 \(x = 0\)：\(f'(0) = \cos 0 + \sin 0 = 1 + 0 = 1\)

    (d)

    例题 5.3C（指数与对数求导）¶

    求下列函数的导数： (a) \(f(x) = 4e^x - \frac{1}{2}\ln x\) (b) \(g(x) = 3^x + \log_2 x\) © 已知 \(h(x) = e^x + \ln x\)，求 \(h'(1)\) (d) \(p(x) = 5^x - 2e^x + 3\ln x\)

    代入 \(x = 1\)：\(h'(1) = e^1 + \frac{1}{1} = e + 1\)

    \[ p'(x) = 5^x \ln 5 - 2e^x + 3 \cdot \frac{1}{x} = 5^x \ln 5 - 2e^x + \frac{3}{x} \]

    例题 5.3D（综合求导——重新表达后再求导）¶

    求下列函数的导数： (a) \(f(x) = \frac{2}{\sqrt[3]{x}}\) (b) \(g(x) = (2x)^3\)（注意与 \(2x^3\) 的区别）

    解：

    (a) 先改写：\(\frac{2}{\sqrt[3]{x}} = 2x^{-1/3}\)

    \[ f'(x) = 2 \cdot \left(-\frac{1}{3}\right)x^{-4/3} = -\frac{2}{3}x^{-4/3} = -\frac{2}{3\sqrt[3]{x^4}} \]

    (b) \((2x)^3 = 8x^3\)，所以 \(g'(x) = 8 \cdot 3x^2 = 24x^2\)

    注意：如果是 \(2x^3\)，导数为 \(6x^2\)，两者不同。

    7.4 链式法则（Chain Rule）¶

    7.4.1 链式法则的原理¶

    当想要求解复合函数的导数时——比如 \(y = (2x+1)^3\) 或 \(y = \sin(3x)\)——就需要用到链式法则。

    链式法则的核心思想是"层层求导，逐层相乘"。设 \(y\) 是 \(u\) 的函数，而 \(u\) 又是 \(x\) 的函数，即 \(y = f(u)\) 且 \(u = g(x)\)，则：

    \[ \boxed{\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}} \]

    用另一种形式写出：如果 \(y = f(g(x))\)，那么：

    \[ \frac{dy}{dx} = f'(g(x)) \cdot g'(x) \]

    即：外层函数对中间变量的导数，乘以中间变量对自变量的导数。

    7.4.2 链式法则的直观理解¶

    为什么链式法则成立？考虑微小变化量（仅供理解，不需要记忆该 7.4.2 节，因为太难了。该节告诉你为什么这个东西成立以及大概的原理是什么）：

    • 当 \(x\) 变化 \(\delta x\) 时，\(u = g(x)\) 变化 \(\delta u \approx g'(x)\delta x\)
    • 当 \(u\) 变化 \(\delta u\) 时，\(y = f(u)\) 变化 \(\delta y \approx f'(u)\delta u\)

    因此：

    \[ \frac{\delta y}{\delta x} \approx \frac{f'(u)\delta u}{\delta x} \approx f'(u) \cdot \frac{\delta u}{\delta x} \approx f'(u) \cdot g'(x) \]

    当 \(\delta x \to 0\) 时，近似变成精确等式。

    7.4.3 链式法则的常见应用模式（核心）¶

    以下六种模式涵盖了 IGCSE 附加数学中链式法则最常见的应用。每个模式都配有完整的逐步推导过程和典型例题。

    模式一：\(y = (ax+b)^n\)¶

    公式：\(\displaystyle \frac{dy}{dx} = a n (ax+b)^{n-1}\)

    逐步推导：

    第 1 步：设定中间变量

    令 \(u = ax + b\)，则原函数可以写成 \(y = u^n\) 的形式。这里 \(u\) 是中间变量，它是 \(x\) 的一次函数。

    • 外层函数：\(y = u^n\)（幂函数）
    • 内层函数：\(u = ax + b\)（线性函数）

    第 2 步：分别求导

    分别计算 \(y\) 对 \(u\) 的导数和 \(u\) 对 \(x\) 的导数：

    \[ \frac{dy}{du} = \frac{d}{du}(u^n) = n u^{n-1} \]
    \[ \frac{du}{dx} = \frac{d}{dx}(ax + b) = a \]

    第 3 步：应用链式法则

    链式法则说 \(\displaystyle \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}\)。将第 2 步的结果代入：

    \[ \frac{dy}{dx} = (n u^{n-1}) \cdot a = a n u^{n-1} \]

    第 4 步：代回原变量

    将 \(u = ax + b\) 代回表达式中：

    \[ \boxed{\frac{dy}{dx} = a n (ax+b)^{n-1}} \]

    模式二：\(y = \sin(ax+b)\)¶

    公式：\(\displaystyle \frac{dy}{dx} = a\cos(ax+b)\)

    逐步推导：

    第 1 步：设定中间变量

    令 \(u = ax + b\)，则 \(y = \sin u\)。

    • 外层函数：\(y = \sin u\)（正弦函数）
    • 内层函数：\(u = ax + b\)（线性函数）

    第 2 步：分别求导

    \[ \frac{dy}{du} = \frac{d}{du}(\sin u) = \cos u \]
    \[ \frac{du}{dx} = \frac{d}{dx}(ax + b) = a \]

    第 3 步：应用链式法则

    \[ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} = (\cos u) \cdot a = a \cos u \]

    第 4 步：代回原变量

    将 \(u = ax + b\) 代回：

    \[ \boxed{\frac{dy}{dx} = a\cos(ax+b)} \]

    模式三：\(y = \cos(ax+b)\)¶

    公式：\(\displaystyle \frac{dy}{dx} = -a\sin(ax+b)\)

    逐步推导：

    第 1 步：设定中间变量

    令 \(u = ax + b\)，则 \(y = \cos u\)。

    • 外层函数：\(y = \cos u\)（余弦函数）
    • 内层函数：\(u = ax + b\)（线性函数）

    第 2 步：分别求导

    \[ \frac{dy}{du} = \frac{d}{du}(\cos u) = -\sin u \]
    \[ \frac{du}{dx} = \frac{d}{dx}(ax + b) = a \]

    第 3 步：应用链式法则

    \[ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} = (-\sin u) \cdot a = -a \sin u \]

    第 4 步：代回原变量

    将 \(u = ax + b\) 代回：

    \[ \boxed{\frac{dy}{dx} = -a\sin(ax+b)} \]

    模式四：\(y = e^{ax+b}\)¶

    公式：\(\displaystyle \frac{dy}{dx} = a e^{ax+b}\)

    逐步推导：

    第 1 步：设定中间变量

    令 \(u = ax + b\)，则 \(y = e^u\)。

    • 外层函数：\(y = e^u\)（指数函数，底数为 \(e\)）。这里 \(u\) 是中间变量，它是 \(x\) 的一次函数。
    • 内层函数：\(u = ax + b\)（线性函数）

    第 2 步：分别求导

    分别计算 \(y\) 对 \(u\) 的导数和 \(u\) 对 \(x\) 的导数：

    首先，\(y\) 对 \(u\) 求导：\(e^u\) 的导数是它本身，即：

    \[ \frac{dy}{du} = \frac{d}{du}(e^u) = e^u \]

    其次，\(u\) 对 \(x\) 求导：\(u = ax + b\) 是一个关于 \(x\) 的一次函数（线性函数），其图像是一条斜率为 \(a\) 的直线。根据幂函数求导公式 \(\frac{d}{dx}(x^n) = nx^{n-1}\)，我们分别对两项求导：

    • \(ax\) 项：将 \(a\) 视为常数系数，\(ax = a \cdot x^1\)，导数为 \(a \cdot 1 \cdot x^{0} = a\)
    • \(b\) 项：常数 \(b\) 的导数为 \(0\)

    因此，\(ax + b\) 的导数就是系数 \(a\)，即：

    \[ \frac{du}{dx} = \frac{d}{dx}(ax + b) = \frac{d}{dx}(ax) + \frac{d}{dx}(b) = a + 0 = a \]

    这个结果在几何上非常直观：一次函数 \(u = ax + b\) 的斜率恒为 \(a\)，意味着无论 \(x\) 取何值，\(u\) 关于 \(x\) 的变化率始终等于 \(a\)——这正是导数所描述的瞬时变化率。

    关键理解：\(a\) 为什么必须保留？
    初学者可能会想："既然 \(e^u\) 的导数还是 \(e^u\)，那结果为什么不直接等于 \(e^u\) 而是 \(a e^u\)？"

    原因在于链式法则的乘法结构：\(\displaystyle \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}\)。即使 \(\frac{dy}{du} = e^u\) 很简单，但 \(\frac{du}{dx} = a\) 是另一个因子，两者必须相乘。这里的 \(a\) 是内层函数 \(u = ax + b\) 对 \(x\) 的变化率——它衡量的是当 \(x\) 变化 1 个单位时，\(u\) 会变化 \(a\) 个单位。这个"传输系数"会随着链式法则层层传递到最终结果中，不能被忽略或"吸收"掉。

    举例来说，\(y = e^{2x}\) 的导数是 \(2e^{2x}\)，而 \(y = e^{x}\) 的导数是 \(e^x\)。两者的差别就是系数 \(2\) 造成的——正是因为内层 \(2x\) 比 \(x\) 变化得更快（快 2 倍），所以导数也要乘以 2。如果去掉 \(a\)，就无法区分 \(e^{2x}\) 和 \(e^{x}\) 在变化率上的差异了。

    第 3 步：应用链式法则

    链式法则指出 \(\displaystyle \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}\)。将第 2 步的结果代入：

    \[ \frac{dy}{dx} = e^u \cdot a = a e^u \]

    第 4 步：代回原变量

    将 \(u = ax + b\) 代回到表达式中，得到最终的导数公式：

    \[ \boxed{\frac{dy}{dx} = a e^{ax+b}} \]

    这个公式的含义是：指数函数 \(e^{ax+b}\) 的导数等于其本身乘以 \(a\)（即内层函数 \(ax+b\) 的导数）。

    模式五：\(y = \ln(ax+b)\)¶

    公式：\(\displaystyle \frac{dy}{dx} = \frac{a}{ax+b}\)

    逐步推导：

    第 1 步：设定中间变量

    令 \(u = ax + b\)，则 \(y = \ln u\)。

    • 外层函数：\(y = \ln u\)（自然对数函数）
    • 内层函数：\(u = ax + b\)（线性函数）

    第 2 步：分别求导

    \[ \frac{dy}{du} = \frac{d}{du}(\ln u) = \frac{1}{u} \]
    \[ \frac{du}{dx} = \frac{d}{dx}(ax + b) = a \]

    第 3 步：应用链式法则

    \[ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} = \frac{1}{u} \cdot a = \frac{a}{u} \]

    第 4 步：代回原变量

    将 \(u = ax + b\) 代回：

    \[ \boxed{\frac{dy}{dx} = \frac{a}{ax+b}} \]

    模式六：\(y = \tan(ax+b)\)¶

    公式：\(\displaystyle \frac{dy}{dx} = a\sec^2(ax+b)\)

    逐步推导：

    第 1 步：设定中间变量

    令 \(u = ax + b\)，则 \(y = \tan u\)。

    • 外层函数：\(y = \tan u\)（正切函数）
    • 内层函数：\(u = ax + b\)（线性函数）

    第 2 步：分别求导

    正切函数的导数为 \(\displaystyle \frac{d}{du}(\tan u) = \sec^2 u\)（该公式可通过 \(\tan u = \frac{\sin u}{\cos u}\) 及商法则推导得出）。

    \[ \frac{dy}{du} = \frac{d}{du}(\tan u) = \sec^2 u \]
    \[ \frac{du}{dx} = \frac{d}{dx}(ax + b) = a \]

    第 3 步：应用链式法则

    \[ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} = (\sec^2 u) \cdot a = a \sec^2 u \]

    第 4 步：代回原变量

    将 \(u = ax + b\) 代回：

    \[ \boxed{\frac{dy}{dx} = a\sec^2(ax+b)} \]
    \[ \boxed{\displaystyle \frac{dy}{dx} = \frac{a}{\cos^2(ax+b)}} \]

    7.4.4 多层链式法则¶

    当函数有三层甚至更多层复合时，链式法则可以连续使用多次。例如 \(y = f(g(h(x)))\)：

    \[ \frac{dy}{dx} = f'(g(h(x))) \cdot g'(h(x)) \cdot h'(x) \]

    从最外层开始，逐层向内求导，每层相乘。

    例题 5.4A（多项式复合函数）¶

    求下列函数的导数： (a) \(y = (3x - 2)^5\) (b) \(y = \frac{1}{(2x+1)^3}\) © \(y = \sqrt{4x - 1}\) (d) \(y = (5 - 2x)^{-4}\)

    解：

    (a) 令 \(u = 3x - 2\)，则 \(y = u^5\)。

    \[ \frac{dy}{dx} = 5u^4 \cdot 3 = 5(3x-2)^4 \cdot 3 = 15(3x-2)^4 \]

    (b) 写成 \(y = (2x+1)^{-3}\)，令 \(u = 2x+1\)。

    \[ \frac{dy}{dx} = (-3)u^{-4} \cdot 2 = -6(2x+1)^{-4} = -\frac{6}{(2x+1)^4} \]

    © 写成 \(y = (4x-1)^{1/2}\)，令 \(u = 4x-1\)。

    \[ \frac{dy}{dx} = \frac{1}{2}u^{-1/2} \cdot 4 = \frac{1}{2}(4x-1)^{-1/2} \cdot 4 = \frac{2}{\sqrt{4x-1}} \]

    (d) 令 \(u = 5 - 2x\)，则 \(y = u^{-4}\)。

    \[ \frac{dy}{dx} = (-4)u^{-5} \cdot (-2) = 8(5-2x)^{-5} = \frac{8}{(5-2x)^5} \]

    例题 5.4B（三角与指数复合函数）¶

    求下列函数的导数： (a) \(y = \sin\left(2x + \frac{\pi}{3}\right)\) (b) \(y = e^{-3x + 1}\) © \(y = \tan(5x)\) (d) \(y = \cos\left(\frac{x}{2}\right)\)

    解：

    (a) 令 \(u = 2x + \frac{\pi}{3}\)，则 \(y = \sin u\)。

    \[ \frac{dy}{dx} = \cos u \cdot 2 = 2\cos\left(2x + \frac{\pi}{3}\right) \]

    (b) 令 \(u = -3x + 1\)，则 \(y = e^u\)。

    \[ \frac{dy}{dx} = e^u \cdot (-3) = -3e^{-3x+1} \]

    © 令 \(u = 5x\)，则 \(y = \tan u\)。

    \[ \frac{dy}{dx} = \sec^2 u \cdot 5 = 5\sec^2(5x) \]

    (d) 令 \(u = \frac{x}{2}\)，则 \(y = \cos u\)。

    \[ \frac{dy}{dx} = -\sin u \cdot \frac{1}{2} = -\frac{1}{2}\sin\left(\frac{x}{2}\right) \]

    例题 5.4C（对数复合与多层链式）¶

    求下列函数的导数： (a) \(y = \ln(3x^2 + 1)\) (b) \(y = e^{\sin x}\) © \(y = \sin^3 x\)（即 \((\sin x)^3\)） (d) \(y = \sqrt{\cos x}\)

    解：

    (a) 令 \(u = 3x^2 + 1\)，则 \(y = \ln u\)。

    \[ \frac{dy}{dx} = \frac{1}{u} \cdot 6x = \frac{6x}{3x^2 + 1} \]

    (b) 令 \(u = \sin x\)，则 \(y = e^u\)。

    \[ \frac{dy}{dx} = e^u \cdot \cos x = e^{\sin x} \cdot \cos x \]

    © 这里有两层复合：令 \(u = \sin x\)，\(y = u^3\)，则：

    \[ \frac{dy}{dx} = 3u^2 \cdot \cos x = 3\sin^2 x \cdot \cos x \]

    (d) 写成 \(y = (\cos x)^{1/2}\)，令 \(u = \cos x\)，\(y = u^{1/2}\)。

    \[ \frac{dy}{dx} = \frac{1}{2}u^{-1/2} \cdot (-\sin x) = \frac{1}{2}(\cos x)^{-1/2} \cdot (-\sin x) = -\frac{\sin x}{2\sqrt{\cos x}} \]

    例题 5.4D（三层链式法则）¶

    求 \(y = \sin^2(3x)\) 的导数。

    解：

    这里有三层复合：\(y = (\sin(3x))^2\)

    令 \(v = 3x\)，\(u = \sin v\)，\(y = u^2\)。

    \[ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dv} \cdot \frac{dv}{dx} = (2u) \cdot (\cos v) \cdot (3) \]
    \[ = 2\sin(3x) \cdot \cos(3x) \cdot 3 = 6\sin(3x)\cos(3x) = 3\sin(6x) \]

    （最后一步使用了倍角公式 \(\sin 2\theta = 2\sin\theta\cos\theta\)）

    7.5 切线与法线¶

    7.5.1 基础知识¶

    给定一条光滑曲线 \(y = f(x)\) 及其上一点 \(P(a, f(a))\)：

    • 切线（Tangent）：过点 \(P\) 且斜率为 \(f'(a)\) 的直线。切线是曲线在该点处的最佳线性逼近（好比过山车在该点断电后飞出去的方向）。
    • 法线（Normal）：过点 \(P\) 且与切线垂直的直线（好比过山车轨道的垂直支撑杆）。

    0606 核心：切线不等于“与曲线只有一个交点”，判断切线的唯一标准是斜率是否等于该点的导数值。

    7.5.2 标准三步法（已知切点）¶

    当题目明确说 “在点 P 处的切线”（英文常为 at the point P）时，\(P\) 就是切点。求解步骤如下：

    1. 求切点坐标：确定横坐标 \(a\)，计算 \(f(a)\)，得到切点 \((a, f(a))\)。
    2. 求切线斜率：对 \(f(x)\) 求导，代入 \(x=a\)，得到斜率 \(m = f'(a)\)。
    3. 写切线方程：使用点斜式 \(y - y_0 = m(x - x_0)\)：
    \[ y - f(a) = f'(a)(x - a) \]

    法线的斜率 \(m_{\perp}\) 满足 \(m \cdot m_{\perp} = -1\)（当 \(m \neq 0\) 时），即 \(m_{\perp} = -\dfrac{1}{f'(a)}\)。法线方程为：

    \[ y - f(a) = -\frac{1}{f'(a)}(x - a) \]

    【标准例题】

    已知曲线 \(y = x^3 - 2x^2 + 1\)，求该曲线在点 \(P(1, 0)\) 处的切线方程和法线方程。

    解： - 求导：\(\frac{dy}{dx} = 3x^2 - 4x\)。 - 点 \(P(1,0)\) 在曲线上（检验成立），斜率 \(m = 3(1)^2 - 4(1) = -1\)。 - 切线：\(y - 0 = -1(x - 1)\)，即 \(\boxed{y = -x + 1}\)。 - 法线：\(m_{\perp} = -\frac{1}{-1} = 1\)。法线方程：\(y - 0 = 1(x - 1)\)，即 \(\boxed{y = x - 1}\)。

    ⚠️ 特殊情况（高频易错）： - 若 \(f'(a) = 0\)（切线水平），则法线为竖直线 \(x = a\)（法线不能写成 \(y=mx+c\) 的形式！）。 - 若 \(f'(a)\) 不存在（如尖点），则切线竖直，法线水平（0606极少考，但思维上要了解）。

    7.5.3 为什么切线斜率等于导数？¶

    从几何上看，曲线上两点 \((a, f(a))\) 和 \((a+\delta x, f(a+\delta x))\) 的连线斜率为 \(\frac{f(a+\delta x) - f(a)}{\delta x}\)。当 \(\delta x\) 趋近于 0 时，这两个点无限靠近，这条连线逐渐逼近切线，其斜率趋近于导数 \(f'(a)\)。

    从代数上看，切线方程 \(y = f(a) + f'(a)(x-a)\) 在 \(x=a\) 处与曲线有相同的函数值和相同的一阶导数，因此它是曲线在该点处最精确的线性近似。

    0606 记忆法：导数求出来，把切点横坐标代进去，算出来的数字就是切线的斜率。物理上叫瞬时变化率，几何上就是切线斜率。

    7.5.4 重要陷阱：切点未知的情形（0606 必考压轴）¶

    如果题目说 “经过点 P 的切线”（英文常为 passes through the point P），而非 “在点 P 处”，那么 \(P\) 可能不是切点（点可能在曲线外，也可能在曲线上但不是切点）。

    🚨 用红笔记住： - “在点 P 处” ➡️ \(P\) 一定是切点（用 5.5.2 三步法）。 - “过点 P 的切线” ➡️ \(P\) 不一定是切点（必须设未知数求解）。

    标准处理流程：

    1. 设切点：设切点为 \((a, f(a))\)，其中 \(a\) 为未知数。
    2. 写通式：写出过该切点的切线方程：\(y - f(a) = f'(a)(x - a)\)。
    3. 代入点 P：将 \(P\) 的坐标代入上述方程，得到关于 \(a\) 的方程。
    4. 解方程：解出所有可能的 \(a\) 值。
    5. 写答案：每个 \(a\) 对应一条切线，全部写出来。

    【完整实战例题（切点未知）】

    求曲线 \(f(x) = x^2 - 4x + 5\) 过原点 \((0,0)\) 的切线方程。

    第一步（审题）：
    先看原点 \((0,0)\) 在不在曲线上？代入 \(f(0)=5 \neq 0\)。显然，原点不在曲线上，所以原点绝对不是切点。

    第二步（设切点）：
    设切点为 \(Q(a, f(a))\)，即 \(Q(a, a^2 - 4a + 5)\)。

    第三步（写通式）：
    求导得 \(f'(x) = 2x - 4\)，斜率 \(m = 2a - 4\)。
    过切点 \(Q\) 的切线通式为： $$ y - (a^2 - 4a + 5) = (2a - 4)(x - a) $$

    7.6 驻点（极大值与极小值）¶

    7.6.1 什么是驻点？¶

    驻点（stationary point）是函数图像上切线水平（斜率为零）的点。在驻点处，函数的值可能达到局部最大、局部最小，或者既不是最大也不是最小（后一种情况在 IGCSE 中不考,BUT pre-AP precalculus考哦～～～～）。

    求驻点的步骤： 1. 求 \(f'(x)\)。 2. 解方程 \(f'(x) = 0\)。 3. 得到的每个解 \(x = a\) 对应一个驻点 \((a, f(a))\)。

    7.6.2 判别极大值与极小值¶

    有两种方法可以区分极大值和极小值。

    方法一：一阶导数判别法（符号变化法）

    观察驻点 \(x = a\) 左右两侧 \(f'(x)\) 的符号：

    \(x\) 略小于 \(a\)（左） \(x = a\) \(x\) 略大于 \(a\)（右） 结论
    \(f' > 0\)（上升） \(f' = 0\) \(f' < 0\)（下降） 局部最大值
    \(f' < 0\)（下降） \(f' = 0\) \(f' > 0\)（上升） 局部最小值
    \(f' > 0\)（上升） \(f' = 0\) \(f' > 0\)（上升） 非极值（不考）
    \(f' < 0\)（下降） \(f' = 0\) \(f' < 0\)（下降） 非极值（不考）

    为什么符号变化能判断极值？想象你爬山： - 如果你先上坡（\(f'>0\)），到达山顶（\(f'=0\)），然后下坡（\(f'<0\)），那么山顶就是局部最大值。 - 如果你先下坡（\(f'<0\)），到达谷底（\(f'=0\)），然后上坡（\(f'>0\)），那么谷底就是局部最小值。

    方法二：二阶导数判别法

    二阶导数 \(f''(x)\) 是一阶导数的导数，它告诉我们 \(f'(x)\) 的变化率。

    • 如果 \(f'(a) = 0\) 且 \(f''(a) > 0\) → 局部最小值（曲线在该点"向上凹"，像碗底）。
    • 如果 \(f'(a) = 0\) 且 \(f''(a) < 0\) → 局部最大值（曲线在该点"向下凹"，像倒扣的碗）。
    • 如果 \(f''(a) = 0\)，判别法失效，需要用一阶导数法。

    为什么二阶导数能判断？ - \(f''(a) > 0\) 意味着 \(f'(x)\) 在 \(x=a\) 处递增。由于 \(f'(a)=0\)，那么 \(f'\) 从负变为正→最小值。 - \(f''(a) < 0\) 意味着 \(f'(x)\) 在 \(x=a\) 处递减。由于 \(f'(a)=0\)，那么 \(f'\) 从正变为负→最大值。

    7.6.3 二阶导数的求法¶

    二阶导数就是一阶导数的导数。用记号表示：

    \[ f''(x) = \frac{d}{dx}(f'(x)) \quad \text{或} \quad \frac{d^2y}{dx^2} = \frac{d}{dx}\left(\frac{dy}{dx}\right) \]

    示例：\(f(x) = x^3 - 3x^2 + 2\) - 一阶导数：\(f'(x) = 3x^2 - 6x\) - 二阶导数：\(f''(x) = 6x - 6\)

    例题 5.6A（多项式函数的驻点）¶

    求 \(f(x) = 2x^3 - 9x^2 + 12x - 3\) 的驻点，并判别它们是极大值还是极小值。

    解：

    第一步：求 \(f'(x)\) 并令其为零。

    \[ f'(x) = 6x^2 - 18x + 12 = 6(x^2 - 3x + 2) = 6(x-1)(x-2) \]

    令 \(f'(x) = 0\)，得 \(x = 1\) 或 \(x = 2\)。

    \[ f(1) = 2 - 9 + 12 - 3 = 2，\quad 驻点 (1, 2) $$ $$ f(2) = 16 - 36 + 24 - 3 = 1，\quad 驻点 (2, 1) \]

    第二步：用二阶导数判别。

    \[ f''(x) = 12x - 18 \]
    • \(f''(1) = 12(1) - 18 = -6 < 0\) → \((1, 2)\) 是局部最大值。
    • \(f''(2) = 12(2) - 18 = 6 > 0\) → \((2, 1)\) 是局部最小值。

    一阶导数法验证：在 \(x=1\) 左侧取 \(x=0\)，\(f'(0) = 12 > 0\)；在 \(x=1\) 右侧取 \(x=1.5\)，\(f'(1.5) = 6(0.5)(-0.5) = -1.5 < 0\)。符号从正变负，确认是最大值。

    例题 5.6B（含三角函数的驻点） --该区域有三角函数插入¶

    求 \(f(x) = \sin x + \cos x\) 在区间 \([0, 2\pi]\) 上的驻点，并判别类型。

    解：

    \[ f'(x) = \cos x - \sin x \]

    令 \(f'(x) = 0\)：

    \[ \cos x - \sin x = 0 \quad \Rightarrow \quad \cos x = \sin x \quad \Rightarrow \quad \cos x/\cos x = \sin x/\cos x \quad \Rightarrow \quad \tan x = 1 \]

    在 \([0, 2\pi]\) 上，\(\tan x = 1\) 的解为 \(x = \frac{\pi}{4}\) 和 \(x = \frac{5\pi}{4}\)。

    \[ f\left(\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2} = \sqrt{2}，\quad f\left(\frac{5\pi}{4}\right) = -\frac{\sqrt{2}}{2} - \frac{\sqrt{2}}{2} = -\sqrt{2} \]

    求二阶导数：\(f''(x) = -\sin x - \cos x\)。

    • \(f''\left(\frac{\pi}{4}\right) = -\frac{\sqrt{2}}{2} - \frac{\sqrt{2}}{2} = -\sqrt{2} < 0\) → \(\left(\frac{\pi}{4}, \sqrt{2}\right)\) 是局部最大值。
    • \(f''\left(\frac{5\pi}{4}\right) = \frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2} = \sqrt{2} > 0\) → \(\left(\frac{5\pi}{4}, -\sqrt{2}\right)\) 是局部最小值。

    解释1：¶

    因为正切函数 \(\tan x\) 的周期是 \(\pi\)（而不是 \(2\pi\)）所以是\(x = \frac{\pi}{4}\) 和 \(x = \frac{5\pi}{4}\)

    具体推导如下：

    1. 求基本解：
      在 \([0, 2\pi]\) 内，满足 \(\tan x = 1\) 的最小正根是
      $$ x = \arctan(1) = \frac{\pi}{4} $$

    2. 利用周期性写出通解：
      因为 \(\tan x\) 的周期是 \(\pi\)，所以方程 \(\tan x = 1\) 的所有解为： $$ x = \frac{\pi}{4} + k\pi \quad (k \in \mathbb{Z}) $$

    3. 在指定区间内筛选：
      给定区间是 \([0, 2\pi]\)，我们代入不同的整数 \(k\)：

    4. \(k = 0\)：\(x = \frac{\pi}{4}\)（符合）
    5. \(k = 1\)：\(x = \frac{\pi}{4} + \pi = \frac{5\pi}{4}\)（符合）
    6. \(k = 2\)：\(x = \frac{\pi}{4} + 2\pi = \frac{9\pi}{4} > 2\pi\)（超出范围，舍去）
    7. \(k = -1\)：\(x = \frac{\pi}{4} - \pi = -\frac{3\pi}{4} < 0\)（超出范围，舍去）

    所以，在 \([0, 2\pi]\) 上只有这两个解。

    直观理解（单位圆）：
    \(\tan x = 1\) 意味着 \(\sin x = \cos x\)，即单位圆上 \(x\) 坐标和 \(y\) 坐标相等的点。在单位圆上，只有第一象限的角平分线（\(\pi/4\)）和第三象限的角平分线（\(\pi/4 + \pi = 5\pi/4\)）满足这一点。

    解释2:¶

    1. 基本通解公式（对比）¶

    • \(\sin x = \sin \theta\) 的通解为： $$ x = k\pi + (-1)^k \theta \quad (k \in \mathbb{Z}) $$

    • \(\cos x = \cos \theta\) 的通解为： $$ x = 2k\pi \pm \theta \quad (k \in \mathbb{Z}) $$

    • \(\tan x = \tan \theta\) 的通解为： $$ x = k\pi + \theta \quad (k \in \mathbb{Z}) $$

    2. 针对本题 \(\sin x = \cos x\) 的推导（仅介绍，不需要记忆）¶

    我们将其转化为标准形式来套用上述公式。

    方法一：转化为 \(\sin\)（利用 \(\cos x = \sin(\frac{\pi}{2} - x)\)）¶

    原方程化为： $$ \sin x = \sin\left(\frac{\pi}{2} - x\right) $$

    套用 \(\sin\) 的通解公式（\(x = k\pi + (-1)^k \theta\)）：

    • 当 \(k\) 为偶数（设 \(k=2n\)）： $$ x = 2n\pi + \left(\frac{\pi}{2} - x\right) \quad\Rightarrow\quad 2x = 2n\pi + \frac{\pi}{2} \quad\Rightarrow\quad x = n\pi + \frac{\pi}{4} $$

    • 当 \(k\) 为奇数（设 \(k=2n+1\)）： $$ x = (2n+1)\pi - \left(\frac{\pi}{2} - x\right) \quad\Rightarrow\quad x = 2n\pi + \pi - \frac{\pi}{2} + x \quad\Rightarrow\quad 0 = 2n\pi + \frac{\pi}{2} $$ 此式显然不成立，故奇数情况无解。

    所以解得： $$ x = n\pi + \frac{\pi}{4} \quad (n \in \mathbb{Z}) $$

    方法二：转化为 \(\cos\)（利用 \(\sin x = \cos(\frac{\pi}{2} - x)\)）（仅介绍，不需要记忆）¶

    原方程化为： $$ \cos\left(\frac{\pi}{2} - x\right) = \cos x $$

    套用 \(\cos\) 的通解公式（\(A = 2k\pi \pm B\)）：

    • 取 \(+\) 号： $$ \frac{\pi}{2} - x = 2k\pi + x \quad\Rightarrow\quad 2x = \frac{\pi}{2} - 2k\pi \quad\Rightarrow\quad x = \frac{\pi}{4} - k\pi $$ 等价于 \(x = n\pi + \frac{\pi}{4}\)。

    • 取 \(-\) 号： $$ \frac{\pi}{2} - x = 2k\pi - x \quad\Rightarrow\quad \frac{\pi}{2} = 2k\pi $$ 此式不成立，舍去。

    所以解得： $$ x = n\pi + \frac{\pi}{4} \quad (n \in \mathbb{Z}) $$

    3. 结论¶

    无论用 \(\tan\)、\(\sin\) 还是 \(\cos\) 的通解，最终结果完全一致： $$ \boxed{x = \frac{\pi}{4} + n\pi \quad (n \in \mathbb{Z})} $$

    在区间 \([0, 2\pi]\) 内取 \(n=0, 1\)，即得到 \(\frac{\pi}{4}\) 和 \(\frac{5\pi}{4}\)。

    3. 复合角换元法（Paper 1 & 2 必考重灾区）¶

    当方程括号里不是单纯的 \(x\)，而是如 \(2x\)、\(3x + \frac{\pi}{4}\) 时，严禁直接展开。

    1. 第 1 步（换元）：令 \(u\) 等于括号里的整个角。
    2. 第 2 步（换区间——这是 90% 丢分的原因）：将原 \(x\) 的区间左右边界同时代入 \(u\) 的表达式，计算出 \(u\) 的新区间。务必只在 \(u\) 的新区间里找解，不要在 \(0\) 到 \(2\pi\) 里找。
    3. 第 3 步（解 \(u\)）：利用第 2 部分的“求生表”解出所有符合条件的 \(u\)。
    4. 第 4 步（回代）：解一元一次方程 \(u = 2x + \cdots\) 求出最终的 \(x\)。

    4. 辅助角公式（隐藏 BOSS）¶

    当式子呈现 \(a\sin x \pm b\cos x = c\) 的形态时，无法直接除以 \(\cos x\)，必须将其捏合成单一的正弦函数。

    1. 标准形式化法： $$ a\sin x + b\cos x = R\sin(x + \alpha) $$
    2. 计算 \(R = \sqrt{a^2 + b^2}\)
    3. 计算 \(\alpha = \tan^{-1}\left(\frac{b}{a}\right)\)（注意：分子是 \(\cos\) 的系数 \(b\)）
    4. 若为减号：\(a\sin x - b\cos x = R\sin(x - \alpha)\)，公式同上。
    5. 后续处理：化成 \(R\sin(x+\alpha)=c\) 后，令 \(u = x+\alpha\)，立即切换成第 3 部分（复合角换元法） 进行操作。
    6. 秒杀应用（极值题）：若问 \(f(x)=a\sin x + b\cos x\) 的最大值/最小值，不用求导，最大值就是 \(+R\)，最小值就是 \(-R\)。

    例题 5.6C（含指数函数的驻点）¶

    求 \(f(x) = xe^{-x}\) 的驻点，并判别类型。求该函数的最大值。

    解：

    使用积法则：设 \(u = x\)，\(v = e^{-x}\)，则 \(u' = 1\)，\(v' = -e^{-x}\)。

    \[ f'(x) = x \cdot (-e^{-x}) + e^{-x} \cdot 1 = e^{-x}(1 - x) \]

    令 \(f'(x) = 0\)。由于 \(e^{-x} > 0\) 对所有 \(x\) 成立，所以 \(1 - x = 0\)，即 \(x = 1\)。

    \[ f(1) = 1 \cdot e^{-1} = \frac{1}{e} \]

    驻点为 \(\left(1, \frac{1}{e}\right)\)。

    用一阶导数法判别：在 \(x=1\) 左侧取 \(x=0\)，\(f'(0) = e^0(1-0) = 1 > 0\)；在 \(x=1\) 右侧取 \(x=2\)，\(f'(2) = e^{-2}(1-2) = -e^{-2} < 0\)。符号从正变负，所以 \(\left(1, \frac{1}{e}\right)\) 是局部最大值。

    由于当 \(x \to \infty\) 时 \(xe^{-x} \to 0\)，当 \(x \to -\infty\) 时 \(xe^{-x} \to -\infty\)，这个最大值也是全局最大值，最大值为 \(\frac{1}{e}\)。

    例题 5.6D（驻点求参数）¶

    已知 \(f(x) = x^3 + ax^2 + b\) 在 \(x = 2\) 处有驻点，且该驻点的函数值为 \(5\)，求常数 \(a\) 和 \(b\)。

    解：

    \(f'(x) = 3x^2 + 2ax\)

    在 \(x=2\) 处有驻点（也叫 极值），所以 \(f'(2) = 0\)：

    \[ 3(2)^2 + 2a(2) = 0 \quad \Rightarrow \quad 12 + 4a = 0 \quad \Rightarrow \quad a = -3 \]

    驻点函数值 \(f(2) = 5\)：

    \[ f(2) = 2^3 + (-3)(2)^2 + b = 8 - 12 + b = b - 4 = 5 \quad \Rightarrow \quad b = 9 \]

    所以 \(a = -3\)，\(b = 9\)。\(f(x) = x^3 - 3x^2 + 9\)。

    7.7 相关变化率与微小增量近似¶

    7.7.1 相关变化率（Connected Rates of Change）¶

    相关变化率问题处理的是多个相互关联的量的变化速度。核心思路是：如果 \(y\) 通过某个关系依赖于 \(u\)，而 \(u\) 又依赖于 \(x\)，那么我们可以通过链式法则将 \(\frac{dy}{dx}\) 与 \(\frac{dy}{du}\) 和 \(\frac{du}{dx}\) 联系起来。

    \[ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} \]

    更一般地，如果问题涉及时间 \(t\)，我们经常使用：

    \[ \frac{dy}{dt} = \frac{dy}{dx} \cdot \frac{dx}{dt} \]

    解题步骤： 1. 找出所有相关变量，确定已知变化率和需求的变化率。 2. 建立变量之间的函数关系（几何公式、物理关系等）。 3. 对关系式两边关于时间 \(t\) 求导（隐式微分）。 4. 代入已知数值，解出未知变化率。

    7.7.2 微小增量与近似（Small Increments and Approximations）¶

    导数的另一个重要应用是：用切线来近似函数在某个点附近的变化。

    从导数定义出发： $$ f'(a) \approx \frac{f(a + \delta x) - f(a)}{\delta x} $$ 移项整理，得到核心估算公式： $$ \boxed{f(a + \delta x) \approx f(a) + f'(a) \cdot \delta x} $$

    更常用的简写版（令 \(y = f(x)\)）： $$ \boxed{\delta y \approx \frac{dy}{dx} \cdot \delta x} $$

    更长的版本：

    第 1 步：从导数的“官方定义”出发¶

    导数的定义是： $$ f'(a) = \lim_{\delta x \to 0} \frac{f(a + \delta x) - f(a)}{\delta x} $$

    翻译成人话：当 \(\delta x\) 无限趋近于 0 时，那个“割线斜率”就变成了“切线斜率”。

    第 2 步：撕掉“极限”这个紧箍咒（核心推导）¶

    如果 \(\delta x\) 非常小（但不是无限小，比如 0.01），那么它就不再是严格的极限，而是一个近似值。

    所以，上面的等号（\(=\)）就可以暂时变成约等号（\(\approx\)）： $$ f'(a) \approx \frac{f(a + \delta x) - f(a)}{\delta x} $$

    为什么这里敢变成约等号？ 因为 \(f'(a)\) 是切线斜率，而 \(\frac{f(a + \delta x) - f(a)}{\delta x}\) 是割线斜率。当 \(\delta x\) 很小时，割线斜率 \(\approx\) 切线斜率。这就是推导的几何合法性。

    第 3 步：纯粹的代数变形（乘过去）¶

    现在我们有了： $$ f'(a) \approx \frac{f(a + \delta x) - f(a)}{\delta x} $$

    两边同时乘以 \(\delta x\)（这是小学四年级的等式性质，随便乘）： $$ f'(a) \cdot \delta x \approx f(a + \delta x) - f(a) $$

    第 4 步：把 \(f(a)\) 移过去（小学六年级的移项）¶

    两边同时加上 \(f(a)\)： $$ \boxed{f(a) + f'(a) \cdot \delta x \approx f(a + \delta x)} $$

    为了符合阅读习惯，把左右两边对调一下，就是我们常看到的公式： $$ \boxed{f(a + \delta x) \approx f(a) + f'(a) \cdot \delta x} $$

    第 5 步：为什么还有 \(\delta y\) 那个简写版？¶

    如果你令 \(y = f(x)\)：

    • 高度变化量：\(\delta y = f(a + \delta x) - f(a)\)
    • 导数（坡度）：\(\frac{dy}{dx} = f'(a)\)

    把这两个代入第 3 步的式子 \(f'(a) \cdot \delta x \approx f(a + \delta x) - f(a)\)，直接就得到： $$ \boxed{\delta y \approx \frac{dy}{dx} \cdot \delta x} $$

    第 6 步：灵魂拷问 —— 为什么必须是“约等于”而不是“等于”？（误差从哪来）¶

    我们把推导过程倒过来看，推导中唯一一个“不严格”的地方，是第 2 步把“极限等号”变成了“约等号”。

    • 如果 \(\delta x\) 是无限小（趋近于 0），那么 \(\frac{f(a + \delta x) - f(a)}{\delta x}\) 严格等于 \(f'(a)\)，这时公式是精确的（这就是微积分基本定理）。
    • 但如果 \(\delta x\) 是有限小（比如 0.01），割线斜率不等于切线斜率，会有一点点偏差。这个偏差的大小，大约相当于 \(\delta x\) 的平方级别（比如 0.0001）。因为 \(\delta x\) 很小，平方就更小，所以我们可以忽略它，用约等号。

    终极总结（推导全链条）¶

    \[ \text{导数定义} \xrightarrow{\text{去掉极限变近似}} \text{割线斜率} \approx \text{切线斜率} \xrightarrow[\text{移项}]{\text{乘 }\delta x} \text{近似公式} \]

    你现在看到这个公式，脑子里应该反射出三行字： 1. 这是从导数定义里把极限符号摘掉得来的。 2. 因为用切线代替了割线，所以必须写 \(\approx\)。 3. 误差很小，因为误差里藏着 \((\delta x)^2\)。

    注意：\(\delta y\) 表示 \(y\) 的微小变化量（近似值），\(\frac{dy}{dx}\) 是在起始点处的导数值，要先代 \(x\) 的具体数值，再乘以 \(\delta x\)。

    求的东西 合法公式 说明
    求变化量 \(\delta y\) \(\delta y \approx f'(a) \cdot \delta x\) 最常用（你第四步做的就是这个）
    求新的函数值 \(f(a+\delta x) \approx f(a) + f'(a) \cdot \delta x\) 把变化量加回旧高度
    求步长 \(\delta x\)（倒着考） \(\delta x \approx \frac{\delta y}{f'(a)}\) 把核心公式两边除以 \(f'(a)\)

    1. 逐步实战（多项式篇）

    例题：已知 \(y = x^3 + 2x\)，当 \(x\) 从 \(2\) 增加到 \(2.01\) 时，求 \(y\) 的近似变化量。

    • 第 1 步：确定起始点和增量
      \(a = 2\)，\(\delta x = 0.01\)

    • 第 2 步：求导
      $$ \frac{dy}{dx} = 3x^2 + 2 $$

    • 第 3 步：计算起始点的切线斜率
      代 \(x = 2\)：
      $$ f'(2) = 3(2)^2 + 2 = 14 $$

    • 第 4 步：套公式算近似变化
      $$ \delta y \approx f'(2) \cdot \delta x = 14 \times 0.01 = 0.14 $$

    最终答案：\(y\) 增加了约 \(\boxed{0.14}\)。

    验算（让你放心）：真实值 \(f(2.01) - f(2) = (2.01^3 + 4.02) - (8 + 4) = 12.1206 - 12 = 0.1206\)。近似值 \(0.14\) 很接近（因为 \(\delta x\) 很小）。

    2. 逐步实战（三角函数篇）—— 0606 最爱混合考

    例题：已知 \(y = \sin x\)，\(x\) 以弧度为单位。当 \(x\) 从 \(\frac{\pi}{3}\) 增加到 \(\frac{\pi}{3} + 0.02\) 时，求 \(y\) 的近似变化量。

    • 第 1 步：确定起始点和增量
      \(a = \frac{\pi}{3}\)，\(\delta x = 0.02\)

    • 第 2 步：求导
      $$ \frac{dy}{dx} = \cos x $$

    • 第 3 步：计算起始点的切线斜率
      代 \(x = \frac{\pi}{3}\)：
      $$ f'\left(\frac{\pi}{3}\right) = \cos\left(\frac{\pi}{3}\right) = \frac{1}{2} $$

    • 第 4 步：套公式算近似变化
      $$ \delta y \approx \frac{1}{2} \times 0.02 = 0.01 $$

    最终答案：\(y\) 增加了约 \(\boxed{0.01}\)。

    关键警告：题目里如果 \(x\) 给的是角度制（如 \(30^\circ\)），必须先转换成弧度才能用这个公式，因为微积分导数公式 \(\frac{d}{dx}(\sin x) = \cos x\) 只在弧度制下成立！

    3. 必背的“先代再乘”铁律（防呆版）

    很多同学把公式背成 \(f'(a + \delta x) \cdot \delta x\)，这是致命错误。

    错误写法 正确写法 为什么错？
    \(\delta y \approx f'(a + \delta x) \cdot \delta x\) \(\delta y \approx f'(a) \cdot \delta x\) 斜率应该取起始点 \(a\) 的切线斜率，不是终点 \(a+\delta x\) 的斜率。

    记忆口诀：“先求起点斜率，再乘微小位移。”

    4. 考试题型识别关键词（0606 原题常见措辞）

    当你看到以下任何一句英文，立刻触发“小增量近似”技能：

    • "Find the approximate change in \(y\) ..."
    • "Estimate the increase in \(y\) ..."
    • "Use differentiation to find a small approximation ..."
    • 题目明确给出“微小增量”（small increment）并要求估算，而不是精确计算。

    5. 把“近似”变“精确”的桥梁（进阶理解）

    这个公式的本质是用直线（切线）代替曲线（原函数） ： - 当 \(\delta x \to 0\)（无限趋近于 0）时，约等于号 \(\approx\) 会变成严格的等号，这就是导数的定义。 - 考试只考 \(\delta x\) 是小数（如 \(0.01, -0.02\)）的情况，所以只写 \(\approx\) 和最终小数即可。

    这就是线性近似公式。它告诉我们：对于微小的变化 \(\delta x\)，函数的改变量大约等于导数乘以自变量的改变量。

    用莱布尼茨记号表示：

    \[ \delta y \approx \frac{dy}{dx} \cdot \delta x \]

    其中 \(\delta y = f(x + \delta x) - f(x)\) 是函数值的实际变化量，而 \(\frac{dy}{dx} \cdot \delta x\) 是切线上的变化量（近似值）。

    为什么这成立？ 从几何上看，切线是曲线在该点附近的最佳近似。当 \(\delta x\) 很小时，曲线上的点 \((a+\delta x, f(a+\delta x))\) 非常接近切线上的点 \((a+\delta x, f(a) + f'(a)\delta x)\)，所以可以用切线上的变化来近似曲线上的变化。

    例题 5.7A（相关变化率——圆面积）¶

    一个圆的半径以 \(2\) cm/s 的速率增加。求当半径为 \(5\) cm 时，圆面积的增加速率。

    解：

    设半径为 \(r\)，面积为 \(A\)。已知 \(\frac{dr}{dt} = 2\)，求当 \(r = 5\) 时的 \(\frac{dA}{dt}\)。

    圆面积公式：\(A = \pi r^2\)

    对时间 \(t\) 求导（使用链式法则）：

    \[ \frac{dA}{dt} = \frac{dA}{dr} \cdot \frac{dr}{dt} = 2\pi r \cdot \frac{dr}{dt} \]

    代入已知值：\(r = 5\)，\(\frac{dr}{dt} = 2\)。

    \[ \frac{dA}{dt} = 2\pi \cdot 5 \cdot 2 = 20\pi \text{ cm}^2/\text{s} \]

    所以当半径为 \(5\) cm 时，圆面积以 \(20\pi\) cm²/s 的速率增加。

    例题 5.7B（相关变化率——运动学中的关联）¶

    一个倒圆锥形容器，顶部半径为 \(4\) m，高为 \(8\) m，以 \(2\) m³/min 的速率注水。求当水深为 \(3\) m 时，水面上升的速率。

    解：

    设水深为 \(h\)，水面半径为 \(r\)，水的体积为 \(V\)。已知 \(\frac{dV}{dt} = 2\)，求当 \(h = 3\) 时的 \(\frac{dh}{dt}\)。

    由相似三角形：\(\frac{r}{h} = \frac{4}{8} = \frac{1}{2}\)，所以 \(r = \frac{h}{2}\)。

    圆锥体积公式：

    \[ V = \frac{1}{3}\pi r^2 h = \frac{1}{3}\pi \left(\frac{h}{2}\right)^2 h = \frac{1}{3}\pi \cdot \frac{h^2}{4} \cdot h = \frac{\pi}{12}h^3 \]

    对时间求导：

    \[ \frac{dV}{dt} = \frac{dV}{dh} \cdot \frac{dh}{dt} = \frac{\pi}{12} \cdot 3h^2 \cdot \frac{dh}{dt} = \frac{\pi}{4}h^2 \cdot \frac{dh}{dt} \]

    代入 \(\frac{dV}{dt} = 2\) 和 \(h = 3\)：

    \[ 2 = \frac{\pi}{4} \cdot 3^2 \cdot \frac{dh}{dt} = \frac{9\pi}{4} \cdot \frac{dh}{dt} \]

    解得：

    \[ \frac{dh}{dt} = \frac{2 \cdot 4}{9\pi} = \frac{8}{9\pi} \text{ m/min} \]

    所以水深为 \(3\) m 时，水面以 \(\frac{8}{9\pi}\) m/min 的速率上升。

    例题 5.7C（微小增量近似）¶

    用微分近似计算 \(\sqrt{4.02}\) 的值。

    解：

    设 \(f(x) = \sqrt{x}\)，取 \(a = 4\)（\(4\) 是一个容易计算平方根的数），\(\delta x = 0.02\)。

    \[ f(x) = x^{1/2}，\quad f'(x) = \frac{1}{2}x^{-1/2} = \frac{1}{2\sqrt{x}} \]
    \[ f(4) = \sqrt{4} = 2，\quad f'(4) = \frac{1}{2\sqrt{4}} = \frac{1}{4} \]

    线性近似公式：

    \[ f(4 + 0.02) \approx f(4) + f'(4) \cdot 0.02 \]
    \[ \sqrt{4.02} \approx 2 + \frac{1}{4} \times 0.02 = 2 + 0.005 = 2.005 \]

    与精确值 \(2.004993\ldots\) 相比，近似值 \(2.005\) 的误差非常小（约 \(7 \times 10^{-6}\)）。

    例题 5.7D（微小增量近似——已知误差求最大误差）¶

    球的体积公式为 \(V = \frac{4}{3}\pi r^3\)。如果测量半径时的最大误差为 \(0.1\) cm，当测量半径为 \(5\) cm 时，求计算体积时的最大近似误差。

    解：

    已知 \(r = 5\)，\(|\delta r| \leq 0.1\)。

    \[ \frac{dV}{dr} = 4\pi r^2 \]
    \[ \delta V \approx \frac{dV}{dr} \cdot \delta r = 4\pi r^2 \cdot \delta r \]

    最大误差（取绝对值）：

    \[ |\delta V|_{\max} \approx 4\pi \cdot 5^2 \cdot 0.1 = 4\pi \cdot 25 \cdot 0.1 = 10\pi \text{ cm}^3 \]

    所以体积的最大近似误差约为 \(10\pi \approx 31.4\) cm³。

    7.8 实际最值问题¶

    7.8.1 解题思路¶

    实际最值问题（Practical Maxima and Minima）将微积分应用于现实世界中的优化问题——例如，如何用最少的材料制作一个容器、如何在给定成本下最大化利润、如何确定最快的路径等。

    标准解题步骤：

    1. 理解问题：明确需要最大化或最小化的量是什么（目标函数）。
    2. 建立变量：引入变量，用变量表示所有相关量。
    3. 建立关系：利用题目条件（几何关系、物理约束等），将目标函数表示为一个变量的函数。
    4. 求导找驻点：对目标函数求导，令导数为零，解出驻点。
    5. 判别类型：用一阶或二阶导数法确认是最大值还是最小值。
    6. 检验合理性：验证驻点是否在定义域内，并回答原问题。

    ⚠️ 关键点：实际问题通常有约束条件（如固定总长度、固定面积等），需要用约束条件消去多余变量，将目标函数化为单变量函数。

    例题 5.8A（面积最大化）¶

    用一段长 \(100\) m 的篱笆围成一个矩形花园，一边靠墙（墙足够长），求花园的最大面积及此时的尺寸。

    解：

    设垂直于墙的两边长为 \(x\) m，平行于墙的一边长为 \(y\) m。

    篱笆总长为 \(100\) m，约束条件：\(2x + y = 100\)，即 \(y = 100 - 2x\)。

    花园面积 \(A = x \cdot y = x(100 - 2x) = 100x - 2x^2\)。

    注意定义域：\(x > 0\) 且 \(y > 0\)，即 \(100 - 2x > 0\)，\(x < 50\)，所以 \(0 < x < 50\)。

    求导：

    \[ A'(x) = 100 - 4x \]

    令 \(A'(x) = 0\)：\(100 - 4x = 0\)，解得 \(x = 25\)。

    二阶导数：\(A''(x) = -4 < 0\)，确认 \(x = 25\) 处为最大值。

    此时 \(y = 100 - 2(25) = 50\)。

    最大面积：\(A = 25 \times 50 = 1250\) m²。

    答案：当垂直于墙的边长为 \(25\) m，平行于墙的边长为 \(50\) m 时，最大面积为 \(1250\) m²。

    以下是关于那道“篱笆围花园”最值问题的完整拆解。每一步都写了“怎么算”和“为什么这么算”，没有跳步，也没有“显然”。

    第 1 步：设未知数¶

    怎么算：
    设垂直于墙的两边长为 \(x\) m，平行于墙的一边长为 \(y\) m。

    为什么这样设？

    • 矩形有四条边，但墙代替了一条边，所以实际用篱笆的只有三条边。
    • 在这三条边中，两条是“垂直于墙”的（长度相等，都是 \(x\)），一条是“平行于墙”的（长度是 \(y\)）。
    • 设两个未知数 \(x\) 和 \(y\)，是为了先用它们表示“篱笆总长”，再用它们表示“面积”。这两个是题目要求的最终答案，所以必须用未知数把它们框出来。

    为什么选“垂直于墙的”为 \(x\)，而不是“平行于墙的”？
    因为总长公式是 \(2x + y = 100\)，把“重复出现的那条边”放在系数 2 的位置，方程写起来最自然。如果你设平行于墙的为 \(x\)，方程会变成 \(x + 2y = 100\)，本质一样，但后面面积表达式里系数会变。选哪种都可以，关键是保持一致。

    第 2 步：写出“篱笆总长”的约束条件¶

    怎么算： $$ 2x + y = 100 \quad \Rightarrow \quad y = 100 - 2x $$

    为什么这样写？

    • 篱笆围住了两条垂直于墙的边（每段 \(x\)）和一条平行于墙的边（\(y\)），总长度是 \(2x + y\)。
    • 题目告诉你总长是 \(100\) m，所以 \(2x + y = 100\) 是一个硬约束——它把 \(y\) 和 \(x\) 绑在了一起。
    • 把这个式子改写成 \(y = 100 - 2x\)，是为了把两个未知数“消掉一个”，让面积公式变成只含 \(x\) 的一元函数。只有一元函数才能求导。

    第 3 步：写出面积公式并“消元”¶

    怎么算： $$ A = x \cdot y = x(100 - 2x) = 100x - 2x^2 $$

    为什么这样写？

    • 矩形面积 = 长 × 宽，即 \(x \times y\)。
    • 直接用 \(x \times y\) 有两个未知数，无法求导。所以把第 2 步的 \(y = 100 - 2x\) 代入，得到 \(A(x) = 100x - 2x^2\)。
    • 现在面积 \(A\) 只是 \(x\) 的函数——\(x\) 变了，面积跟着变。我们可以把这个函数画出来，看它什么时候最高。

    第 4 步：确定 \(x\) 的取值范围（定义域）¶

    怎么算： $$ x > 0, \quad y > 0 \quad \Rightarrow \quad x > 0, \quad 100 - 2x > 0 \quad \Rightarrow \quad 0 < x < 50 $$

    为什么必须写这一步？（书上 90% 会跳过）

    • \(x\) 是长度，不能为负数，也不能为 0（否则没有边），所以 \(x > 0\)。
    • \(y\) 也是长度，\(y = 100 - 2x\) 也必须大于 0，所以 \(100 - 2x > 0\)，解得 \(x < 50\)。
    • 定义域决定了“最大值在哪里找”。如果 \(x\) 没有限制，\(A(x) = 100x - 2x^2\) 在 \(x\) 很大时会变成负数（没有实际意义）。定义域把它框在了 \(0\) 到 \(50\) 之间。
    • 在这个区间内，\(x=0\) 或 \(x=50\) 时面积都是 \(0\)（一边长度为 0），所以最大值一定在区间内部。

    第 5 步：求导¶

    怎么算： $$ A'(x) = 100 - 4x $$

    为什么求导？

    • 导数 \(A'(x)\) 在图像上表示函数在某一点的“坡度”（变化率）。
    • 当函数爬到最高点时，切线是水平的，坡度正好为 0。
    • 所以，要找最大值，就去找 “导数为 0 的点”（驻点）。
    • 用幂法则求导：\(100x\) 的导数是 \(100\)，\(-2x^2\) 的导数是 \(-4x\)。

    第 6 步：令导数为 0，解 \(x\)¶

    怎么算： $$ 100 - 4x = 0 \quad \Rightarrow \quad x = 25 $$

    为什么这样做？

    • 导数 \(A'(x) = 100 - 4x\) 代表“面积随 \(x\) 变化的瞬时速度”。
    • 当 \(x < 25\) 时，\(A'(x) > 0\)（例如 \(x=10\) 时，导数为 60），说明面积还在增加。
    • 当 \(x > 25\) 时，\(A'(x) < 0\)（例如 \(x=30\) 时，导数为 \(-20\)），说明面积开始减少。
    • 在 \(x=25\) 这个点，变化率恰好为 0——这是面积从“上升”转为“下降”的转折点，也就是最高点。

    为什么不用“画图”而用“求导”？
    因为这道题的函数是抛物线，你能画出图像。但如果函数是三次、四次、带根号的，你画不出来。导数是普适方法，适用于所有可导函数。

    第 7 步：用二阶导数确认这是“最大值”而非“最小值”¶

    怎么算： $$ A''(x) = -4 < 0 $$

    为什么必须算二阶导数？

    • 令 \(A'(x)=0\) 只能找到“驻点”（坡度为零的点）。但这个点可能是：山顶（最大值）、谷底（最小值），或者是个拐点（坡度水平但不停顿）。
    • 二阶导数 \(A''(x)\) 告诉我们“坡度本身的变化趋势”：
    • \(A''(x) < 0\)：坡度在下降（函数图像向下凸，像倒扣的碗）→ 这里是最大值。
    • \(A''(x) > 0\)：坡度在上升（函数图像向上凸，像碗）→ 这里是最小值。
    • 这道题 \(A''(x) = -4\)，恒小于 0，所以 \(x=25\) 处是最大值。

    如果 \(A''(x)=0\) 怎么办？
    那就要用更高阶导数或检查左右符号来判断。但 0606 里绝大部分题，二阶导数都能明确判断。这道题直接用 \(-4 < 0\) 就够了。

    第 8 步：代回求 \(y\) 和最大面积¶

    怎么算： $$ y = 100 - 2(25) = 50, \quad A_{\max} = 25 \times 50 = 1250 $$

    为什么最后还要这一步？

    • 题目问的是“面积”和“尺寸”，不能只写 \(x=25\)。你需要把另一条边 \(y\) 也算出来。
    • 第 2 步的约束条件 \(y = 100 - 2x\) 就是用来干这个的。
    • 最大面积 \(1250\) 是最终答案，单位是 m²，别忘了写。

    完整答案检查表（考场上对照用）¶

    1. ✅ 设了两个变量（\(x\) 垂直于墙，\(y\) 平行于墙）。
    2. ✅ 写出了总长约束 \(2x + y = 100\)。
    3. ✅ 面积函数化成了只含 \(x\) 的一元函数。
    4. ✅ 写出了定义域 \(0 < x < 50\)。
    5. ✅ 求导 \(A'(x) = 100 - 4x\)。
    6. ✅ 令导数为 0，解出驻点 \(x=25\)。
    7. ✅ 二阶导数 \(A''(x) = -4 < 0\)，确认最大值。
    8. ✅ 代回求 \(y=50\)，算面积 \(1250\)，写出完整答案。

    如果这道题改一下：墙不够长怎么办？¶

    如果墙的长度只有 \(30\) m，那 \(y\) 就不能超过 30。此时定义域变成 \(0 < y \leq 30\)，即 \(0 < 100 - 2x \leq 30\)，解得 \(35 \leq x < 50\)。

    这时候 \(x=25\) 根本不在定义域内，你不能再令导数为 0 去求最大值——因为函数在整个定义域内是单调递减的。最大值发生在定义域的边界，也就是 \(y=30\)（墙的最远端），此时 \(x=35\)，最大面积 \(1050\)。

    例题 5.8B（体积最大化——无盖盒子）¶

    从一张 \(30\) cm \(\times\) \(20\) cm 的矩形纸板的四个角各剪去一个边长为 \(x\) cm 的小正方形，然后折起四周做成一个无盖盒子。求 \(x\) 为多少时盒子的体积最大，并求最大体积。

    解：

    剪去边长为 \(x\) 的正方形后，盒子的底面尺寸为 \((30 - 2x) \times (20 - 2x)\)，高为 \(x\)。

    盒子体积：

    \[ V(x) = x(30 - 2x)(20 - 2x) = x(600 - 60x - 40x + 4x^2) = x(600 - 100x + 4x^2) \]
    \[ V(x) = 4x^3 - 100x^2 + 600x \]

    定义域：\(x > 0\)，\(30 - 2x > 0 \Rightarrow x < 15\)，\(20 - 2x > 0 \Rightarrow x < 10\)，所以 \(0 < x < 10\)。

    求导：

    \[ V'(x) = 12x^2 - 200x + 600 \]

    令 \(V'(x) = 0\)：

    \[ 12x^2 - 200x + 600 = 0 \]

    两边除以 \(4\)：\(3x^2 - 50x + 150 = 0\)

    用求根公式：

    \[ x = \frac{50 \pm \sqrt{2500 - 1800}}{6} = \frac{50 \pm \sqrt{700}}{6} = \frac{50 \pm 10\sqrt{7}}{6} \]

    两个解：\(x_1 = \frac{50 + 10\sqrt{7}}{6} \approx \frac{50 + 26.46}{6} \approx 12.74\)（超出定义域 \(x < 10\)，舍去）

    \[ x_2 = \frac{50 - 10\sqrt{7}}{6} \approx \frac{50 - 26.46}{6} \approx 3.92 \]

    所以 \(x = \frac{50 - 10\sqrt{7}}{6} \approx 3.92\) cm。

    用二阶导数验证：\(V''(x) = 24x - 200\)

    \[ V''(3.92) = 24(3.92) - 200 \approx 94.08 - 200 = -105.92 < 0 \]

    确认是最大值。

    最大体积：

    \[ V = 3.92 \times (30 - 7.84) \times (20 - 7.84) = 3.92 \times 22.16 \times 12.16 \approx 1056.3 \text{ cm}^3 \]

    答案：当剪去的小正方形边长约为 \(3.92\) cm 时，盒子体积最大，约为 \(1056\) cm³。

    例题 5.8C（成本最小化）¶

    某公司需要制造一个开口圆柱形水桶，容积固定为 \(V = 1000\pi\) cm³。桶底材料价格为 \(2\) 元/cm²，侧面材料价格为 \(1\) 元/cm²。求水桶的底面半径 \(r\) 和高 \(h\) 为何值时，总成本最小？最小成本是多少？

    解：

    设底面半径为 \(r\) cm，高为 \(h\) cm。

    容积约束：\(V = \pi r^2 h = 1000\pi\)，所以 \(h = \frac{1000}{r^2}\)。

    成本：底面积 \(\pi r^2\)，价格 \(2\) 元/cm²；侧面积 \(2\pi r h\)，价格 \(1\) 元/cm²。

    \[ C = 2 \cdot \pi r^2 + 1 \cdot 2\pi r h = 2\pi r^2 + 2\pi r \cdot \frac{1000}{r^2} = 2\pi r^2 + \frac{2000\pi}{r} \]

    定义域：\(r > 0\)。

    求导：

    \[ C'(r) = 4\pi r - \frac{2000\pi}{r^2} \]

    令 \(C'(r) = 0\)：

    \[ 4\pi r - \frac{2000\pi}{r^2} = 0 \quad \Rightarrow \quad 4\pi r = \frac{2000\pi}{r^2} \]

    两边除以 \(\pi\)（\(\pi > 0\)）：

    \[ 4r = \frac{2000}{r^2} \quad \Rightarrow \quad 4r^3 = 2000 \quad \Rightarrow \quad r^3 = 500 \]

    解得：\(r = \sqrt[3]{500} = \sqrt[3]{5 \times 100} = 5\sqrt[3]{4}\) cm。

    此时 \(h = \frac{1000}{r^2} = \frac{1000}{500^{2/3}} = 2 \cdot 500^{1/3} = 2r\)。

    所以 \(h = 2r\)，即高等于底面直径时成本最小。

    用二阶导数验证：

    \[ C''(r) = 4\pi + \frac{4000\pi}{r^3} \]

    代入 \(r^3 = 500\)：\(C''(r) = 4\pi + \frac{4000\pi}{500} = 4\pi + 8\pi = 12\pi > 0\)，确认是最小值。

    最小成本：

    \[ C_{\min} = 6\pi \cdot 500^{2/3} \text{ 元} \]

    近似计算：\(500^{2/3} = (500^{1/3})^2 \approx (7.937)^2 \approx 63\)，所以 \(C_{\min} \approx 6\pi \times 63 \approx 1188\) 元。

    答案：当底面半径 \(r = \sqrt[3]{500}\) cm（约 \(7.94\) cm），高 \(h = 2r\)（约 \(15.88\) cm）时，最小成本约为 \(1188\) 元。

    例题 5.8D（利润最大化）¶

    某工厂生产一种产品，每天生产 \(x\) 件的成本为 \(C(x) = 200 + 10x + 0.01x^2\) 元，售价为每件 \(30\) 元。求每天生产多少件时利润最大，最大利润是多少？

    解：

    收入：\(R(x) = 30x\)

    利润：\(P(x) = R(x) - C(x) = 30x - (200 + 10x + 0.01x^2) = -0.01x^2 + 20x - 200\)

    定义域：\(x \ge 0\) 且为整数（实际中为正整数，但我们可以用连续函数近似求最大值，再取整）。

    求导：

    \[ P'(x) = -0.02x + 20 \]

    令 \(P'(x) = 0\)：\(-0.02x + 20 = 0\)，解得 \(x = 1000\)。

    二阶导数：\(P''(x) = -0.02 < 0\)，确认是最大值。

    最大利润：

    \[ P(1000) = -0.01(1000)^2 + 20(1000) - 200 = -10000 + 20000 - 200 = 9800 \text{ 元} \]

    答案：每天生产 \(1000\) 件时利润最大，最大利润为 \(9800\) 元。

    1. \(f(x) = x^3\)，\(f'(x) = 3x^2\)，\(f'(2) = 12\)
    2. 切线：\(y - 8 = 12(x - 2)\)，即 \(y = 12x - 16\)

    3. 法线：\(y - 8 = -\frac{1}{12}(x - 2)\)，即 \(y = -\frac{1}{12}x + \frac{49}{6}\)

    4. \(f(x) = e^x\)，\(f'(x) = e^x\)，\(f'(0) = 1\)

    5. 切线：\(y - 1 = 1(x - 0)\)，即 \(y = x + 1\)

    6. \(f(x) = \sqrt{x}\)，\(f'(x) = \frac{1}{2\sqrt{x}}\)，\(f'(4) = \frac{1}{4}\)

    7. 切线：\(y - 2 = \frac{1}{4}(x - 4)\)，即 \(y = \frac{1}{4}x + 1\)

    8. 法线：\(y - 2 = -4(x - 4)\)，即 \(y = -4x + 18\)

    9. 设切点为 \((a, a^2 - 2a)\)，\(f'(a) = 2a - 2\)。 切线方程：\(y - (a^2 - 2a) = (2a - 2)(x - a)\) 代入 \((1, -4)\)：\(-4 - (a^2 - 2a) = (2a - 2)(1 - a)\) 化简：\(-4 - a^2 + 2a = (2a-2)(1-a) = 2a-2 - 2a^2 + 2a = -2a^2 + 4a - 2\) 整理：\(-4 - a^2 + 2a = -2a^2 + 4a - 2\)，移项：\(a^2 - 2a - 2 = 0\) 解得 \(a = 1 \pm \sqrt{3}\)

    10. \(a = 1 + \sqrt{3}\)：斜率 \(m = 2\sqrt{3}\)，切线 \(y = 2\sqrt{3}x - 2\sqrt{3} - 4\)
    11. \(a = 1 - \sqrt{3}\)：斜率 \(m = -2\sqrt{3}\)，切线 \(y = -2\sqrt{3}x + 2\sqrt{3} - 4\)

    7.6 驻点¶

    1. \(f'(x) = 3x^2 - 12x + 9 = 3(x-1)(x-3)\) \(x = 1\)：\(f(1) = 5\)，\(f''(1) = 6-12 = -6 < 0\) → 极大值 \(x = 3\)：\(f(3) = 1\)，\(f''(3) = 18-12 = 6 > 0\) → 极小值

    2. \(f'(x) = 2xe^x + x^2e^x = xe^x(2 + x)\) \(x = 0\)：\(f(0) = 0\)，\(f''(0) = 2 > 0\) → 极小值 \(x = -2\)：\(f(-2) = 4e^{-2}\)，\(f''(-2) = -2e^{-2} < 0\) → 极大值

    3. \(f'(x) = 3x^2 + a\)，\(f'(1) = 3 + a = 0\) → \(a = -3\) \(f(1) = 1 + (-3)(1) + b = 4\) → \(b = 6\)

    4. \(f'(x) = 6x^2 - 6x - 12 = 6(x^2 - x - 2) = 6(x-2)(x+1)\) \(x = -1\)：\(f(-1) = -2 - 3 + 12 + 5 = 12\)，\(f''(-1) = -12 - 6 = -18 < 0\) → 极大值 \(12\) \(x = 2\)：\(f(2) = 16 - 12 - 24 + 5 = -15\)，\(f''(2) = 24 - 6 = 18 > 0\) → 极小值 \(-15\)

    7.7 相关变化率与微小增量近似¶

    1. \(A = s^2\)，\(\frac{dA}{dt} = 2s\frac{ds}{dt} = 2(10)(3) = 60\) cm²/s

    2. \(f(x) = x^{1/3}\)，\(f'(x) = \frac{1}{3}x^{-2/3}\)，取 \(a = 8\)，\(\delta x = 0.03\) \(f(8) = 2\)，\(f'(8) = \frac{1}{3}(8)^{-2/3} = \frac{1}{3}\cdot\frac{1}{4} = \frac{1}{12}\) \(\sqrt[3]{8.03} \approx 2 + \frac{1}{12} \times 0.03 = 2 + 0.0025 = 2.0025\)

    3. \(V = \frac{4}{3}\pi r^3\)，\(\frac{dV}{dt} = 4\pi r^2\frac{dr}{dt}\) \(16\pi = 4\pi(2)^2\frac{dr}{dt} = 16\pi\frac{dr}{dt}\) → \(\frac{dr}{dt} = 1\) m/s

    7.8 实际最值问题¶

    1. 设长为 \(x\)，宽为 \(y\)，\(2x + 2y = 120\)，\(y = 60 - x\) \(A = xy = x(60-x) = 60x - x^2\) \(A'(x) = 60 - 2x = 0\) → \(x = 30\)，\(y = 30\) \(A''(x) = -2 < 0\) → 最大值 最大面积 \(= 30 \times 30 = 900\) m²

    2. \(d^2 = x^2 + (x^2 - 4x + 5)^2\) 设 \(g(x) = d^2\)，求导找最小值。 或者：到原点的最短距离即原点到抛物线的最短距离，可用求导法。

    更简单的方法：设 \(h(x) = x^2 + (x^2-4x+5)^2\) \(h'(x) = 2x + 2(x^2-4x+5)(2x-4)\) \(= 2x + 2(x^2-4x+5)(2)(x-2)\) \(= 2x + 4(x^2-4x+5)(x-2)\)

    令 \(h'(x) = 0\)，可解得 \(x = 2\)。 \(d^2 = 2^2 + (4-8+5)^2 = 4 + 1 = 5\)，\(d = \sqrt{5}\)

    1. 表面积 \(S = \pi r^2 + 2\pi rh\)，体积 \(V = \pi r^2 h\)（常数），\(h = \frac{V}{\pi r^2}\) \(S = \pi r^2 + 2\pi r\left(\frac{V}{\pi r^2}\right) = \pi r^2 + \frac{2V}{r}\) \(S'(r) = 2\pi r - \frac{2V}{r^2} = 0\) → \(2\pi r = \frac{2V}{r^2}\) → \(\pi r^3 = V\) → \(r^3 = \frac{V}{\pi}\) 而 \(V = \pi r^2 h\)，所以 \(\pi r^3 = \pi r^2 h\) → \(r = h\) 答案：\(r : h = 1 : 1\)，即底面半径等于高时表面积最小。
