    5.1 函数的基础概念¶

    5.1.1 什么是函数？¶

    函数是一种特殊的对应关系：它将定义域中的每一个输入值 \(x\)，对应到恰好一个输出值 \(y = f(x)\)。我们称 \(y\) 是 \(x\) 的像（image）。

    \[ f: D \to \mathbb{R}, \quad x \mapsto f(x) \]

    其中 \(D\) 是定义域，值域（range / image set）是所有可能的输出值 \(f(x)\) 的集合。

    函数必须满足的条件：对于定义域中的每个 \(x\)，必须有且仅有一个 \(y\) 与之对应。这是函数的垂直检验线法则——任何竖直线与函数图形最多相交一次。

    如何解释一个关系式是否为函数（考纲 1.1）：

    对于定义域中的每一个 \(x\) 值，关系式只给出唯一的一个 \(y\) 值。

    • \(y = x^2\) 是函数：每个 \(x\) 对应唯一一个 \(y\)。
    • \(x = y^2\) 不是函数：例如 \(x=4\) 时，\(y\) 可以是 \(2\) 或 \(-2\)，一个 \(x\) 对应两个 \(y\)。
    • \(y = \pm\sqrt{x}\) 不是函数：每个正 \(x\) 对应两个 \(y\) 值。

    5.1.2 单射（一对一）与多对一¶

    • 单射（one–one function / injective）：定义域中不同的 \(x\) 对应不同的 \(y\)。即：若 \(x_1 \neq x_2\)，则 \(f(x_1) \neq f(x_2)\)。检验方法——水平检验线法则：任何水平线与图形最多相交一次。

    • 多对一（many–one function）：不同的 \(x\) 可以对应同一个 \(y\)。例如 \(f(x) = x^2\)，\(f(2) = f(-2) = 4\)。水平检验线 \(y=4\) 与图形相交于两点。

    ⚠️ 只有单射函数才有反函数。这是因为反函数需要将每个输出值唯一地映射回输入值——如果原函数是多对一的，那么反函数将是一对多，不满足函数的定义。

    5.1.3 函数记号¶

    IGCSE 0606 中使用的函数记号包括：

    • \(f(x)\)：最常见的记号，如 \(f(x) = 2e^x\)
    • \(f: x \mapsto\)：映射记号，如 \(f: x \mapsto \lg x\)，表示"\(f\) 将 \(x\) 映射到 \(\lg x\)"
    • \(f^{-1}(x)\)：反函数记号
    • \(fg(x)\)：复合函数记号，\(fg(x) = f(g(x))\)
    • \(f^2(x)\)：表示 \(f(f(x))\)，即 \(f\) 复合自身

    ⚠️ 重要：记号 \(f^2(x)\) 不适用于三角函数。例如 \(\sin^2 x\) 表示 \((\sin x)^2\)，而不是 \(\sin(\sin x)\)。

    📌 两种记号的对比：\(f(x)\) vs \(f: x \mapsto\)

    记号 例子 含义 侧重点
    \(f(x) = \lg x\) \(f(x) = \lg x\) 定义函数 \(f\) 的对应规则 结果——给定 \(x\)，算出 \(\lg x\)
    \(f: x \mapsto \lg x\) \(f: x \mapsto \lg x\) \(f\) 将 \(x\) 映射到 \(\lg x\) 过程——强调从输入到输出的映射方向

    两种写法表达的是同一个函数，但视角不同： - \(f(x) = \lg x\) 更侧重于代数关系——\(f\) 是一个规则，输入 \(x\) 得到 \(\lg x\) - \(f: x \mapsto \lg x\) 更侧重于映射关系——从 \(x\) "出发"，经过 \(f\) 的作用 "到达" \(\lg x\)

    理解要点：

    • 箭头 \(\mapsto\) 读作"映射到"（maps to），与集合论中的箭头 \(\to\) 不同——\(\to\) 表示集合之间的映射关系（\(f: D \to \mathbb{R}\)），而 \(\mapsto\) 表示具体元素之间的对应关系
    • 有时也写作 \(x \xmapsto{f} f(x)\)，更直观地显示 \(x\) 被 \(f\) 作用后变成 \(f(x)\)
    • 在 IGCSE 0606 考试中，两种写法都接受，但 \(f(x)\) 更常用

    5.1.4 定义域与值域的求法¶

    求定义域时需要考虑的限制因素：

    1. 分母不为零：\(f(x) = \dfrac{1}{g(x)} \Rightarrow g(x) \neq 0\)
    2. 偶次根号内非负：\(f(x) = \sqrt{g(x)} \Rightarrow g(x) \geq 0\)
    3. 对数的真数为正：\(f(x) = \log_a(g(x)) \Rightarrow g(x) > 0\)

    值域的求法：

    方法一——配方法（适用于二次函数）： 将 \(f(x) = ax^2 + bx + c\) 写成 \(a(x-h)^2 + k\) 的形式。 - 若 \(a > 0\)，最小值为 \(k\)，值域为 \([k, \infty)\) - 若 \(a < 0\)，最大值为 \(k\)，值域为 \((-\infty, k]\)

    方法二——观察法（适用于单调函数）： 如果函数在定义域上单调递增或递减，值域就是两端函数值的区间。

    方法三——反函数法： 若函数有反函数，原函数的值域等于反函数的定义域。

    例题 4.1（定义域与值域）¶

    例 1（基础型——根号与分母）：求 \(f(x) = \sqrt{x-2} + \dfrac{1}{x-3}\) 的定义域。

    解：

    这个函数由两部分组成：\(\sqrt{x-2}\)（根号部分）和 \(\dfrac{1}{x-3}\)（分式部分）。定义域必须同时满足所有部分的限制条件。

    第一步（根号条件——偶次根号内非负）：

    \[ x-2 \geq 0 \quad\Rightarrow\quad x \geq 2 \]

    根号下的表达式必须为非负数，否则在实数范围内无意义。

    第二步（分母条件——分母不为零）：

    \[ x-3 \neq 0 \quad\Rightarrow\quad x \neq 3 \]

    分式的分母不能为零，否则分式无意义。

    第三步（取交集——数轴图示法）：

    将两个条件在数轴上表示出来：

    条件1（根号）：      ●━━━━━━━━━━━━>
条件2（分母）：           ×
                    2    3
交集：              ●━━○━━━━━━━━>
                    2    3

    图例说明： - ● 表示包含该点（端点可取） - ○ 表示不包含该点（端点不可取） - × 表示该点被排除 - ━━━> 表示区间延伸方向

    从数轴可以看出： - \(x \geq 2\) 给出区间 \([2, \infty)\) - \(x \neq 3\) 排除点 \(x = 3\) - 两条件的交集是 \(x \in [2, 3) \cup (3, \infty)\)

    为什么要用并集 \(\cup\)？

    因为 \(x = 3\) 被排除后，原来的连续区间 \([2, \infty)\) 被分成了两段：\([2, 3)\) 和 \((3, \infty)\)，需要将这两段合并起来。

    关于区间端点的细节：

    区间 含义 为什么左端用 \([\) / \((\) ? 为什么右端用 \(]\) / \()\) ?
    \([2, 3)\) \(2 \leq x < 3\) \(x=2\) 可取 ✅：\(\sqrt{2-2}=0\) 有意义，且分母 \(2-3=-1\neq0\) \(x=3\) 不可取 ❌：分母 \(3-3=0\) 无意义，所以 3 不能包含在内，用 )
    \((3, \infty)\) \(x > 3\) \(x=3\) 不可取 ❌：理由同上，所以 3 不能包含在内，用 ( 无穷大不是具体数值，无法取到，所以 \(\infty\) 永远用 )

    快速判断口诀：遇到被排除的点（如 \(x=3\)），靠近它的那一侧用圆括号 \((\) 或 \()\)——因为它"被挖掉了"，不包含在区间内。

    \(\cup\)（并集）符号的使用：

    这段推导展示了如何用集合运算来表达定义域：

    \[ [2, \infty) \setminus \{3\} = [2, 3) \cup (3, \infty) \]

    逐符号解释：

    符号 含义 在本式中的意思
    \([2, \infty)\) 从 2 到无穷大的区间 根号条件 \(x \geq 2\) 给出的范围
    \(\setminus\) 集合差（set difference），读作"减去" 从 \([2, \infty)\) 中移除某些元素
    \(\{3\}\) 只包含数字 3 的集合 分母条件 \(x \neq 3\) 排除的点
    \(=\) 两边表示同一个集合 左右两种写法描述的是同一个定义域
    \(\cup\) 并集（union），将两段合并 把被 3 分开的两段区间拼接起来
    \([2, 3)\) 从 2（含）到 3（不含） 第一段：\(2 \leq x < 3\)
    \((3, \infty)\) 从 3（不含）到无穷大 第二段：\(x > 3\)

    翻译成文字：

    \[ \underbrace{[2, \infty)}_{\text{根号条件}} \;\underbrace{\setminus}_{\text{去掉}} \;\underbrace{\{3\}}_{\text{分母排除的点}} \;=\; \underbrace{[2, 3) \cup (3, \infty)}_{\text{两段拼接}} \]

    "从 \(x \geq 2\) 的范围内挖掉 \(x = 3\) 这个点，剩下的就是两段不相连的区间——\(2\) 到 \(3\)（不含 3）和 \(3\) 以上。"

    常见错误提醒： - ❌ 写成 \([2, \infty)\) —— 忽略了 \(x=3\) 处无定义 - ❌ 写成 \([2, 3) \cap (3, \infty)\) —— 交集 \(\cap\) 取公共部分，这里两段不重叠，交集为空 - ✅ 正确写法是 \([2, 3) \cup (3, \infty)\) —— 并集 \(\cup\) 将两段合并

    最终答案：

    \[ \boxed{[2, 3) \cup (3, \infty)} \]

    验证： - 取 \(x = 2\)：\(\sqrt{0} + \dfrac{1}{-1} = 0 - 1 = -1\)，有意义 ✓ - 取 \(x = 3\)：分母 \(3-3 = 0\)，无意义 ✗ - 取 \(x = 5\)：\(\sqrt{3} + \dfrac{1}{2}\)，有意义 ✓

    例 2（复合型——分离常数求值域）：函数 \(f(x) = \dfrac{2x+1}{x-1}\)，\(x \neq 1\)。

    （i）求值域； （ii）判断 \(f\) 是否为单射。

    解：

    （i）分离常数：将分子改写成与分母相关的形式。

    \[ f(x) = \frac{2x+1}{x-1} = \frac{2(x-1) + 3}{x-1} \]

    这一步的思路：分母是 \(x-1\)，我们希望分子中也出现 \(x-1\) 以便约分。将 \(2x\) 写成 \(2(x-1) + 2\)，再加上原分子中的 \(1\)，得到 \(2(x-1) + 3\)。

    继续化简：

    \[ f(x) = \frac{2(x-1)}{x-1} + \frac{3}{x-1} = 2 + \frac{3}{x-1} \]

    因为 \(\dfrac{3}{x-1} \neq 0\) 对一切 \(x \neq 1\) 成立，所以 \(f(x)\) 永远取不到 \(2\)。

    值域为 \(\mathbb{R} \setminus \{2\}\)。

    （ii）判断单射：设 \(f(a) = f(b)\)，则：

    \[ 2 + \frac{3}{a-1} = 2 + \frac{3}{b-1} \]

    两边减去 \(2\)：

    \[ \frac{3}{a-1} = \frac{3}{b-1} \]

    两边取倒数再乘以 \(3\)：

    \[ a-1 = b-1 \Rightarrow a = b \]

    因此 \(f\) 是单射。从图形上看，\(y = 2 + \dfrac{3}{x-1}\) 是反比例函数经过平移后的结果，每条水平线（除 \(y=2\) 外）恰好相交一次。

    例 3（半圆型值域）：已知 \(f(x) = \sqrt{4 - x^2}\)。

    （i）求定义域和值域； （ii）判断 \(f\) 是否有反函数。

    解：

    （i）定义域：\(4 - x^2 \geq 0 \Rightarrow x^2 \leq 4 \Rightarrow -2 \leq x \leq 2\)。定义域为 \([-2, 2]\)。

    值域：令 \(y = \sqrt{4 - x^2}\)，则 \(y \geq 0\) 且 \(y^2 = 4 - x^2\)，即 \(x^2 + y^2 = 4\)（\(y \geq 0\)）。

    这是一个圆心在原点、半径为 \(2\) 的上半圆。\(y\) 的最小值出现在 \(x = \pm 2\) 时，\(y = 0\)；最大值出现在 \(x = 0\) 时，\(y = 2\)。因此值域为 \([0, 2]\)。

    （ii）\(f\) 不是单射，因为例如 \(f(-1) = f(1) = \sqrt{3}\)。水平检验线 \(y = \sqrt{3}\) 与上半圆相交于 \((\pm 1, \sqrt{3})\) 两点。因此 \(f\) 没有反函数。

    但如果将定义域限制为 \(x \in [0, 2]\)，则 \(f\) 变为单射，此时反函数为 \(f^{-1}(x) = \sqrt{4 - x^2}\)（定义域 \([0, 2]\)）。

    例 4（对数与分式复合型定义域）：求 \(f(x) = \ln(3x - 6) + \dfrac{1}{\sqrt{8 - 2x}}\) 的定义域。

    解：

    条件 1（对数真数大于零）：\(3x - 6 > 0 \Rightarrow x > 2\)。

    条件 2（分母根号内大于零——因为分母不能为零且根号在分母中）：\(8 - 2x > 0 \Rightarrow x < 4\)。

    取交集：\(x > 2\) 且 \(x < 4\)，即 \((2, 4)\)。

    例 5（判断关系式是否为函数——考纲 1.1 要求）：判断下列关系式是否为函数，并解释原因。

    （i）\(y = \pm \sqrt{x}\)，\(x \geq 0\) （ii）\(y = x^3 - 2x + 1\) （iii）\(x^2 + y^2 = 25\)

    解：

    （i）不是函数。对于同一个 \(x\)（例如 \(x=4\)），关系式给出两个 \(y\) 值：\(y = 2\) 和 \(y = -2\)。这违反了函数每个输入对应唯一输出的定义。垂直检验线 \(x=4\) 与图形相交于两点。

    （ii）是函数。对于每一个实数 \(x\)，\(x^3 - 2x + 1\) 恰好计算出一个实数 \(y\)。垂直检验线在任何 \(x\) 处都只与图形相交一次。

    （iii）不是函数。例如 \(x=0\) 时，\(y^2 = 25 \Rightarrow y = \pm 5\)，一个 \(x\) 对应两个 \(y\)。垂直检验线 \(x=0\) 与圆相交于 \((0,5)\) 和 \((0,-5)\) 两点。

    5.2 线性函数与三次函数¶

    5.2.1 线性函数 \(f(x) = mx + c\)¶

    线性函数是最简单的函数类型。它的图形是一条直线。

    斜率 \(m\) 的几何意义：\(x\) 每增加 \(1\) 个单位，\(y\) 增加 \(m\) 个单位。如果 \(m > 0\)，直线向右上方倾斜；\(m < 0\)，向右下方倾斜；\(m = 0\)，水平直线。

    截距 \(c\)：直线与 \(y\) 轴的交点纵坐标，即 \(f(0)\) 的值。

    变化率特征：线性函数的变化率是常数——无论在哪一点上，瞬时变化率都等于 \(m\)。这是线性函数区别于其他函数的最重要特性。

    由两点 \((x_1, y_1)\) 和 \((x_2, y_2)\) 求斜率：

    \[ m = \frac{y_2 - y_1}{x_2 - x_1} \]

    这个公式的推导思路：两点之间的垂直变化是 \(y_2 - y_1\)，水平变化是 \(x_2 - x_1\)，斜率就是"升程除以行程"。

    点斜式方程：过点 \((x_0, y_0)\) 且斜率为 \(m\) 的直线方程为：

    \[ y - y_0 = m(x - x_0) \]

    5.2.2 三次函数 \(f(x) = ax^3 + bx^2 + cx + d\)（\(a \neq 0\)）¶

    三次函数的图形呈 S 形（或反 S 形）。它的导数 \(f'(x) = 3ax^2 + 2bx + c\) 是一个二次函数，可能有两个零点（对应局部极值点），也可能只有一个或没有实数零点。

    三次函数的两种基本形态：

    1. 三个线性因式乘积形式：\(f(x) = a(x - p)(x - q)(x - r)\)，与 \(x\) 轴交于 \(x = p, q, r\)。
    2. 一个线性因式与一个二次因式的乘积：\(f(x) = (x - p)(Ax^2 + Bx + C)\)，可能只有一个实根。

    END BEHAVIOR 末端行为： - 若 \(a > 0\)：当 \(x \to -\infty\) 时 \(f(x) \to -\infty\)；当 \(x \to \infty\) 时 \(f(x) \to \infty\)。 - 若 \(a < 0\)：当 \(x \to -\infty\) 时 \(f(x) \to \infty\)；当 \(x \to \infty\) 时 \(f(x) \to -\infty\)。

    例题 4.2（线性与三次函数）¶

    例 1（线性函数参数求解）：已知直线 \(L\) 经过点 \(A(2, 5)\) 和 \(B(4, 11)\)。

    （i）求 \(L\) 的方程； （ii）求 \(L\) 与 \(x\) 轴和 \(y\) 轴的交点。

    解：

    （i）求斜率：

    \[ m = \frac{11 - 5}{4 - 2} = \frac{6}{2} = 3 \]

    写方程：使用点斜式，取 \(A(2, 5)\) 作为已知点：

    \[ y - 5 = 3(x - 2) \]

    化简：

    \[ y - 5 = 3x - 6 \Rightarrow y = 3x - 1 \]

    （ii）\(y\) 截距：令 \(x = 0\)，得 \(y = 3(0) - 1 = -1\)，即 \((0, -1)\)。

    \(x\) 截距：令 \(y = 0\)，得 \(0 = 3x - 1 \Rightarrow x = \dfrac{1}{3}\)，即 \(\left(\dfrac{1}{3}, 0\right)\)。

    例 2（三次函数图形与极值）：已知 \(f(x) = x^3 - 3x^2 + 2\)。

    （i）求 \(f'(x)\) 并解 \(f'(x) = 0\)； （ii）判断驻点的类型； （iii）求 \(f\) 与坐标轴的交点。

    解：

    （i）求导：

    \[ f'(x) = \frac{d}{dx}(x^3) - \frac{d}{dx}(3x^2) + \frac{d}{dx}(2) = 3x^2 - 6x \]

    因式分解：\(f'(x) = 3x(x - 2)\)。

    令 \(f'(x) = 0\)，得 \(3x(x-2) = 0\)，即 \(x = 0\) 或 \(x = 2\)。

    （ii）用一阶导数符号检验每个驻点附近的单调性变化：

    在 \(x = 0\) 处： - 取 \(x = -1\)（左侧）：\(f'(-1) = 3(-1)(-3) = 9 > 0\)，递增 - 取 \(x = 1\)（右侧）：\(f'(1) = 3(1)(-1) = -3 < 0\)，递减 - 从左到右：递增 → 递减 → 局部最大值。\(f(0) = 2\)。

    在 \(x = 2\) 处： - 取 \(x = 1\)（左侧）：\(f'(1) = -3 < 0\)，递减 - 取 \(x = 3\)（右侧）：\(f'(3) = 3(3)(1) = 9 > 0\)，递增 - 从左到右：递减 → 递增 → 局部最小值。\(f(2) = 8 - 12 + 2 = -2\)。

    （iii）\(y\) 截距：\(f(0) = 2\)，即 \((0, 2)\)。

    \(x\) 截距：解 \(x^3 - 3x^2 + 2 = 0\)。

    尝试有理根。检验 \(x = 1\)：\(f(1) = 1 - 3 + 2 = 0\)，所以 \(x-1\) 是因子。

    用综合除法分解：

    \[ \begin{array}{c|ccc} 1 & 1 & -3 & 0 & 2 \\ & & 1 & -2 & -2 \\ \hline & 1 & -2 & -2 & 0 \end{array} \]

    商为 \(x^2 - 2x - 2\)。用二次公式求根：

    \[ x = \frac{2 \pm \sqrt{4 - 4(1)(-2)}}{2(1)} = \frac{2 \pm \sqrt{4 + 8}}{2} = \frac{2 \pm \sqrt{12}}{2} = \frac{2 \pm 2\sqrt{3}}{2} = 1 \pm \sqrt{3} \]

    三个 \(x\) 截距：\(x = 1\)，\(x = 1 + \sqrt{3}\)，\(x = 1 - \sqrt{3}\)。

    例 3（三次函数的符号分析与不等式）：已知 \(f(x) = (x+2)(x-1)(x-3)\)。

    （i）求 \(f(x) = 0\) 的解； （ii）解 \(f(x) > 0\)； （iii）画出 \(y = f(x)\) 的草图。

    解：

    （i）三个线性因子分别等于零：\(x = -2\)，\(x = 1\)，\(x = 3\)。

    （ii）将实轴按三个零点分为四个区间。在每个区间内取一个测试点，判断每个因子的符号，三个因子符号的乘积即为 \(f(x)\) 的符号：

    区间 测试点 \((x+2)\) \((x-1)\) \((x-3)\) 乘积符号
    \(x < -2\) \(x = -3\) \(-1\)（负） \(-4\)（负） \(-6\)（负） 负×负×负 = 负
    \(-2 < x < 1\) \(x = 0\) \(2\)（正） \(-1\)（负） \(-3\)（负） 正×负×负 = 正
    \(1 < x < 3\) \(x = 2\) \(4\)（正） \(1\)（正） \(-1\)（负） 正×正×负 = 负
    \(x > 3\) \(x = 4\) \(6\)（正） \(3\)（正） \(1\)（正） 正×正×正 = 正

    因此 \(f(x) > 0\) 的解为 \(-2 < x < 1\) 或 \(x > 3\)。

    （iii）草图要点： - \(x\) 截距：\((-2, 0)\)，\((1, 0)\)，\((3, 0)\) - \(y\) 截距：\(f(0) = (2)(-1)(-3) = 6\) - 端部行为：\(a = 1 > 0\)，所以 \(x \to -\infty\) 时 \(f \to -\infty\)，\(x \to \infty\) 时 \(f \to \infty\) - 图形在三个零点之间依次穿越 \(x\) 轴

    例 4（因式定理与三次函数分解）：已知 \(f(x) = x^3 + kx^2 - 4x - 4\) 能被 \(x+1\) 整除，求 \(k\) 的值，并完全因式分解 \(f(x)\)。

    解：

    第一步（应用因式定理）：如果 \(x+1\) 是因子，则 \(f(-1) = 0\)。

    \[ f(-1) = (-1)^3 + k(-1)^2 - 4(-1) - 4 = -1 + k + 4 - 4 = k - 1 \]

    令 \(f(-1) = 0\)，得 \(k - 1 = 0 \Rightarrow k = 1\)。

    第二步（综合除法分解）：\(f(x) = x^3 + x^2 - 4x - 4\)。

    除以 \((x+1)\)：

    \[ \begin{array}{c|ccc} -1 & 1 & 1 & -4 & -4 \\ & & -1 & 0 & 4 \\ \hline & 1 & 0 & -4 & 0 \end{array} \]

    商为 \(x^2 - 4 = (x-2)(x+2)\)。

    第三步（写出完全因式分解）：

    \[ f(x) = (x+1)(x-2)(x+2) \]

    5.3 指数函数与对数函数¶

    前置知识：如果你对指数运算（如 \(2^3 = 8\)）和对数（如 \(\log_2 8 = 3\)）已基本熟悉，可以直接进入 §4.3.1。如果你是第一次接触，下面的内容可以帮助你建立直观理解。

    指数和对数就像一对"反义词"——一个是问"结果是多少"，另一个是问"用了多少次"。

    🔢 指数——重复乘法

    指数运算 \(a^n\) 就是"把 \(a\) 自乘 \(n\) 次"：

    \[ 2^3 = 2 \times 2 \times 2 = 8 \]

    这里的 \(a\) 叫底数（base），\(n\) 叫指数（exponent），结果 \(8\) 叫幂（power）。

    指数增长的一个经典例子：一张纸对折 1 次变 2 层，对折 2 次变 4 层，对折 \(x\) 次后层数为 \(2^x\)。这就是为什么指数增长如此惊人——对折 10 次就超过了 1000 层。

    🔄 对数——指数的"反向操作"

    对数回答的是："要把底数 \(a\) 乘多少次才能得到 \(x\)？"

    \[ \log_2 8 = 3 \quad\Longleftrightarrow\quad 2^3 = 8 \]

    读作："以 \(2\) 为底 \(8\) 的对数是 \(3\)"，意思是"\(2\) 需要乘 \(3\) 次才得到 \(8\)"。

    指数形式 对数形式 读法
    \(2^3 = 8\) \(\log_2 8 = 3\) 以 2 为底 8 的对数是 3
    \(10^2 = 100\) \(\log_{10} 100 = 2\) 以 10 为底 100 的对数是 2
    \(e^1 = e\) \(\ln e = 1\) 自然对数，\(e\) 的对数是 1

    关键理解：指数和对数是互逆运算——就像加法和减法、乘法和除法一样。

    \[ \underbrace{2^3 = 8}_{\text{指数：已知底和指数，求幂}} \quad \Longleftrightarrow \quad \underbrace{\log_2 8 = 3}_{\text{对数：已知底和幂，求指数}} \]

    📊 为什么它们如此重要？

    指数函数描述的是"增长越来越快"的过程： - 细菌繁殖（每 20 分钟翻一番） - 复利计算（利息产生利息） - 放射性衰变（物质随时间减少）

    对数函数则将这种爆炸式增长"压缩"成可读的尺度： - 地震的里氏震级（\(\log\) 尺度） - 声音的分贝（\(\log\) 尺度） - pH 值（\(\log\) 尺度）

    🗺️ 本节学习路径

    指数函数 $a^x$         对数函数 $\log_a x$
   ↓                        ↑
   ├── 基本性质 ──────────┤ 互为反函数
   ├── 自然底数 $e$        └── 运算法则（积、商、幂、换底）
   └── 图像与渐近线             └── 解指数方程 $a^x = b$

    5.3.1 指数函数 \(f(x) = a^x\)（\(a > 0\)，\(a \neq 1\)）¶

    指数函数的核心特征是：函数值的增长（或衰减）速度与函数本身的大小成正比。

    图形性质（以 \(a > 1\) 为例）： - 定义域：\(\mathbb{R}\)（全体实数） - 值域：\((0, \infty)\)（永远取正值） - 恒过点 \((0, 1)\)，因为 \(a^0 = 1\) - 当 \(a > 1\) 时，函数严格递增；当 \(0 < a < 1\) 时，函数严格递减 - 水平渐近线：\(y = 0\)（\(x\) 轴）。当 \(a > 1\) 时，\(x \to -\infty\) 时趋近于 \(y=0\)；当 \(0 < a < 1\) 时，\(x \to \infty\) 时趋近于 \(y=0\)。

    更一般的形式：\(y = k e^{nx} + a\) - 水平渐近线为 \(y = a\) - \(k\) 控制垂直拉伸和方向（\(k > 0\) 时图形在渐近线上方，\(k < 0\) 时在下方） - y-intercept = k+a

    为什么 \(e\) 如此重要？

    \[ \frac{d}{dx}e^x = e^x \]

    \(e^x\) 是唯一导数等于自身的函数。如果用一般底数 \(a\)：

    \[ \frac{d}{dx}a^x = a^x \ln a \]

    当 \(a = e\) 时，\(\ln e = 1\)，导数简化为 \(e^x\) 自身。

    5.3.2 自然指数函数 \(e^x\) 的详细推导¶

    问题：是否存在一个数 \(e\)，使得 \(e^x\) 的导数等于 \(e^x\)？

    从一般指数函数 \(f(x) = a^x\) 出发。根据导数定义：

    \[ f'(x) = \lim_{h \to 0} \frac{a^{x+h} - a^x}{h} \]

    第一步：提取公因子 \(a^x\)：

    \[ f'(x) = \lim_{h \to 0} \frac{a^x(a^h - 1)}{h} = a^x \cdot \lim_{h \to 0} \frac{a^h - 1}{h} \]

    第二步：记 \(L(a) = \displaystyle\lim_{h \to 0} \frac{a^h - 1}{h}\)。这个极限依赖于 \(a\)。于是：

    \[ f'(x) = a^x \cdot L(a) = f(x) \cdot L(a) \]

    第三步：我们希望 \(L(a) = 1\)，这样 \(f'(x) = f(x)\)。数值求解 \(L(a) = 1\)：

    \(a\) \(L(a) \approx \dfrac{a^{0.001} - 1}{0.001}\)
    \(2\) \(\approx 0.693\)
    \(2.7\) \(\approx 0.993\)
    \(2.71\) \(\approx 0.996\)
    \(2.718\) \(\approx 0.999\)
    \(2.71828\) \(\approx 1.000\)

    这个特殊的数就是 \(e \approx 2.71828\)，它也可以定义为极限：

    \[ e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n \]

    数值验证： - \(n = 1\)：\((1+1)^1 = 2\) - \(n = 10\)：\((1.1)^{10} \approx 2.594\) - \(n = 100\)：\((1.01)^{100} \approx 2.705\) - \(n = 10000\)：\((1.0001)^{10000} \approx 2.718\)

    5.3.3 对数函数 \(f(x) = \log_a x\)（\(a > 0\)，\(a \neq 1\)）¶

    对数函数是指数函数的反函数：

    \[ y = \log_a x \iff a^y = x \quad (x > 0) \]

    图形性质（以 \(a > 1\) 为例）： - 定义域：\((0, \infty)\)（真数必须为正） - 值域：\(\mathbb{R}\) - 恒过点 \((1, 0)\)，因为 \(\log_a 1 = 0\) - 当 \(a > 1\) 时，函数严格递增；当 \(0 < a < 1\) 时，函数严格递减 - 垂直渐近线：\(x = 0\)（\(y\) 轴）。当 \(a > 1\) 时，\(x \to 0^+\) 时 \(\log_a x \to -\infty\)

    更一般的形式：\(y = k \ln(ax + b)\) - 垂直渐近线在 \(ax + b = 0\) 处，即 \(x = -\dfrac{b}{a}\) - 定义域为 \(x > -\dfrac{b}{a}\)

    两个重要的特殊底数： - 常用对数（以 \(10\) 为底）：\(\log_{10} x\)，有时记作 \(\lg x\) - 自然对数（以 \(e\) 为底）：\(\log_e x\)，记作 \(\ln x\)

    指数函数与对数函数互为反函数：

    \[ y = a^x \quad \stackrel{\text{反函数}}{\longleftrightarrow} \quad y = \log_a x \]

    对称性推导： 假设点 \((p, q)\) 在 \(y = a^x\) 上，则 \(q = a^p\)。 由对数定义，\(p = \log_a q\)，所以点 \((q, p)\) 在 \(y = \log_a x\) 上。 点 \((p, q)\) 关于直线 \(y = x\) 的对称点正是 \((q, p)\)（因为交换坐标）。 因此两个函数的图形关于 \(y = x\) 对称。

    5.3.4 对数运算法则的详细推导¶

    对数法则的本质：将对数运算降级——乘法变为加法，除法变为减法，指数变为系数。

    法则 1——积的对数：\(\log_a (MN) = \log_a M + \log_a N\)

    推导： 设 \(\log_a M = x\)，\(\log_a N = y\)。 由对数定义：\(a^x = M\)，\(a^y = N\)。 那么 \(MN = a^x \cdot a^y = a^{x+y}\)。 再由对数定义：\(\log_a (MN) = x + y = \log_a M + \log_a N\)。\(\square\)

    法则 2——商的对数：\(\log_a \left(\dfrac{M}{N}\right) = \log_a M - \log_a N\)

    推导： 设 \(\log_a M = x\)，\(\log_a N = y\)。 则 \(\dfrac{M}{N} = \dfrac{a^x}{a^y} = a^{x-y}\)。 因此 \(\log_a \left(\dfrac{M}{N}\right) = x - y = \log_a M - \log_a N\)。\(\square\)

    法则 3——幂的对数：\(\log_a (M^k) = k \log_a M\)

    推导： 设 \(\log_a M = x\)，则 \(a^x = M\)。 于是 \(M^k = (a^x)^k = a^{kx}\)。 由定义：\(\log_a (M^k) = kx = k \log_a M\)。\(\square\)

    法则 4——换底公式：\(\log_a M = \dfrac{\log_b M}{\log_b a}\)

    推导： 设 \(y = \log_a M\)，则 \(a^y = M\)。 两边取以 \(b\) 为底的对数： \(\log_b (a^y) = \log_b M\) \(y \log_b a = \log_b M\) \(y = \dfrac{\log_b M}{\log_b a}\) 因此 \(\log_a M = \dfrac{\log_b M}{\log_b a}\)。\(\square\)

    换底公式最常见的两种应用形式：

    \[ \log_a M = \frac{\log M}{\log a} \quad \text{（换为常用对数）}, \qquad \log_a M = \frac{\ln M}{\ln a} \quad \text{（换为自然对数）} \]

    逆恒等式（直接来自反函数定义）：

    \[ a^{\log_a x} = x \quad (x > 0), \qquad \log_a (a^x) = x \quad (x \in \mathbb{R}) \]

    5.3.5 解指数方程 \(a^x = b\)¶

    基本方法：两边取对数，利用幂法则将对数中的指数"降"为系数。

    \[ a^x = b \quad \Rightarrow \quad \ln(a^x) = \ln b \quad \Rightarrow \quad x \ln a = \ln b \quad \Rightarrow \quad x = \frac{\ln b}{\ln a} \]

    也可以用常用对数：\(x = \dfrac{\log b}{\log a}\)。

    ⚠️ 注意：只有当 \(b > 0\) 时方程才有实数解。若 \(b \leq 0\)，方程 \(a^x = b\) 无实数解（因为指数函数的值域为 \((0, \infty)\)）。

    例题 4.3（指数与对数函数）¶

    例 1（对数化简与求值）：化简 \(\log_2 24 - \log_2 3 + \log_2 \dfrac{1}{2}\)。

    解：

    第一步（用商法则合并前两项）：

    \[ \log_2 24 - \log_2 3 = \log_2 \frac{24}{3} = \log_2 8 \]

    第二步（用积法则继续合并）：

    \[ \log_2 8 + \log_2 \frac{1}{2} = \log_2 \left(8 \times \frac{1}{2}\right) = \log_2 4 \]

    第三步（求值）：\(\log_2 4 = 2\)，因为 \(2^2 = 4\)。

    所以表达式的值为 \(2\)。

    例 2（换底公式与对数方程）：

    （i）用自然对数表示 \(\log_5 20\) 并化简； （ii）解方程 \(\log_2 (x+1) + \log_2 (x-1) = 3\)。

    解：

    （i）用换底公式：

    \[ \log_5 20 = \frac{\ln 20}{\ln 5} \]

    分解 \(20 = 4 \times 5\)，所以 \(\ln 20 = \ln(4 \times 5) = \ln 4 + \ln 5 = \ln(2^2) + \ln 5 = 2\ln 2 + \ln 5\)。

    因此：

    \[ \log_5 20 = \frac{2\ln 2 + \ln 5}{\ln 5} = \frac{2\ln 2}{\ln 5} + 1 \]

    （ii）第一步（合并对数）：

    \[ \log_2[(x+1)(x-1)] = 3 \Rightarrow \log_2(x^2 - 1) = 3 \]

    第二步（去对数）：两边取以 \(2\) 为底的指数：

    \[ x^2 - 1 = 2^3 = 8 \]

    第三步（解二次方程）：

    \[ x^2 = 9 \Rightarrow x = \pm 3 \]

    第四步（检查定义域）：对数的真数必须为正。

    \(x+1 > 0 \Rightarrow x > -1\)，\(x-1 > 0 \Rightarrow x > 1\)。取交集得 \(x > 1\)。

    \(x = 3 > 1\)，有效。\(x = -3\) 不满足 \(x > 1\)，舍去。

    因此 \(x = 3\)。

    例 3（解指数方程与指数—对数复合）：

    （i）解 \(3^{2x-1} = 7\)，结果用自然对数表示； （ii）已知 \(f(x) = \ln(e^{2x} + 1)\)，求 \(f(0)\)。

    解：

    （i）两边取自然对数：

    \[ \ln(3^{2x-1}) = \ln 7 \]

    用幂法则将对数中的指数"降"下来：

    \[ (2x - 1)\ln 3 = \ln 7 \]

    解出 \(x\)：

    \[ 2x - 1 = \frac{\ln 7}{\ln 3} \Rightarrow 2x = 1 + \frac{\ln 7}{\ln 3} \Rightarrow x = \frac{1}{2}\left(1 + \frac{\ln 7}{\ln 3}\right) \]

    （ii）代入 \(x = 0\)：

    \[ f(0) = \ln(e^{0} + 1) = \ln(1 + 1) = \ln 2 \]

    例 4（指数方程——代换法）：解方程 \(4^x - 5 \cdot 2^x + 4 = 0\)。

    解：

    第一步（识别结构）：注意到 \(4^x = (2^2)^x = 2^{2x} = (2^x)^2\)。

    第二步（换元）：令 \(u = 2^x\)，注意 \(u > 0\)（因为指数函数的值域为正）。

    方程化为：

    \[ u^2 - 5u + 4 = 0 \]

    第三步（解二次方程）：

    \[ (u-1)(u-4) = 0 \Rightarrow u = 1 \text{ 或 } u = 4 \]

    第四步（回代）：

    • \(2^x = 1 \Rightarrow x = \log_2 1 = 0\)
    • \(2^x = 4 \Rightarrow x = \log_2 4 = 2\)

    两个解都满足定义域，所以 \(x = 0\) 或 \(x = 2\)。

    例 5（对数方程——换底后化为一元二次）：解方程 \(\log_3 x + \log_x 3 = 2\)。

    解：

    第一步（换底）：用换底公式将 \(\log_x 3\) 转换为以 \(3\) 为底：

    \[ \log_x 3 = \frac{\log_3 3}{\log_3 x} = \frac{1}{\log_3 x} \]

    第二步（换元）：设 \(u = \log_3 x\)（注意 \(x > 0\) 且 \(x \neq 1\)，否则 \(\log_x 3\) 无定义）。

    方程化为：

    \[ u + \frac{1}{u} = 2 \]

    第三步（去分母）：两边乘以 \(u\)（\(u \neq 0\)）：

    \[ u^2 + 1 = 2u \Rightarrow u^2 - 2u + 1 = 0 \Rightarrow (u-1)^2 = 0 \]

    第四步（回代）：\(u = 1 \Rightarrow \log_3 x = 1 \Rightarrow x = 3^1 = 3\)。

    验证：\(\log_3 3 = 1\)，\(\log_3 3 = 1\)，\(1 + 1 = 2\)。\(\checkmark\)

    例 6（指数不等式——两边取对数）：解不等式 \(2^x < 5\)。

    解：

    两边取自然对数。因为 \(\ln\) 是递增函数，不等号方向不变：

    \[ \ln(2^x) < \ln 5 \]

    用幂法则：

    \[ x \ln 2 < \ln 5 \]

    因为 \(\ln 2 > 0\)，两边除以 \(\ln 2\) 不等号方向不变：

    \[ x < \frac{\ln 5}{\ln 2} \]

    所以解为 \(x < \dfrac{\ln 5}{\ln 2}\)（约为 \(x < 2.322\)）。

    ⚠️ 注意：如果底数 \(a\) 满足 \(0 < a < 1\)，取对数时不等号会反转（因为 \(\ln a < 0\)）。例如解 \(\left(\dfrac12\right)^x < 3\) 时：

    \(x\ln\frac12 < \ln 3\)，因为 \(\ln\frac12 < 0\)，两边除以它得到 \(x > \dfrac{\ln 3}{\ln(1/2)}\)。

    例 7（用已知对数表示未知对数）：已知 \(\log_a 2 = p\)，\(\log_a 5 = q\)。用 \(p\) 和 \(q\) 表示：

    （i）\(\log_a 20\)； （ii）\(\log_a 0.4\)。

    解：

    （i）\(20 = 2^2 \times 5\)，所以：

    \[ \log_a 20 = \log_a (2^2 \times 5) = \log_a 2^2 + \log_a 5 = 2\log_a 2 + \log_a 5 = 2p + q \]

    （ii）\(0.4 = \dfrac{2}{5}\)，所以：

    \[ \log_a 0.4 = \log_a \frac{2}{5} = \log_a 2 - \log_a 5 = p - q \]

    例 8（指数函数图形的渐近线与变换——考纲 6.1）：函数 \(f(x) = 3e^{2x} - 4\)。

    （i）求 \(f(x)\) 的水平渐近线； （ii）求 \(f(x)\) 与坐标轴的交点； （iii）描述 \(f\) 的定义域和值域。

    解：

    （i）当 \(x \to -\infty\) 时，\(e^{2x} \to 0\)，所以 \(3e^{2x} - 4 \to -4\)。

    因此水平渐近线为 \(y = -4\)。

    （ii）\(y\) 截距：令 \(x = 0\)，\(f(0) = 3e^{0} - 4 = 3 - 4 = -1\)，即 \((0, -1)\)。

    \(x\) 截距：令 \(f(x) = 0\)：

    \[ 3e^{2x} - 4 = 0 \Rightarrow e^{2x} = \frac{4}{3} \]

    两边取自然对数：\(2x = \ln\frac{4}{3} \Rightarrow x = \dfrac12\ln\frac{4}{3}\)。

    \(x\) 截距为 \(\left(\dfrac12\ln\frac{4}{3}, 0\right)\)。

    （iii）定义域：\(\mathbb{R}\)（全体实数）。

    值域：因为 \(e^{2x} > 0\) 对所有实数 \(x\) 成立，所以 \(3e^{2x} > 0\)，\(3e^{2x} - 4 > -4\)。值域为 \((-4, \infty)\)。

    例 9（对数函数图形的渐近线——考纲 6.1）：函数 \(g(x) = 2\ln(x-1) + 3\)。

    （i）求 \(g(x)\) 的定义域和垂直渐近线； （ii）求 \(g(x)\) 与坐标轴的交点。

    解：

    （i）定义域：真数必须为正，\(x-1 > 0 \Rightarrow x > 1\)。定义域为 \((1, \infty)\)。

    垂直渐近线：真数为零处 \(x-1 = 0 \Rightarrow x = 1\)。当 \(x \to 1^+\) 时，\(\ln(x-1) \to -\infty\)，\(g(x) \to -\infty\)。

    因此垂直渐近线方程为 \(x = 1\)。

    （ii）\(y\) 截距：\(x = 0\) 不在定义域内，所以没有 \(y\) 截距。

    \(x\) 截距：令 \(g(x) = 0\)：

    \[ 2\ln(x-1) + 3 = 0 \Rightarrow \ln(x-1) = -\frac{3}{2} \]

    两边取指数：\(x - 1 = e^{-3/2} \Rightarrow x = 1 + e^{-3/2}\)。

    \(x\) 截距为 \((1 + e^{-3/2}, 0)\)（约为 \((1.223, 0)\)）。

    5.4 反函数与复合函数¶

    5.4.1 反函数¶

    定义：若函数 \(f\) 是单射（一一对应），则存在反函数 \(f^{-1}\)，满足：

    \[ f^{-1}(y) = x \iff f(x) = y \]

    核心性质：

    \[ f^{-1}(f(x)) = x, \qquad f(f^{-1}(x)) = x \]

    几何意义：\(y = f(x)\) 与 \(y = f^{-1}(x)\) 的图形关于直线 \(y = x\) 对称。

    对称性的详细推导：

    设点 \((a, b)\) 在 \(y = f(x)\) 上，即 \(b = f(a)\)。 由反函数定义，\(a = f^{-1}(b)\)，所以点 \((b, a)\) 在 \(y = f^{-1}(x)\) 上。 点 \((a, b)\) 关于直线 \(y = x\) 的对称点正是 \((b, a)\)（因为交换坐标）。 因此 \(f\) 和 \(f^{-1}\) 的图形互为关于 \(y = x\) 的镜像。

    举例：对于 \(f(x) = 2^x\) 和 \(f^{-1}(x) = \log_2 x\)： - \(f\) 过 \((0, 1)\)，\((1, 2)\)，\((2, 4)\) - \(f^{-1}\) 过 \((1, 0)\)，\((2, 1)\)，\((4, 2)\) - 每一对点关于 \(y = x\) 对称

    为什么只有单射函数才有反函数？

    如果 \(f\) 不是单射（即存在 \(x_1 \neq x_2\) 使得 \(f(x_1) = f(x_2) = y_0\)），那么反函数 \(f^{-1}\) 在 \(x = y_0\) 处需要返回两个不同的值——\(x_1\) 和 \(x_2\)——这违反了函数的定义。因此非单射函数没有反函数。

    如何用文字解释函数没有反函数（考纲 1.5 标准表述）：

    "函数 \(f\) 不是单射（one–one），因为存在不同的 \(x\) 值对应同一个 \(y\) 值。例如 \(f(a) = f(b)\) 但 \(a \neq b\)。水平检验线 \(y = f(a)\) 与 \(y = f(x)\) 的图形相交于多于一个点。因此 \(f\) 没有反函数。"

    求反函数的步骤： 1. 将 \(y = f(x)\) 写成等式。 2. 解出 \(x\)，用 \(y\) 表示。 3. 交换 \(x\) 和 \(y\) 的角色，得到 \(y = f^{-1}(x)\) 的表达式。 4. 注明反函数的定义域（即原函数的值域）。

    原函数与反函数定义域和值域的关系： - \(f\) 的定义域 = \(f^{-1}\) 的值域 - \(f\) 的值域 = \(f^{-1}\) 的定义域

    ⚠️ 关键：有时原函数的定义域需要被限制（restrict）才能使 \(f\) 成为单射，从而存在反函数。例如 \(f(x) = x^2\) 在整个 \(\mathbb{R}\) 上不是单射，但限制为 \(x \geq 0\) 后，变为单射，反函数为 \(\sqrt{x}\)。

    5.4.2 复合函数¶

    定义：\((f \circ g)(x) = f(g(x))\)，读作"\(f\) 复合 \(g\)"，也写作 \(fg(x)\)。

    复合顺序：先应用 \(g\)，再将 \(f\) 应用于结果。顺序通常不可交换——一般 \(f(g(x)) \neq g(f(x))\)。

    复合函数的定义域：需要满足两个条件： 1. \(x\) 在 \(g\) 的定义域内 2. \(g(x)\) 在 \(f\) 的定义域内

    重要关系（考纲 1.2）：

    \[ \text{Domain}(gf) \subseteq \text{Domain}(f), \qquad \text{Range}(gf) \subseteq \text{Range}(g) \]

    解释：要计算 \(gf(x) = g(f(x))\)，首先 \(x\) 必须在 \(f\) 的定义域内，且 \(f(x)\) 必须在 \(g\) 的定义域内。因此 \(gf\) 的定义域是 \(f\) 的定义域的子集。\(gf\) 的输出来自 \(g\)，所以其值域是 \(g\) 的值域的子集。

    定义域限制使复合函数存在的进一步说明：

    有时 \(f\) 的定义域需要被限制，才能使 \(gf\) 存在。这是因为 \(f(x)\) 必须落在 \(g\) 的定义域内。

    示例：已知 \(f(x) = x^2\)（定义域 \(\mathbb{R}\)），\(g(x) = \sqrt{1 - x^2}\)（定义域 \(|x| \leq 1\)）。

    \(gf(x) = g(f(x)) = \sqrt{1 - (x^2)^2} = \sqrt{1 - x^4}\)。

    \(gf\) 的定义域要求 \(1 - x^4 \geq 0 \Rightarrow |x| \leq 1\)。

    所以 \(\text{Domain}(gf) = [-1, 1] \subset \mathbb{R} = \text{Domain}(f)\)。

    例题 4.4（反函数与复合函数）¶

    例 1（求反函数——线性函数）：求 \(f(x) = \dfrac{2x - 3}{5}\) 的反函数。

    解：

    第一步（写等式）：\(y = \dfrac{2x - 3}{5}\)

    第二步（解出 \(x\)）：

    \[ 5y = 2x - 3 \Rightarrow 2x = 5y + 3 \Rightarrow x = \frac{5y + 3}{2} \]

    第三步（交换 \(x\) 和 \(y\)）：

    \[ f^{-1}(x) = \frac{5x + 3}{2} \]

    第四步（定义域）：反函数的定义域为 \(\mathbb{R}\)（原函数的值域为 \(\mathbb{R}\)）。

    验证：

    \[ f(f^{-1}(x)) = f\left(\frac{5x+3}{2}\right) = \frac{2\cdot\frac{5x+3}{2} - 3}{5} = \frac{5x+3-3}{5} = x \]

    例 2（求反函数——含定义域限制）：已知 \(f(x) = x^2 - 4x + 3\)，\(x \geq 2\)。求 \(f^{-1}(x)\) 及其定义域。

    解：

    第一步（配方法找顶点和值域）：

    \[ f(x) = x^2 - 4x + 3 = (x^2 - 4x + 4) - 4 + 3 = (x-2)^2 - 1 \]

    顶点在 \((2, -1)\)。因为 \(a = 1 > 0\)，且定义域为 \(x \geq 2\)（在顶点右侧），函数单调递增。值域为 \([-1, \infty)\)。

    第二步（解出 \(x\)）：令 \(y = (x-2)^2 - 1\)。

    \[ y + 1 = (x-2)^2 \Rightarrow x - 2 = \pm \sqrt{y+1} \]

    因为 \(x \geq 2\)，取正号：\(x = 2 + \sqrt{y+1}\)。

    第三步（交换 \(x\) 和 \(y\)）：

    \[ f^{-1}(x) = 2 + \sqrt{x+1} \]

    第四步（定义域）：反函数的定义域是原函数的值域，即 \([-1, \infty)\)。

    验证：

    \[ f(f^{-1}(x)) = f(2 + \sqrt{x+1}) = (2+\sqrt{x+1} - 2)^2 - 1 = (x+1) - 1 = x \]

    例 3（复合函数及其定义域——详细推导）：已知 \(f(x) = \sqrt{x-1}\)，\(g(x) = \dfrac{1}{x-2}\)。

    （i）求 \(fg(x)\) 及其定义域； （ii）求 \(gf(x)\) 及其定义域。

    解：

    （i）\(fg(x) = f(g(x)) = \sqrt{\dfrac{1}{x-2} - 1}\)

    定义域分析：

    条件 1：\(g(x)\) 有定义。分母不为零：\(x \neq 2\)。

    条件 2：\(g(x)\) 必须落在 \(f\) 的定义域内。\(f\) 的定义域为 \(\sqrt{\text{内}} \geq 0\)，即：

    \[ \frac{1}{x-2} - 1 \geq 0 \]

    解这个不等式。这是关键步骤，分情况讨论：

    情况 A：\(x > 2\)。两边乘以正数 \((x-2)\)，不等号不变：

    \[ 1 \geq x - 2 \Rightarrow x \leq 3 \]

    结合 \(x > 2\)，得 \(2 < x \leq 3\)。

    情况 B：\(x < 2\)。两边乘以负数 \((x-2)\)，不等号反转：

    \[ 1 \leq x - 2 \Rightarrow x \geq 3 \]

    结合 \(x < 2\)，无解。

    因此条件 2 给出 \(2 < x \leq 3\)。

    取交集：\(x \neq 2\) 且 \(2 < x \leq 3\)，定义域为 \((2, 3]\)。

    化简表达式：

    \[ \frac{1}{x-2} - 1 = \frac{1 - (x-2)}{x-2} = \frac{3 - x}{x-2} \]

    因此：

    \[ fg(x) = \sqrt{\frac{3 - x}{x - 2}}, \quad x \in (2, 3] \]

    （ii）\(gf(x) = g(f(x)) = \dfrac{1}{\sqrt{x-1} - 2}\)

    定义域分析：

    条件 1：\(f(x)\) 有定义。根号内非负：\(x - 1 \geq 0 \Rightarrow x \geq 1\)。

    条件 2：\(f(x)\) 必须落在 \(g\) 的定义域内。\(g\) 的分母不能为零：\(\sqrt{x-1} - 2 \neq 0\)。

    \[ \sqrt{x-1} \neq 2 \Rightarrow x-1 \neq 4 \Rightarrow x \neq 5 \]

    取交集：\(x \geq 1\) 且 \(x \neq 5\)，定义域为 \([1, 5) \cup (5, \infty)\)。

    例 4（复合函数的值域与 \(fg \neq gf\)）：\(f(x) = 2^x\)，\(g(x) = x^2\)。求 \(fg(x)\) 和 \(gf(x)\) 的表达式，并求 \(fg(x)\) 的值域。

    解：

    \(fg(x)\)：\(fg(x) = f(g(x)) = 2^{x^2}\)

    \(gf(x)\)：\(gf(x) = g(f(x)) = (2^x)^2 = 2^{2x} = 4^x\)

    注意 \(fg(x) = 2^{x^2} \neq 4^x = gf(x)\)，说明复合顺序重要。

    求 \(fg(x)\) 的值域： - \(g(x) = x^2\) 的值域为 \([0, \infty)\) - \(f(u) = 2^u\) 在 \([0, \infty)\) 上单调递增 - 最小值：\(u = 0\) 时 \(2^0 = 1\) - 上界：\(u \to \infty\) 时 \(2^u \to \infty\)

    因此 \(fg(x)\) 的值域为 \([1, \infty)\)。

    例 5（用文字解释函数为何没有反函数——考纲 1.5）：

    （i）\(f(x) = x^2\)，定义域 \(\mathbb{R}\)。 （ii）\(f(x) = \cos x\)，定义域 \([0, 2\pi]\)。

    解：

    （i）\(f(x) = x^2\) 不是单射，因为存在不同的 \(x\) 值对应同一个 \(y\) 值。例如 \(f(2) = 4\) 且 \(f(-2) = 4\)，即 \(2 \neq -2\) 但 \(f(2) = f(-2)\)。水平检验线 \(y = 4\) 与 \(y = x^2\) 的图形相交于 \((2, 4)\) 和 \((-2, 4)\) 两点。因此 \(f\) 没有反函数。

    但若将定义域限制为 \(x \geq 0\)，则 \(f\) 变为单射，反函数为 \(f^{-1}(x) = \sqrt{x}\)。

    （ii）\(f(x) = \cos x\) 在 \([0, 2\pi]\) 上不是单射。例如 \(\cos(\frac{\pi}{3}) = \frac12\) 且 \(\cos(\frac{5\pi}{3}) = \frac12\)，但 \(\frac{\pi}{3} \neq \frac{5\pi}{3}\)。水平检验线 \(y = \frac12\) 与图形相交于两点。因此 \(f\) 没有反函数。

    但若将定义域限制为 \([0, \pi]\)，\(\cos x\) 严格递减，此时反函数为 \(\arccos x\)。

    例 6（草图表示函数与其反函数关于 \(y=x\) 对称——考纲 1.8）：已知 \(f(x) = e^x\)。

    （i）求 \(f^{-1}(x)\)； （ii）描述 \(y = f(x)\)，\(y = f^{-1}(x)\) 和 \(y = x\) 在同一坐标系中的关系。

    解：

    （i）\(y = e^x \Rightarrow x = \ln y \Rightarrow f^{-1}(x) = \ln x\)（定义域 \(x > 0\)）。

    （ii）对称关系：\(y = e^x\) 和 \(y = \ln x\) 的图形关于直线 \(y = x\) 对称。

    具体对应点： - \(e^x\) 过 \((0, 1)\) → \(\ln x\) 过 \((1, 0)\) - \(e^x\) 过 \((1, e)\) → \(\ln x\) 过 \((e, 1)\) - \(e^x\) 过 \((-1, e^{-1})\) → \(\ln x\) 过 \((e^{-1}, -1)\)

    每条曲线都是另一条在 \(y = x\) 中的镜像。

    渐近线关系： - \(y = e^x\) 有水平渐近线 \(y = 0\)（\(x\) 轴） - \(y = \ln x\) 有垂直渐近线 \(x = 0\)（\(y\) 轴） - 这一对渐近线也关于 \(y = x\) 对称

    例 7（复合函数的顺序重要性 \(fg \neq gf\)——考纲 1.7）：\(f(x) = 3x + 1\)，\(g(x) = x^2\)。求 \(fg(x)\) 和 \(gf(x)\)，并比较。

    解：

    \(fg(x) = f(g(x)) = f(x^2) = 3x^2 + 1\)

    \(gf(x) = g(f(x)) = g(3x+1) = (3x+1)^2 = 9x^2 + 6x + 1\)

    显然 \(fg(x) \neq gf(x)\)，因此复合函数的顺序至关重要。

    例 8（反函数与复合的综合应用）：已知 \(f(x) = 2x + 3\)，\(g(x) = \dfrac{1}{x-1}\)，\(x \neq 1\)。

    （i）求 \(f^{-1}(x)\)； （ii）求 \(gf^{-1}(x)\) 及其定义域。

    解：

    （i）\(y = 2x + 3 \Rightarrow 2x = y - 3 \Rightarrow x = \dfrac{y-3}{2}\) 交换得 \(f^{-1}(x) = \dfrac{x-3}{2}\)，定义域 \(\mathbb{R}\)。

    （ii）\(gf^{-1}(x) = g\left(\dfrac{x-3}{2}\right) = \dfrac{1}{\dfrac{x-3}{2} - 1}\)

    化简分母：\(\dfrac{x-3}{2} - 1 = \dfrac{x-3 - 2}{2} = \dfrac{x-5}{2}\)

    因此：

    \[ gf^{-1}(x) = \frac{1}{\frac{x-5}{2}} = \frac{2}{x-5} \]

    定义域： - \(f^{-1}(x)\) 的定义域为 \(\mathbb{R}\)（无限制） - \(g\) 的定义域要求分母不为零：\(\dfrac{x-3}{2} - 1 \neq 0 \Rightarrow \dfrac{x-5}{2} \neq 0 \Rightarrow x \neq 5\)

    因此定义域为 \(\mathbb{R} \setminus \{5\}\)。

    例 9（考纲 1.6 指定示例——指数函数的反函数）：已知 \(f(x) = e^{2x}\)，求 \(f^{-1}(x)\)。

    解：

    令 \(y = e^{2x}\)。两边取自然对数：

    \[ \ln y = \ln(e^{2x}) = 2x \cdot \ln e = 2x \]

    因为 \(\ln e = 1\)，所以 \(2x = \ln y \Rightarrow x = \frac12\ln y\)。

    交换 \(x\) 和 \(y\)：

    \[ f^{-1}(x) = \frac12\ln x \]

    定义域：原函数 \(f(x) = e^{2x}\) 的值域为 \((0, \infty)\)，所以 \(f^{-1}\) 的定义域为 \((0, \infty)\)。

    验证：

    \[ f(f^{-1}(x)) = e^{2 \cdot \frac12\ln x} = e^{\ln x} = x \quad (x > 0) \]

    例 10（验证 \(\text{Domain}(gf) \subseteq \text{Domain}(f)\)——考纲 1.2）：\(f(x) = \sqrt{x}\)，\(g(x) = \dfrac{1}{x-3}\)。求 \(gf(x)\) 的定义域，并验证 \(\text{Domain}(gf) \subseteq \text{Domain}(f)\)。

    解：

    \(gf(x) = g(f(x)) = \dfrac{1}{\sqrt{x} - 3}\)

    条件 1：\(f\) 的定义域：\(x \geq 0\)。 条件 2：\(f(x)\) 在 \(g\) 的定义域内：\(\sqrt{x} - 3 \neq 0 \Rightarrow \sqrt{x} \neq 3 \Rightarrow x \neq 9\)。

    取交集：\(x \geq 0\) 且 \(x \neq 9\)，即 \([0, 9) \cup (9, \infty)\)。

    验证 \(\text{Domain}(gf) \subseteq \text{Domain}(f)\)： \(\text{Domain}(f) = [0, \infty)\)，\(\text{Domain}(gf) = [0, 9) \cup (9, \infty) \subset [0, \infty)\)。\(\checkmark\)

    5.5 绝对值函数 \(y = |f(x)|\) 的图像¶

    5.5.1 基本原理¶

    \(y = |f(x)|\) 的定义为：

    \[ |f(x)| = \begin{cases} f(x), & f(x) \geq 0 \\ -f(x), & f(x) < 0 \end{cases} \]

    图形变换规则：取 \(y = f(x)\) 的图形，将 \(x\) 轴下方的部分沿 \(x\) 轴向上反射（即取 \(y\) 坐标的绝对值），\(x\) 轴上方和轴上的部分保持不变。

    关键观察： - 反射后，图形的所有 \(y\) 值都非负（\(|f(x)| \geq 0\)）。 - 在 \(f(x) = 0\) 的点（即 \(x\) 截距处），绝对值图形会形成尖点（cusp）——这是因为左右两侧的斜率突然改变了符号。 - \(|f(x)|\) 的值域是 \([0, \infty)\)（如果原函数能取到任意大的正值）或 \([0, \text{有限最大值}]\)。

    5.5.2 各类函数的绝对值图形特征¶

    原函数类型 \(\vert f(x) \vert\) 的特征
    线性 \(\vert mx + c \vert\) V 形，尖点在 \(x = -c/m\)
    二次 \(\vert ax^2+bx+c \vert\) 在 \(x\) 截距处有尖点，抛物线在 \(x\) 轴下方的部分翻折到上方
    三次 \(\vert (x-p)(x-q)(x-r) \vert\) 在三个 \(x\) 截距处都有尖点
    三角 \(\vert a\sin bx + c \vert\) 周期减半（\(\sin\) 从 \(2\pi\) 变为 \(\pi\)），波谷翻为波峰
    三角 \(\vert a\cos bx + c \vert\) 周期减半（\(\cos\) 从 \(2\pi\) 变为 \(\pi\)），波谷翻为波峰
    三角 \(\vert a\tan bx + c \vert\) 垂直渐近线位置不变，图像翻折使 \(y \geq 0\)
    指数 \(\vert a^x \vert\) 与 \(a^x\) 相同（因为 \(a^x > 0\)）
    对数 \(\vert \log_a x \vert\) 在 \(x\) 截距处有尖点，\(x < 1\) 部分翻折到上方

    5.5.3 绝对值方程与不等式的解法¶

    方程 \(|f(x)| = k\)（\(k > 0\)）：等价于 \(f(x) = k\) 或 \(f(x) = -k\)。

    不等式 \(|f(x)| < k\)（\(k > 0\)）：等价于 \(-k < f(x) < k\)。

    不等式 \(|f(x)| > k\)（\(k > 0\)）：等价于 \(f(x) > k\) 或 \(f(x) < -k\)。

    例题 4.5（绝对值函数）¶

    例 1（线性函数的绝对值——V 形）：画出 \(y = |2x - 3|\) 的草图，并求 \(x\) 为何值时 \(y = 5\)。

    解：

    画图：

    \(f(x) = 2x - 3\)，\(f(x) = 0\) 时 \(x = 1.5\)。

    当 \(x \geq 1.5\) 时，\(2x - 3 \geq 0\)，所以 \(|2x-3| = 2x-3\)（直线，斜率 \(2\)）。 当 \(x < 1.5\) 时，\(2x - 3 < 0\)，所以 \(|2x-3| = -(2x-3) = -2x+3\)（直线，斜率 \(-2\)）。

    图形是 V 形，尖点在 \((1.5, 0)\)。

    解方程 \(|2x-3| = 5\)：

    情况 1：\(2x-3 = 5 \Rightarrow 2x = 8 \Rightarrow x = 4\) 情况 2：\(2x-3 = -5 \Rightarrow 2x = -2 \Rightarrow x = -1\)

    解为 \(x = 4\) 或 \(x = -1\)。

    例 2（二次函数的绝对值）：画出 \(y = |x^2 - 4x + 3|\) 的草图。

    解：

    第一步（画原函数）：\(y = x^2 - 4x + 3 = (x-1)(x-3)\)。

    • \(x\) 截距：\(x = 1\) 和 \(x = 3\)
    • 顶点：\(x = 2\)，\(y = 4 - 8 + 3 = -1\)，即 \((2, -1)\)
    • 开口向上（\(a = 1 > 0\)）

    第二步（取绝对值）：\([1, 3]\) 区间内原函数 \(f(x) \leq 0\)，这部分翻折到上方。 \(x < 1\) 和 \(x > 3\) 部分 \(f(x) > 0\)，保持不变。

    第三步（标出关键点）：尖点在 \(x = 1\) 和 \(x = 3\) 处。翻折后原顶点 \((2, -1)\) 变为 \((2, 1)\)。

    值域为 \([0, \infty)\)。

    例 3（三次函数的绝对值图像与符号分析）：已知 \(f(x) = (x+1)(x-1)(x-2)\)。

    （i）画出 \(y = |f(x)|\) 的草图； （ii）讨论 \(|f(x)|\) 与 \(y = 2\) 的交点情况。

    解：

    （i）符号分析：

    区间 测试点 \((x+1)\) \((x-1)\) \((x-2)\) \(f(x)\) 符号 \(\vert f(x)\vert\)
    \(x < -1\) \(x=-2\) 负 负 负 负 翻折到正
    \(-1 < x < 1\) \(x=0\) 正 负 负 正 保持不变
    \(1 < x < 2\) \(x=1.5\) 正 正 负 负 翻折到正
    \(x > 2\) \(x=3\) 正 正 正 正 保持不变

    \(x\) 截距：\(x = -1, 1, 2\)（均为尖点）。 \(y\) 截距：\(f(0) = (1)(-1)(-2) = 2\)。

    （ii）\(y = 2\) 与 \(|f(x)|\) 的交点： - 在 \((-1, 1)\) 区间上，\(f(0) = 2\)，有一个交点。 - 在 \(x < -1\) 翻折区域，\(|f(x)| = -f(x)\)，\(f(-2) = (-1)(-3)(-4) = -12\)，\(|f(-2)| = 12\)，\(f(-1) = 0\)。由连续性，\(y = 2\) 在此区间上相交一次。 - 在 \((1, 2)\) 翻折区域，同理相交一次。

    因此共有 3 个交点。

    例 4（\(|a\sin bx + c|\) 形式——考纲 1.4 指定）：画出 \(y = |\sin x|\) 在 \([0, 2\pi]\) 上的草图。

    解：

    先画 \(y = \sin x\)： - \([0, \pi]\) 上 \(\sin x \geq 0\)（\(x\) 轴及上方） - \([\pi, 2\pi]\) 上 \(\sin x \leq 0\)（\(x\) 轴下方）

    取绝对值： - \([0, \pi]\)：保持不变 - \([\pi, 2\pi]\)：向上反射（\(|\sin x| = -\sin x\)）

    图形特征： - 两个相同的"拱形"：\((0,0)\to(\frac{\pi}{2},1)\to(\pi,0)\) 和 \((\pi,0)\to(\frac{3\pi}{2},1)\to(2\pi,0)\) - 周期：\(\pi\)（原 \(\sin x\) 周期为 \(2\pi\)，反射后每 \(\pi\) 重复一次） - 值域：\([0, 1]\) - 尖点：\(x = 0, \pi, 2\pi\) 等处

    例 5（\(|a\cos bx + c|\) 形式——考纲 1.4 指定）：画出 \(y = |3\cos 2x - 1|\) 在 \([0, \pi]\) 上的草图。

    解：

    第一步（画原函数 \(y = 3\cos 2x - 1\)）： - 振幅为 \(3\)，周期为 \(\dfrac{2\pi}{2} = \pi\)，垂直下移 \(1\) 个单位 - 最大值：\(3(1) - 1 = 2\)，最小值：\(3(-1) - 1 = -4\) - 零点：\(3\cos 2x - 1 = 0 \Rightarrow \cos 2x = \dfrac13\) \(2x = \arccos\dfrac13\) 或 \(2x = 2\pi - \arccos\dfrac13\) 即 \(x = \dfrac12\arccos\dfrac13\) 或 \(x = \pi - \dfrac12\arccos\dfrac13\) 记 \(\alpha = \dfrac12\arccos\dfrac13 \approx 0.615\) 弧度

    第二步（取绝对值）： - 在两个零点之间的区间（\(\alpha < x < \pi - \alpha\)），\(3\cos 2x - 1 \leq 0\)，这部分翻折到上方 - 其余部分保持不变

    第三步（标出关键点）： - 尖点：\(x = \alpha\) 和 \(x = \pi - \alpha\) 处 - 翻折后的"波峰"：原最小值 \(x = \dfrac{\pi}{2}\) 处 \(3\cos\pi - 1 = -4\) 翻折为 \(4\) - 原最大值 \(x = 0\) 处 \(2\) 和 \(x = \pi\) 处 \(2\) 保持不变

    最终图形特征： - 值域：\([0, 4]\) - 尖点数量（一个周期内）：2 个 - 渐近线：无

    例 6（\(|a\tan bx + c|\) 形式——考纲 1.4 指定）：画出 \(y = |\tan x - 1|\) 在 \(\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)\) 上的草图。

    解：

    第一步（画原函数 \(y = \tan x - 1\)）： - \(\tan x\) 的周期为 \(\pi\)，垂直下移 \(1\) 个单位 - 垂直渐近线：\(x = -\dfrac{\pi}{2}\) 和 \(x = \dfrac{\pi}{2}\) - 零点：\(\tan x - 1 = 0 \Rightarrow \tan x = 1 \Rightarrow x = \dfrac{\pi}{4}\)（在区间 \((-\frac{\pi}{2}, \frac{\pi}{2})\) 内） - 当 \(x \to \dfrac{\pi}{2}^-\) 时，\(\tan x \to \infty\)，\(\tan x - 1 \to \infty\) - 当 \(x \to -\dfrac{\pi}{2}^+\) 时，\(\tan x \to -\infty\)，\(\tan x - 1 \to -\infty\)

    第二步（取绝对值）： - 当 \(x < \dfrac{\pi}{4}\) 时，\(\tan x - 1 < 0\)，翻折到上方 - 当 \(x > \dfrac{\pi}{4}\) 时，\(\tan x - 1 > 0\)，保持不变 - 当 \(x = \dfrac{\pi}{4}\) 时，\(\tan\dfrac{\pi}{4} - 1 = 0\)，为尖点

    第三步（分析翻折后的行为）： - 在 \(x < \dfrac{\pi}{4}\) 区域，\(|\tan x - 1| = -(\tan x - 1) = 1 - \tan x\) 当 \(x \to -\dfrac{\pi}{2}^+\) 时，\(\tan x \to -\infty\)，\(1 - \tan x \to \infty\) - 在 \(x > \dfrac{\pi}{4}\) 区域，\(|\tan x - 1| = \tan x - 1\) 当 \(x \to \dfrac{\pi}{2}^-\) 时，\(\tan x \to \infty\)，\(\tan x - 1 \to \infty\)

    最终图形特征： - 垂直渐近线仍然在 \(x = -\dfrac{\pi}{2}\) 和 \(x = \dfrac{\pi}{2}\) 处（绝对值不改变渐近线的位置） - 尖点在 \(x = \dfrac{\pi}{4}\) 处 - 图形在尖点两侧都趋向无穷大 - 值域：\([0, \infty)\)（最小值 \(0\) 在 \(x = \dfrac{\pi}{4}\) 处）

    例 7（绝对值方程——二次型）：解方程 \(|x^2 - 3x + 2| = 2\)。

    解：

    原二次式 \(x^2 - 3x + 2 = (x-1)(x-2)\)，根为 \(x = 1, 2\)。

    情况 1：\(x^2 - 3x + 2 = 2\)

    \[ x^2 - 3x = 0 \Rightarrow x(x-3) = 0 \Rightarrow x = 0 \text{ 或 } x = 3 \]

    检查：\(x = 0\) 时 \(0 - 0 + 2 = 2 > 0\)（在非负区域），有效。\(x = 3\) 时 \(9 - 9 + 2 = 2 > 0\)，有效。

    情况 2：\(x^2 - 3x + 2 = -2\)

    \[ x^2 - 3x + 4 = 0 \]

    判别式 \(\Delta = 9 - 16 = -7 < 0\)，无实数解。

    因此解为 \(x = 0\) 或 \(x = 3\)。

    例 8（绝对值不等式——两边平方技巧）：解 \(|x-1| > |2x+3|\)。

    解：

    两边都非负，可以平方，不等号方向不变：

    \[ (x-1)^2 > (2x+3)^2 \]

    展开：

    \[ x^2 - 2x + 1 > 4x^2 + 12x + 9 \]

    移项：

    \[ 0 > 3x^2 + 14x + 8 \Rightarrow 3x^2 + 14x + 8 < 0 \]

    求根：

    \[ x = \frac{-14 \pm \sqrt{196 - 96}}{6} = \frac{-14 \pm 10}{6} \]

    \(x = \dfrac{-14 + 10}{6} = -\dfrac{4}{6} = -\dfrac{2}{3}\)，\(x = \dfrac{-14 - 10}{6} = -\dfrac{24}{6} = -4\)。

    因为二次项系数 \(3 > 0\)，抛物线开口向上，不等式在两根之间成立：

    \[ -4 < x < -\frac{2}{3} \]

    例 9（绝对值函数的最值——几何意义法）：函数 \(f(x) = |x-1| + |x-3|\)，求 \(f(x)\) 的最小值。

    解：

    几何解释：\(|x-1|\) 是数轴上 \(x\) 到 \(1\) 的距离，\(|x-3|\) 是 \(x\) 到 \(3\) 的距离。\(f(x)\) 是这两个距离之和。

    当 \(x\) 在 \([1, 3]\) 之间时，两距离之和恒等于线段长度 \(2\)。 当 \(x < 1\) 或 \(x > 3\) 时，和大于 \(2\)。

    因此 \(f(x)\) 的最小值为 \(2\)，在 \(x \in [1, 3]\) 时取到。

    代数验证——分段讨论：

    \[ f(x) = \begin{cases} -(x-1) - (x-3) = -2x + 4, & x < 1 \\ (x-1) - (x-3) = 2, & 1 \leq x \leq 3 \\ (x-1) + (x-3) = 2x - 4, & x > 3 \end{cases} \]

    当 \(x < 1\) 时，\(f(x) = -2x + 4 > 2\)（因为 \(-2x > -2\)）。 当 \(1 \leq x \leq 3\) 时，\(f(x) = 2\)。 当 \(x > 3\) 时，\(f(x) = 2x - 4 > 2\)。

    最小值为 \(2\)。

    5.6 三次函数的因式分解、方程与图像¶

    5.6.1 分解三次多项式¶

    分解三次多项式 \(f(x) = ax^3 + bx^2 + cx + d\) 就像解一个"三层锁"：先找到一把钥匙（一个线性因式），打开第一层锁后露出一个二次锁，再用熟悉的二次分解方法打开它。

    标准流程：

    Step 1：试根——用因式定理找线性因式

    试 \(x = \pm 1, \pm 2, \pm 3, \dots\) 以及分数 \(\pm \frac{\text{常数项的因数}}{\text{首项系数的因数}}\)。找到 \(p\) 使得 \(f(p) = 0\)，则 \((x - p)\) 是一个因式。

    Step 2：综合除法——求二次商式

    将 \(f(x)\) 除以 \((x - p)\)，得到二次式 \(Ax^2 + Bx + C\)。

    Step 3：分解二次式

    用因式分解、求根公式或配方法分解 \(Ax^2 + Bx + C\)。

    Step 4：完整因式分解

    写出 \(f(x) = (x - p) \times (\text{二次因式的分解})\)。

    综合除法详解（补充）¶

    综合除法是一种简化的多项式除法方法，专门用于除以形如 \((x - p)\) 的线性因式。它通过一个表格来组织计算，避免了传统长除法中繁琐的多项式书写。

    综合除法的底层逻辑——它为什么有效？

    综合除法的核心思路其实是：把多项式按降幂写出系数，然后反复使用 \(x = p\) 代入时 \((x - p) = 0\) 这一事实来逐步消去各项。更具体地说：

    设 \(f(x) = a_3 x^3 + a_2 x^2 + a_1 x + a_0\)，除式为 \((x - p)\)，商式 \(q(x) = b_2 x^2 + b_1 x + b_0\)，余数 \(R\)。由带余除法恒等式：

    \[ a_3 x^3 + a_2 x^2 + a_1 x + a_0 = (x - p)(b_2 x^2 + b_1 x + b_0) + R \]

    展开右边：

    \[ \begin{aligned} (x - p)(b_2 x^2 + b_1 x + b_0) + R &= b_2 x^3 + b_1 x^2 + b_0 x - p b_2 x^2 - p b_1 x - p b_0 + R \\ &= b_2 x^3 + (b_1 - p b_2) x^2 + (b_0 - p b_1) x + (-p b_0 + R) \end{aligned} \]

    比较左右两边同次项的系数（恒等式两边 \(x\) 的各次幂系数必须一一相等）：

    \[ \begin{aligned} \text{比较 } x^3 \text{ 系数：}&\quad a_3 = b_2 &&\Longrightarrow\; \boxed{b_2 = a_3} \\[8pt] \text{比较 } x^2 \text{ 系数：}&\quad a_2 = b_1 - p b_2 &&\Longrightarrow\; \boxed{b_1 = a_2 + p b_2} \\[8pt] \text{比较 } x^1 \text{ 系数：}&\quad a_1 = b_0 - p b_1 &&\Longrightarrow\; \boxed{b_0 = a_1 + p b_1} \\[8pt] \text{比较常数项：}&\quad a_0 = -p b_0 + R &&\Longrightarrow\; \boxed{R = a_0 + p b_0} \end{aligned} \]

    这就是综合除法表格中每一步运算的来源：

    表格中的操作 对应的代数关系
    下拉首项系数 \(b_2 = a_3\)
    \(p \times b_2\) 写第二行，\(a_2\) 加上它 \(b_1 = a_2 + p b_2\)
    \(p \times b_1\) 写第二行，\(a_1\) 加上它 \(b_0 = a_1 + p b_1\)
    \(p \times b_0\) 写第二行，\(a_0\) 加上它 \(R = a_0 + p b_0\)（余数）

    规律：每一步都是「乘 \(p\) → 加下一系数」，反复执行直到常数项。

    步骤

    以 \(f(x) = a_3 x^3 + a_2 x^2 + a_1 x + a_0\) 除以 \((x - p)\) 为例。

    表格结构：

    p |  a₃   a₂   a₁   a₀        ← 第 1 行：被除式系数
  |      p·b₂ p·b₁ p·b₀       ← 第 2 行：中间运算结果
  ------------------------     ← 分割线
     b₂   b₁   b₀   R          ← 第 3 行：商式系数 + 余数

    口诀记忆：下拉 → 乘 → 加 → 再乘 → 再加 → … → 最后一格是余数。

    逐步规则：

    1. 下拉（Drop）：首项系数 \(a_3\) 原封不动抄到第三行首位，记为 \(b_2 = a_3\)。
    2. 循环操作（对第二列到最后一列依次执行）：
    3. 乘：将第三行刚算出的数（\(b_2\)）乘以左边的 \(p\)，结果写到第二行下一列。
    4. 加：第一行该列的数加上第二行刚写的数，结果写到第三行。
    5. 读取结果：
    6. 第三行前三个数 \(b_2, b_1, b_0\) 是商式的系数（从高次到低次）。
    7. 第三行最后一个数 \(R\) 是余数。如果 \(R = 0\)，说明 \((x-p)\) 整除 \(f(x)\)。

    公式汇总：

    操作 公式
    下拉 \(b_2 = a_3\)
    第一次乘加 \(b_1 = a_2 + p \cdot b_2\)
    第二次乘加 \(b_0 = a_1 + p \cdot b_1\)
    第三次乘加（余数） \(R = a_0 + p \cdot b_0\)

    商式为 \(b_2 x^2 + b_1 x + b_0\)，余数为 \(R\)。

    示例¶

    在进入正式例题之前，先用一个超简单的例子熟悉操作流程。

    例：\(f(x) = 2x^2 + 5x - 3\) 除以 \((x - 2)\)（虽然是二次式，但操作规则完全一样。）

    系数：\(2,\;5,\;-3\)。\(p = 2\)。

        2 |  2    5   -3
      |       4   18
      ----------------
         2    9   15

    逐步走一遍：

    • 写第一行：系数 \(2, 5, -3\)。
    • 左边写 \(p = 2\)。
    • 下拉：\(2\) 直接抄到第三行第一位。
    • 乘：\(2 \times 2 = 4\)，写到第二行第二列。
    • 加：\(5 + 4 = 9\)，写到第三行第二列。
    • 乘：\(9 \times 2 = 18\)，写到第二行第三列。
    • 加：\(-3 + 18 = 15\)，写到第三行第三列。

    结果：商式 \(2x + 9\)，余数 \(15\)。

    验证（用余数定理）：\(f(2) = 2(4) + 5(2) - 3 = 8 + 10 - 3 = 15\)。✓ 余数一致！

    常见易错点提醒

    易错点 正确做法
    ❌ 忘记缺项补 0 ✅ 如果多项式缺少某一幂次（如 \(x^3 + 0x^2 + 2x - 5\)），必须在该位置写 0 作为系数
    ❌ 把 \(p\) 的符号搞反 ✅ \((x - p)\) 对应的 \(p\) 就是 \(p\) 本身（不变号）。\((x + k)\) 对应的 \(p = -k\)
    ❌ 第二行的数写到错误的列 ✅ 每次都是"第三行刚算出的数 × p → 写入第二行的下一列"
    ❌ 把余数当商式系数 ✅ 第三行最后一个数是余数 \(R\)，前面的是商式系数

    例题 1：分解 \(f(x) = x^3 - 6x^2 + 11x - 6\)。

    详解：

    Step 1：试根。从最简单的 \(x = 1\) 开始试：

    \[ f(1) = 1 - 6 + 11 - 6 = 0 \]

    所以 \((x - 1)\) 是一个因式。

    Step 2：综合除法。

        1 |  1   -6   11   -6
      |      1   -5    6
      -------------------
         1   -5    6    0

    详细过程说明： - 将系数 \(1, -6, 11, -6\) 依次排开。 - 最左边的数字 \(1\) 来自 \((x - 1)\) 的根 \(x = 1\)。 - 下拉：首项系数 \(1\) 直接写到下面。 - 第 1 步：\(1 \times 1 = 1\)，写到第二行第二个位置。\(-6 + 1 = -5\) 写到下面。 - 第 2 步：\((-5) \times 1 = -5\)，写到第二行第三个位置。\(11 + (-5) = 6\) 写到下面。 - 第 3 步：\(6 \times 1 = 6\)，写到第二行第四个位置。\(-6 + 6 = 0\) 写到下面。

    下面第三行的数字 \(1, -5, 6, 0\) 的含义： - \(1, -5, 6\) 是商式的系数：\(1x^2 - 5x + 6\) - 最后的 \(0\) 是余数——为 0 说明整除，验证了 \((x - 1)\) 确实为因式。

    Step 3：分解二次式。

    \[ x^2 - 5x + 6 = (x - 2)(x - 3) \]

    找到两个数乘积为 \(6\)、和为 \(-5\)：\(-2\) 和 \(-3\)。

    Step 4：完整分解。

    \[ \boxed{f(x) = (x - 1)(x - 2)(x - 3)} \]

    例题 2：分解 \(f(x) = 2x^3 - 3x^2 - 11x + 6\)。

    详解：

    Step 1：试根。

    首项系数为 2，常数项为 6，可能的有理根为 \(\pm 1, \pm 2, \pm 3, \pm 6, \pm \frac{1}{2}, \pm \frac{3}{2}\)。

    试 \(x = 2\)：\(f(2) = 16 - 12 - 22 + 6 = -12 \neq 0\)。 试 \(x = -2\)：

    \[ f(-2) = -16 - 12 + 22 + 6 = 0 \]

    所以 \((x + 2)\) 是一个因式（注意 \(x = -2\) 对应 \(x + 2 = 0\)）。

    Step 2：综合除法。

        -2 |  2   -3   -11    6
       |     -4    14    -6
       --------------------
          2   -7     3    0

    过程说明： - 最左边是 \(-2\)（根的值）。 - 下拉 \(2\)。 - \(2 \times (-2) = -4\)，\(-3 + (-4) = -7\)。 - \((-7) \times (-2) = 14\)，\(-11 + 14 = 3\)。 - \(3 \times (-2) = -6\)，\(6 + (-6) = 0\)。

    商式为 \(2x^2 - 7x + 3\)。

    Step 3：分解二次式 \(2x^2 - 7x + 3\)。

    \(a \times c = 2 \times 3 = 6\)。找两个数乘积为 \(6\)、和为 \(-7\)：\((-1) \times (-6) = 6\)，\((-1) + (-6) = -7\)。

    拆分并分组：

    \[ \begin{aligned} 2x^2 - 7x + 3 &= 2x^2 - x - 6x + 3 \\ &= x(2x - 1) - 3(2x - 1) \\ &= (2x - 1)(x - 3) \end{aligned} \]

    Step 4：完整分解。

    \[ \boxed{f(x) = (x + 2)(2x - 1)(x - 3)} \]

    例题 3：分解 \(f(x) = 3x^3 + 6x^2 - 3x - 6\)。

    详解：

    Step 0 观察：所有系数都能被 3 整除，先提取公因式 3：

    \[ f(x) = 3(x^3 + 2x^2 - x - 2) \]

    令 \(g(x) = x^3 + 2x^2 - x - 2\)。

    Step 1：试根。试 \(x = 1\)：\(g(1) = 1 + 2 - 1 - 2 = 0\)。所以 \((x - 1)\) 是 \(g(x)\) 的因式。

    Step 2：综合除法。

        1 |  1    2   -1   -2
      |       1    3    2
      --------------------
         1    3    2    0

    商式为 \(x^2 + 3x + 2\)。

    Step 3：分解二次式。

    \[ x^2 + 3x + 2 = (x + 1)(x + 2) \]

    Step 4：完整分解。

    \[ \boxed{f(x) = 3(x - 1)(x + 1)(x + 2)} \]

    例题 4：分解 \(f(x) = 2x^3 - 9x^2 + 7x + 6\)。

    详解：

    Step 1：试根。

    试 \(x = 1\)：\(f(1) = 2 - 9 + 7 + 6 = 6 \neq 0\)。 试 \(x = -1\)：\(f(-1) = -2 - 9 - 7 + 6 = -12 \neq 0\)。 试 \(x = 2\)：\(f(2) = 16 - 36 + 14 + 6 = 0\)。✓

    所以 \((x - 2)\) 是一个因式。

    Step 2：综合除法。

        2 |  2   -9    7    6
      |       4  -10   -6
      --------------------
         2   -5   -3    0

    商式为 \(2x^2 - 5x - 3\)。

    Step 3：分解二次式 \(2x^2 - 5x - 3\)。

    \(a \times c = 2 \times (-3) = -6\)。找两个数乘积为 \(-6\)、和为 \(-5\)：\((-6) \times 1 = -6\)，\((-6) + 1 = -5\)。

    \[ 2x^2 - 6x + x - 3 = 2x(x - 3) + 1(x - 3) = (2x + 1)(x - 3) \]

    Step 4：完整分解。

    \[ \boxed{f(x) = (x - 2)(2x + 1)(x - 3)} \]

    5.6.2 解三次方程¶

    解三次方程 \(ax^3 + bx^2 + cx + d = 0\) 的流程就是将三次多项式分解因式，然后令每个因式等于零。因为如果几个因式的乘积为零，则至少其中一个因式为零。

    例题 1：解 \(x^3 - 4x^2 + x + 6 = 0\)。

    详解：

    试根：\(f(2) = 8 - 16 + 2 + 6 = 0\)，所以 \((x - 2)\) 是因式。

    综合除法：

        2 |  1   -4    1    6
      |       2   -4   -6
      --------------------
         1   -2   -3    0

    商式 \(x^2 - 2x - 3 = (x - 3)(x + 1)\)。

    所以 \((x - 2)(x - 3)(x + 1) = 0\)。

    解得：

    \[ \boxed{x = 2,\quad x = 3,\quad x = -1} \]

    例题 2：解 \(x^3 - 5x^2 + 8x - 4 = 0\)。

    详解：

    试 \(x = 1\)：\(f(1) = 1 - 5 + 8 - 4 = 0\)。

    综合除法：

        1 |  1   -5    8   -4
      |       1   -4    4
      --------------------
         1   -4    4    0

    商式 \(x^2 - 4x + 4 = (x - 2)^2\)。

    所以 \((x - 1)(x - 2)^2 = 0\)。

    解得：

    \[ \boxed{x = 1 \quad\text{或}\quad x = 2\ (\text{二重根})} \]

    例题 3：已知 \(x = 2\) 是 \(2x^3 - 3x^2 - 18x + k = 0\) 的一个根，求 \(k\) 并解此方程。

    详解：

    代入 \(x = 2\)：\(16 - 12 - 36 + k = -32 + k = 0 \Rightarrow k = 32\)。

    方程为 \(2x^3 - 3x^2 - 18x + 32 = 0\)。已知 \((x - 2)\) 是因式。

    综合除法：

        2 |  2   -3   -18   32
      |       4     2   -32
      ----------------------
         2    1   -16    0

    商式 \(2x^2 + x - 16\)。用求根公式：

    \[ x = \frac{-1 \pm \sqrt{1 + 128}}{4} = \frac{-1 \pm \sqrt{129}}{4} \]

    所以解为：

    \[ \boxed{x = 2,\quad x = \frac{-1 + \sqrt{129}}{4},\quad x = \frac{-1 - \sqrt{129}}{4}} \]

    5.6.3 三次多项式的图像与不等式¶

    5.6.3.1 三个线性因式乘积的图像¶

    \(f(x) = a(x - p)(x - q)(x - r)\) 的图像特征：

    （1）\(x\) 轴截距：\(x = p, q, r\)（三个零点）。

    （2）\(y\) 轴截距：\(f(0) = a(-p)(-q)(-r) = -a \cdot pqr\)。

    （3）端点行为——取决于最高次项 \(ax^3\)：

    当 \(|x|\) 很大时，最高次项 \(ax^3\) 起主导作用：

    \(a\) 的符号 \(x \to -\infty\) \(x \to +\infty\)
    \(a > 0\) \(f(x) \to -\infty\)（左下） \(f(x) \to +\infty\)（右上）
    \(a < 0\) \(f(x) \to +\infty\)（左上） \(f(x) \to -\infty\)（右下）

    （4）零点处的行为： - 单根（因式次数为 1）：图像穿过 \(x\) 轴。 - 二重根（因式次数为 2）：图像触及并反弹（相切于 \(x\) 轴）。

    画草图步骤： 1. 标出 \(x\) 轴截距 \(p, q, r\)。 2. 标出 \(y\) 轴截距。 3. 根据 \(a\) 的符号确定两端走向。 4. 用平滑的 S 形曲线连接各点，在单根处穿过，在二重根处反弹。

    零点和极值概念详解¶

    在三次函数图像中，有三个关键概念需要区分清楚：

    1. 零点（Zero Point / \(x\)-intercept / Root）

    零点就是图像与 \(x\) 轴的交点，即满足 \(f(x) = 0\) 的 \(x\) 值。对于 \(f(x) = a(x-p)(x-q)(x-r)\)，零点是 \(x = p, q, r\)。

    关键性质： - 每个单根处，图像穿过 \(x\) 轴（符号改变）。 - 每个重根处，图像触及 \(x\) 轴但不穿过（符号不变，相切反弹）。 - 三次函数至少有一个实根，最多三个实根。

    2. 局部极值（Local Maximum / Local Minimum）

    局部极值是图像在某一段范围内的"山峰"或"山谷"。

    对于三次多项式 \(f(x) = ax^3 + bx^2 + cx + d\)，其导数 \(f'(x) = 3ax^2 + 2bx + c\) 是二次函数。令 \(f'(x) = 0\) 可得两个临界点（如果 \(\Delta_{f'} > 0\)），分别是局部极大值和局部极小值的位置（求根公式中的两个值分别对应之）。

    \[ f'(x) = 0 \;\Longrightarrow\; x = \frac{-2b \pm \sqrt{4b^2 - 12ac}}{6a} \]

    但作为 IGCSE 级别的考试，通常只需在草图中定性标出局部极值的大致位置，而非精确计算。下表总结了三种基本情况：

    \(a\) 的符号 三个单根的情况 一个二重根的情况
    \(a > 0\) 从左到右：局部极大值 → 局部极小值 左边上升/下降后反弹→右边（无局部极值或只有一个）
    \(a < 0\) 从左到右：局部极小值 → 局部极大值 同上，方向相反

    a > 0 且有三个单根时：从左下上升 → 第一个零点（穿过）→ 继续上升到局部极大值 → 下降到第二个零点（穿过）→ 继续下降到局部极小值 → 上升到第三个零点（穿过）→ 向右上延伸。

    a < 0 且有三个单根时：从左上下降 → 第一个零点（穿过）→ 继续下降到局部极小值 → 上升到第二个零点（穿过）→ 继续上升到局部极大值 → 下降到第三个零点（穿过）→ 向右下延伸。

    3. 全局极值（Global Maximum / Global Minimum）

    全局极值是函数在整个定义域（\(\mathbb{R}\)）上的最大或最小值。

    • 三次函数没有全局最大值或全局最小值。
    • 因为当 \(x \to \pm\infty\) 时，\(f(x) \to \pm\infty\)（取决于 \(a\) 的符号），函数值总会趋于无穷大和无穷小。
    • 三次函数只有局部极值，没有全局极值。

    但注意：如果题目限制了定义域（例如 \(x \in [a, b]\)），则在该闭区间上函数一定有全局最大值和全局最小值，它们出现在临界点或区间端点处。

    对比总结表

    概念 定义 三次函数的情况
    零点 (Zero) \(f(x) = 0\) 的解 最多 3 个实根
    局部极大值 (Local Max) 在某邻域内函数的最大值 存在（左侧"山峰"）
    局部极小值 (Local Min) 在某邻域内函数的最小值 存在（右侧"山谷"）
    全局最大值 (Global Max) 整个定义域上的最大值 不存在（因为 \(x\to\pm\infty\) 时 \(f\to\pm\infty\)）
    全局最小值 (Global Min) 整个定义域上的最小值 不存在（因为 \(x\to\pm\infty\) 时 \(f\to\pm\infty\)）

    5.6.3.2 绝对值图像¶

    核心规则（必须牢记）：

    \[ y = |f(x)| \]
    • 保留 \(f(x) \geq 0\) 的部分（\(x\) 轴上方的部分不变）
    • 翻折 \(f(x) < 0\) 的部分（将 \(x\) 轴下方的部分沿 \(x\) 轴向上对称翻转）

    即：负数部分翻折到正半轴。

    因此在 \(y = |f(x)|\) 的图像中： 1. 图像永远在 \(x\) 轴上方（或轴上），不可能有负值。 2. 在 \(f(x) = 0\) 的零点处，绝对值图像会出现尖点（因为从正变负或从负变正时，斜率突然反转方向）。 3. 原函数在 \(x\) 轴上方的部分保持不变，下方的部分被"折叠"上来。

    例题 1：画出 \(y = |(x + 1)(x - 1)(x - 3)|\) 的草图。

    先分析 \(f(x) = (x + 1)(x - 1)(x - 3)\) 的符号：

    区间 \(x<-1\) \(-1<x<1\) \(1<x<3\) \(x>3\)
    \(f(x)\) \(-\) \(+\) \(-\) \(+\)

    将负的部分（\(x < -1\) 和 \(1 < x < 3\)）沿 \(x\) 轴向上翻折。

    最终图像在 \(x = -1, 1, 3\) 处与 \(x\) 轴相交（尖点），其余部分全部在 \(x\) 轴上方。

    例题 2：画出 \(y = |(x - 1)(x - 2)(x - 4)|\) 的草图。

    分析 \(f(x) = (x - 1)(x - 2)(x - 4)\) 的符号：

    \(f(0) = (-1)(-2)(-4) = -8\)，说明 \(x=0\) 时 \(f(x) < 0\)。

    区间 \(x<1\) \(1<x<2\) \(2<x<4\) \(x>4\)
    \(f(x)\) \(-\) \(+\) \(-\) \(+\)

    将负的区域（\(x<1\) 和 \(2<x<4\)）沿 \(x\) 轴向上翻折。尖点在 \(x=1,2,4\)。

    例题 3：求 \(|(x + 1)(x - 1)(x - 2)| = 2\) 的实根个数。

    符号分析：\(x<-1\)（\(-\)），\(-1<x<1\)（\(+\)），\(1<x<2\)（\(-\)），\(x>2\)（\(+\)）。

    做绝对值变换后，\(|f(0)| = |(1)(-1)(-2)| = 2\)，\((0,2)\) 是一个交点。

    水平线 \(y=2\) 与图像相交： - \(x<-1\)：1 个交点 - \(-1<x<1\)：2 个交点 - \(1<x<2\)：2 个交点 - \(x>2\)：1 个交点

    总共 5 个交点，即方程有 5 个实根。

    例题 4：画出 \(y = |(x + 2)(x - 1)^2|\) 的草图。

    \(f(x) = (x + 2)(x - 1)^2\)。

    符号：\(x<-2\)（\(-\)），\(-2<x<1\)（\(+\)），\(x>1\)（\(+\)）。

    将 \(x<-2\) 的部分沿 \(x\) 轴向上翻折。在 \(x=-2\) 处有尖点；在 \(x=1\) 处是平滑触及（二重根，原函数在此不改变符号，不需要翻折）。

    例题 5：画出 \(y = |(x+1)(x-2)(x-5)|\) 的草图。

    符号：\(x<-1\)（\(-\)），\(-1<x<2\)（\(+\)），\(2<x<5\)（\(-\)），\(x>5\)（\(+\)）。

    翻折 \(x<-1\) 和 \(2<x<5\) 部分。尖点在 \(x=-1,2,5\)。

    例题 6：求 \(|(x+2)(x-1)(x-4)|=3\) 的实根个数（估算）。

    图像在 \(x<-2\) 和 \(1<x<4\) 部分被翻折上来。水平线 \(y=3\) 与图像大约有 5 个交点，即约 5 个实根。

    5.6.3.3 三次不等式的图像解法（考纲 4.5）¶

    对于 \(f(x) \geq d\)（\(>\), \(\leq\), \(<\) 同理），其中 \(f(x) = a(x-p)(x-q)(x-r)\)：

    1. 画出 \(y = f(x)\) 的草图。
    2. 画水平线 \(y = d\)。
    3. 找出交点横坐标（解 \(f(x) = d\)）。
    4. 读取满足不等式的 \(x\) 区间。

    当 \(d = 0\) 时，水平线就是 \(x\) 轴，问题简化为分析 \(f(x)\) 的符号。

    例题 1：\(f(x) = (x+1)(x-1)(x-3)\)，解 \(f(x) \leq 0\)。

    符号表：

    区间 \(x<-1\) \(-1<x<1\) \(1<x<3\) \(x>3\)
    \(f(x)\) \(-\) \(+\) \(-\) \(+\)

    \(f(x) \leq 0\) 对应负或零的区间（含端点）：

    \[ \boxed{x \leq -1 \quad \text{或} \quad 1 \leq x \leq 3} \]

    例题 2：\(f(x) = -(x+1)(x-2)(x-5)\)，解 \(f(x) > 0\)。

    先考虑 \(g(x) = (x+1)(x-2)(x-5)\)，\(a_g = 1 > 0\)。

    \(g(x)\) 符号：\(x<-1\)（\(-\)），\(-1<x<2\)（\(+\)），\(2<x<5\)（\(-\)），\(x>5\)（\(+\)）。

    \(f(x) = -g(x)\)，符号与 \(g(x)\) 相反：

    区间 \(x<-1\) \(-1<x<2\) \(2<x<5\) \(x>5\)
    \(f(x)\) \(+\) \(-\) \(+\) \(-\)

    \(f(x) > 0\) 对应正区间（不含端点）：

    \[ \boxed{x < -1 \quad \text{或} \quad 2 < x < 5} \]

    例题 3：\(f(x) = (x+2)(x-1)(x-4)\)，解 \(f(x) \geq 8\)。

    展开：\(f(x) = x^3 - 3x^2 - 6x + 8\)。

    解 \(f(x) = 8\)：

    \[ x^3 - 3x^2 - 6x + 8 = 8 \Rightarrow x^3 - 3x^2 - 6x = 0 \Rightarrow x(x^2 - 3x - 6) = 0 \]

    \(x = 0\) 或 \(x = \frac{3 \pm \sqrt{33}}{2}\)。\(\frac{3 - \sqrt{33}}{2} \approx -1.372\)，\(\frac{3 + \sqrt{33}}{2} \approx 4.372\)。

    \(a = 1 > 0\)，左端向下，右端向上。\(f(x) \geq 8\) 的解集为：

    \[ \boxed{\frac{3 - \sqrt{33}}{2} \leq x \leq 0 \quad \text{或} \quad x \geq \frac{3 + \sqrt{33}}{2}} \]

    例题 4：\(f(x) = (x+1)(x-2)(x-4)\)，解 \(f(x) \leq 0\)。

    符号：\(x<-1\)（\(-\)），\(-1<x<2\)（\(+\)），\(2<x<4\)（\(-\)），\(x>4\)（\(+\)）。

    \(\leq 0\)：\(x \leq -1\) 或 \(2 \leq x \leq 4\)。

    例题 5：\(f(x) = -(x+2)(x-1)(x-5)\)，解 \(f(x) \geq 0\)。

    \(f(x) \geq 0 \iff -(x+2)(x-1)(x-5) \geq 0 \iff (x+2)(x-1)(x-5) \leq 0\)。

    符号：\(x<-2\)（\(-\)），\(-2<x<1\)（\(+\)），\(1<x<5\)（\(-\)），\(x>5\)（\(+\)）。

    \((x+2)(x-1)(x-5) \leq 0\)：\(x \leq -2\) 或 \(1 \leq x \leq 5\)。

    例题 6：解 \((x+1)(x-1)(x-3) \geq 4\)。

    \(f(x) = (x+1)(x-1)(x-3) = x^3 - 3x^2 - x + 3\)。

    \(f(x) = 4 \Rightarrow x^3 - 3x^2 - x - 1 = 0\)。此三次方程不易因式分解，在实际考试中通常会给出交点坐标或可通过计算器求解。

    综合练习题答案与详细解析¶

    一、定义域与值域¶

    1. 条件 1（根号）：\(x+3 \geq 0 \Rightarrow x \geq -3\)。 条件 2（分母不为零）：\(x-5 \neq 0 \Rightarrow x \neq 5\)。 取交集：\([-3, 5) \cup (5, \infty)\)。

    2. 配方法：

    \[ f(x) = (x^2 - 6x + 9) + 1 = (x-3)^2 + 1 \]

    因为 \((x-3)^2 \geq 0\)，所以 \(f(x) \geq 1\)。 最小值在 \(x = 3\) 处，\(f(3) = 1\)。 值域为 \([1, \infty)\)。

    3. 定义域：\(4 - x^2 > 0 \Rightarrow x^2 < 4 \Rightarrow -2 < x < 2\)，即 \((-2, 2)\)。

    值域：令 \(u = 4 - x^2\)，\(x \in (-2, 2)\)，则 \(u \in (0, 4]\)。 \(f(x) = \ln u\)，\(u \in (0, 4]\)。 \(\ln u\) 在 \((0, 4]\) 上递增，最小趋近于 \(-\infty\)（\(u \to 0^+\)），最大为 \(\ln 4\)（\(u = 4\)）。 值域为 \((-\infty, \ln 4]\)。

    4. 条件 1（分母根号内）：\(2x-1 > 0\)（严格大于，因在分母中）\(\Rightarrow x > \dfrac12\)。 条件 2（对数真数）：\(5 - x > 0 \Rightarrow x < 5\)。 取交集：\(\left(\dfrac12, 5\right)\)。

    5. 不是函数。例如 \(x = 0\) 时，\(y = \pm \sqrt{9 - 0} = \pm 3\)，一个 \(x\) 对应两个 \(y\) 值。垂直检验线 \(x = 0\) 与图形相交于 \((0, 3)\) 和 \((0, -3)\) 两点。

    6. 分离常数：

    \[ f(x) = \frac{3x-1}{x+2} = \frac{3(x+2) - 7}{x+2} = 3 - \frac{7}{x+2} \]

    因为 \(\dfrac{7}{x+2} \neq 0\)，所以 \(f(x) \neq 3\)。值域为 \(\mathbb{R} \setminus \{3\}\)。

    判断单射：设 \(f(a) = f(b)\)：

    \[ 3 - \frac{7}{a+2} = 3 - \frac{7}{b+2} \Rightarrow \frac{7}{a+2} = \frac{7}{b+2} \Rightarrow a+2 = b+2 \Rightarrow a = b \]

    因此 \(f\) 是单射。

    二、线性与三次函数¶

    7. 平行直线斜率相同，\(m = 3\)。 点斜式：\(y - (-1) = 3(x - 2) \Rightarrow y + 1 = 3x - 6 \Rightarrow y = 3x - 7\)。

    8. （i）\(f(1) = 1 - 2 - 5 + 6 = 0\)，所以 \(x-1\) 是因子。

    综合除法：

    \[ \begin{array}{c|ccc} 1 & 1 & -2 & -5 & 6 \\ & & 1 & -1 & -6 \\ \hline & 1 & -1 & -6 & 0 \end{array} \]

    商为 \(x^2 - x - 6 = (x-3)(x+2)\)。

    因此 \(f(x) = (x-1)(x-3)(x+2)\)。

    （ii）\(f(x) = 0\) 的解为 \(x = 1, 3, -2\)。

    9. 三个根：\(x = -1, 2, 4\)。最高次项系数 \(a = 1 > 0\)。

    符号分析：

    区间 \(x+1\) \(x-2\) \(x-4\) 乘积
    \(x < -1\) 负 负 负 负
    \(-1 < x < 2\) 正 负 负 正
    \(2 < x < 4\) 正 正 负 负
    \(x > 4\) 正 正 正 正

    \(f(x) > 0\) 的解为 \(-1 < x < 2\) 或 \(x > 4\)。

    10. 由因式定理，\(f(-2) = 0\)：

    \[ f(-2) = (-2)^3 + k(4) - 5(-2) - 6 = -8 + 4k + 10 - 6 = 4k - 4 = 0 \]

    \(k = 1\)。

    综合除法除以 \((x+2)\)：

    \[ \begin{array}{c|ccc} -2 & 1 & 1 & -5 & -6 \\ & & -2 & 2 & 6 \\ \hline & 1 & -1 & -3 & 0 \end{array} \]

    商为 \(x^2 - x - 3\)。

    因此 \(f(x) = (x+2)(x^2 - x - 3)\)。二次式不可进一步有理分解。

    三、指数与对数¶

    12.

    \[ \log_3 54 - \log_3 2 = \log_3 \frac{54}{2} = \log_3 27 = 3 \]
    \[ 3 + \log_3 \frac13 = \log_3 \left(27 \times \frac13\right) = \log_3 9 = 2 \]

    值为 \(2\)。

    13.

    \[ 2^{x+1} = 5 \Rightarrow \ln(2^{x+1}) = \ln 5 \Rightarrow (x+1)\ln 2 = \ln 5 \]
    \[ x+1 = \frac{\ln 5}{\ln 2} \Rightarrow x = \frac{\ln 5}{\ln 2} - 1 \]

    14.

    \[ \log_3[(x+2)(x-4)] = 2 \Rightarrow (x+2)(x-4) = 3^2 = 9 \]
    \[ x^2 - 2x - 8 = 9 \Rightarrow x^2 - 2x - 17 = 0 \]
    \[ x = \frac{2 \pm \sqrt{4 + 68}}{2} = \frac{2 \pm \sqrt{72}}{2} = \frac{2 \pm 6\sqrt{2}}{2} = 1 \pm 3\sqrt{2} \]

    检查定义域：\(x+2 > 0\) 且 \(x-4 > 0 \Rightarrow x > 4\)。

    \(1 + 3\sqrt{2} \approx 5.24 > 4\)，有效。 \(1 - 3\sqrt{2} \approx -3.24 < 4\)，舍去。

    因此 \(x = 1 + 3\sqrt{2}\)。

    15. 令 \(u = 3^x > 0\)，则 \(3^{2x} = (3^x)^2 = u^2\)。

    \[ u^2 - 10u + 9 = 0 \Rightarrow (u-1)(u-9) = 0 \Rightarrow u = 1 \text{ 或 } u = 9 \]

    \(3^x = 1 \Rightarrow x = 0\)。 \(3^x = 9 \Rightarrow x = 2\)。

    解为 \(x = 0\) 或 \(x = 2\)。

    16. 使用换底公式，全部换为自然对数：

    \[ \log_2 3 = \frac{\ln 3}{\ln 2}, \quad \log_3 4 = \frac{\ln 4}{\ln 3}, \quad \log_4 5 = \frac{\ln 5}{\ln 4}, \quad \log_5 2 = \frac{\ln 2}{\ln 5} \]

    乘积为：

    \[ \frac{\ln 3}{\ln 2} \cdot \frac{\ln 4}{\ln 3} \cdot \frac{\ln 5}{\ln 4} \cdot \frac{\ln 2}{\ln 5} = 1 \]

    值为 \(1\)（所有项抵消）。

    17. 水平渐近线：\(x \to -\infty\) 时 \(e^x \to 0\)，\(2e^x - 3 \to -3\)，渐近线为 \(y = -3\)。

    \(y\) 截距：\(f(0) = 2e^0 - 3 = 2 - 3 = -1\)，即 \((0, -1)\)。

    \(x\) 截距：\(2e^x - 3 = 0 \Rightarrow e^x = \dfrac32 \Rightarrow x = \ln\dfrac32\)，即 \(\left(\ln\dfrac32, 0\right)\)。

    18. \(3^x < 7 \Rightarrow \ln(3^x) < \ln 7 \Rightarrow x\ln 3 < \ln 7 \Rightarrow x < \dfrac{\ln 7}{\ln 3}\)。

    19. \(\log_a 21 = \log_a (3 \times 7) = \log_a 3 + \log_a 7 = p + q\)。

    \(\log_a \dfrac73 = \log_a 7 - \log_a 3 = q - p\)。

    20. 用换底公式将 \(\log_4 x\) 换为以 \(2\) 为底：

    \[ \log_4 x = \frac{\log_2 x}{\log_2 4} = \frac{\log_2 x}{2} \]

    设 \(u = \log_2 x\)，则原方程化为：

    \[ u + \frac{u}{2} = 3 \Rightarrow \frac{3u}{2} = 3 \Rightarrow u = 2 \]

    \(\log_2 x = 2 \Rightarrow x = 2^2 = 4\)。

    四、反函数与复合函数¶

    21. \(y = \dfrac{3x-2}{4} \Rightarrow 4y = 3x - 2 \Rightarrow 3x = 4y + 2 \Rightarrow x = \dfrac{4y+2}{3}\)。

    交换得 \(f^{-1}(x) = \dfrac{4x+2}{3}\)。

    22. 配方法：\(f(x) = (x+1)^2 - 1\)，\(x \geq -1\)。值域为 \([-1, \infty)\)。

    令 \(y = (x+1)^2 - 1 \Rightarrow y+1 = (x+1)^2 \Rightarrow x+1 = \sqrt{y+1}\)（因 \(x \geq -1\)，取正根）。

    \(x = \sqrt{y+1} - 1\)。

    交换得 \(f^{-1}(x) = \sqrt{x+1} - 1\)，定义域为 \([-1, \infty)\)。

    23. \(fg(x) = f(g(x)) = f\left(\dfrac1x\right) = 2\left(\dfrac1x\right) + 1 = \dfrac{2}{x} + 1\)，\(x \neq 0\)。

    \(gf(x) = g(f(x)) = g(2x+1) = \dfrac{1}{2x+1}\)。

    \(gf(x)\) 的定义域：\(2x+1 \neq 0 \Rightarrow x \neq -\dfrac12\)，即 \(\mathbb{R} \setminus \left\{-\dfrac12\right\}\)。

    24. \(y = e^{3x} \Rightarrow \ln y = 3x \Rightarrow x = \dfrac13\ln y\)。

    交换得 \(f^{-1}(x) = \dfrac13\ln x\)，定义域 \(x > 0\)。

    25. \(y = \ln(x+2) \Rightarrow e^y = x+2 \Rightarrow x = e^y - 2\)。

    交换得 \(f^{-1}(x) = e^x - 2\)。

    原函数值域为 \(\mathbb{R}\)，所以 \(f^{-1}\) 的定义域为 \(\mathbb{R}\)。

    验证：\(f(f^{-1}(x)) = \ln(e^x - 2 + 2) = \ln(e^x) = x\)。\(\checkmark\)

    26. \(f(x) = x^4\) 不是单射，因为存在不同的 \(x\) 值对应同一个 \(y\) 值。例如 \(f(2) = 16\) 且 \(f(-2) = 16\)，即 \(2 \neq -2\) 但 \(f(2) = f(-2)\)。水平检验线 \(y = 16\) 与 \(y = x^4\) 的图形相交于 \((2, 16)\) 和 \((-2, 16)\) 两点。因此 \(f\) 没有反函数。

    若将定义域限制为 \(x \geq 0\)，则反函数为 \(f^{-1}(x) = \sqrt[4]{x}\)。

    27. \(fg(x) = f(g(x)) = \sqrt{(x^2 - 4) + 1} = \sqrt{x^2 - 3}\)。

    定义域：\(f(x) = \sqrt{x+1}\) 的定义域为 \(x+1 \geq 0 \Rightarrow x \geq -1\)。

    所以 \(g(x) \geq -1 \Rightarrow x^2 - 4 \geq -1 \Rightarrow x^2 \geq 3 \Rightarrow |x| \geq \sqrt{3}\)。

    定义域为 \((-\infty, -\sqrt{3}] \cup [\sqrt{3}, \infty)\)。

    28. \(f(x) = x^2\)，\(x \geq 0\)，定义域 \([0, \infty)\)。 \(g(x) = 2x + 1\)，定义域 \(\mathbb{R}\)。

    \(gf(x) = g(f(x)) = 2x^2 + 1\)。

    \(gf\) 的定义域：\(x\) 必须在 \(f\) 的定义域内（\(x \geq 0\)），且 \(f(x)\) 必须在 \(g\) 的定义域内（\(\mathbb{R}\)，无限制）。

    因此 \(\text{Domain}(gf) = [0, \infty)\)。

    \(\text{Domain}(f) = [0, \infty)\)，所以 \(\text{Domain}(gf) \subseteq \text{Domain}(f)\) 成立（实际上两者相等）。\(\checkmark\)

    五、绝对值函数¶

    29. V 形，尖点在 \((2, 0)\)。 \(x \geq 2\) 时 \(y = x-2\)；\(x < 2\) 时 \(y = 2-x\)。

    解 \(|x-2| = 3\)： 情况 1：\(x-2 = 3 \Rightarrow x = 5\) 情况 2：\(x-2 = -3 \Rightarrow x = -1\)

    解为 \(x = 5\) 或 \(x = -1\)。

    30. \(|2x+1| < 5 \Rightarrow -5 < 2x+1 < 5\)。

    左边：\(-5 < 2x+1 \Rightarrow -6 < 2x \Rightarrow -3 < x\)。 右边：\(2x+1 < 5 \Rightarrow 2x < 4 \Rightarrow x < 2\)。

    取交集：\(-3 < x < 2\)。

    31. \(y = |\cos x|\) 在 \([0, 2\pi]\) 上： - \([0, \frac{\pi}{2}]\)：\(\cos x \geq 0\)，从 \((0,1)\) 下降到 \((\frac{\pi}{2}, 0)\) - \([\frac{\pi}{2}, \frac{3\pi}{2}]\)：\(\cos x \leq 0\)，翻折到上方：从 \((\frac{\pi}{2}, 0)\) 上升到 \((\pi, 1)\) 再下降到 \((\frac{3\pi}{2}, 0)\) - \([\frac{3\pi}{2}, 2\pi]\)：\(\cos x \geq 0\)，从 \((\frac{3\pi}{2}, 0)\) 上升到 \((2\pi, 1)\)

    周期为 \(\pi\)。尖点在 \(x = \dfrac{\pi}{2}, \dfrac{3\pi}{2}\) 等处。

    32. \(x^2 - 5x + 6 = (x-2)(x-3)\)。

    情况 1：\(x^2 - 5x + 6 = 2 \Rightarrow x^2 - 5x + 4 = 0 \Rightarrow (x-1)(x-4) = 0 \Rightarrow x = 1\) 或 \(x = 4\)。 检查：\(x=1\) 时 \(1-5+6=2>0\)，有效。\(x=4\) 时 \(16-20+6=2>0\)，有效。

    情况 2：\(x^2 - 5x + 6 = -2 \Rightarrow x^2 - 5x + 8 = 0\)。 \(\Delta = 25 - 32 = -7 < 0\)，无实数解。

    解为 \(x = 1\) 或 \(x = 4\)。

    33. \(|x+2| \geq 3 \Rightarrow x+2 \leq -3\) 或 \(x+2 \geq 3\)。

    \(x+2 \leq -3 \Rightarrow x \leq -5\)。 \(x+2 \geq 3 \Rightarrow x \geq 1\)。

    解为 \(x \leq -5\) 或 \(x \geq 1\)。

    34. 几何解释：\(|x-2|\) 是 \(x\) 到 \(2\) 的距离，\(|x+1| = |x-(-1)|\) 是 \(x\) 到 \(-1\) 的距离。\(f(x)\) 是这两段距离之和。

    数轴上点 \(-1\) 到 \(2\) 的距离为 \(3\)。当 \(x\) 在 \([-1, 2]\) 之间时，两距离之和恒等于 \(3\)。当 \(x < -1\) 或 \(x > 2\) 时，和大于 \(3\)。

    因此最小值为 \(3\)，在 \(x \in [-1, 2]\) 时取到。

    代数验证：

    \[ f(x) = \begin{cases} -(x-2) - (x+1) = -2x + 1, & x < -1 \\ -(x-2) + (x+1) = 3, & -1 \leq x \leq 2 \\ (x-2) + (x+1) = 2x - 1, & x > 2 \end{cases} \]

    当 \(x < -1\) 时，\(f(x) = -2x + 1 > 3\)。 当 \(-1 \leq x \leq 2\) 时，\(f(x) = 3\)。 当 \(x > 2\) 时，\(f(x) = 2x - 1 > 3\)。

    最小值为 \(3\)。

    六、三角函数绝对值¶

    35. \(y = 2\cos x + 1\) 在 \([0, 2\pi]\) 上： - 最大值：\(2(1) + 1 = 3\)（\(x = 0, 2\pi\)） - 最小值：\(2(-1) + 1 = -1\)（\(x = \pi\)） - 零点：\(2\cos x + 1 = 0 \Rightarrow \cos x = -\dfrac12 \Rightarrow x = \dfrac{2\pi}{3}, \dfrac{4\pi}{3}\)

    取绝对值后： - \([\frac{2\pi}{3}, \frac{4\pi}{3}]\) 区间内 \(2\cos x + 1 \leq 0\)，翻折到上方 - 其余部分保持不变 - 尖点：\(x = \dfrac{2\pi}{3}\) 和 \(x = \dfrac{4\pi}{3}\) - 翻折后最大值出现在 \(x = \pi\) 处，\(|2\cos\pi + 1| = |-2+1| = 1\) - 原最大值 \(x = 0\) 处 \(3\) 和 \(x = 2\pi\) 处 \(3\) 保持不变

    值域：\([0, 3]\)。

    36. \(y = |\tan x|\) 在 \((-\frac{\pi}{2}, \frac{\pi}{2})\) 上：

    • \((-\frac{\pi}{2}, 0)\)：\(\tan x < 0\)，绝对值后翻折到上方，\(|\tan x| = -\tan x\)
    • \((0, \frac{\pi}{2})\)：\(\tan x > 0\)，保持不变，\(|\tan x| = \tan x\)
    • \(x = 0\)：\(\tan 0 = 0\)，为尖点

    渐近线：\(x = -\dfrac{\pi}{2}\) 和 \(x = \dfrac{\pi}{2}\) 仍然是垂直渐近线（绝对值不改变渐近线位置）。

    图形特征： - 在 \(x = 0\) 处有尖点 - 在 \(x \to \pm\frac{\pi}{2}\) 时，\(|\tan x| \to \infty\) - 值域：\([0, \infty)\) - 图形关于 \(x = 0\) 对称（偶函数），因为 \(|\tan(-x)| = |-\tan x| = |\tan x|\)

    37. \(f(x) = |3\sin 2x - 2|\)，\(x \in [0, \pi]\)。

    先分析 \(y = 3\sin 2x - 2\)： - 振幅 \(3\)，周期 \(\pi\)，垂直下移 \(2\) - 最大值：\(3(1) - 2 = 1\)，最小值：\(3(-1) - 2 = -5\) - 零点：\(3\sin 2x - 2 = 0 \Rightarrow \sin 2x = \dfrac23\) \(2x = \arcsin\dfrac23\) 或 \(2x = \pi - \arcsin\dfrac23\) 记 \(\alpha = \dfrac12\arcsin\dfrac23 \approx 0.364\) 弧度 则 \(x = \alpha\) 或 \(x = \dfrac{\pi}{2} - \alpha\)

    在 \([0, \pi]\) 上，\(3\sin 2x - 2\) 在 \([\alpha, \frac{\pi}{2} - \alpha]\) 区间为负，翻折到上方。

    最大值：翻折后，原最小值 \(-5\)（\(x = \dfrac{3\pi}{4}\)）变为 \(5\)。所以 \(f(x)\) 的最大值为 \(5\)。 最小值：\(0\)（在零点 \(x = \alpha\) 和 \(x = \dfrac{\pi}{2} - \alpha\) 处）。

    因此 \(f(x)\) 在 \([0, \pi]\) 上的最大值为 \(5\)，最小值为 \(0\)。

    七、定义域限制与复合函数存在¶

    38. \(f(x) = \sqrt{x-2}\)，定义域 \([2, \infty)\)。 \(g(x) = \dfrac{1}{\sqrt{5-x}}\)，定义域 \(x < 5\)。

    \(gf(x) = g(f(x)) = \dfrac{1}{\sqrt{5 - \sqrt{x-2}}}\)。

    定义域条件： 1. \(f\) 的定义域：\(x \geq 2\) 2. \(f(x)\) 在 \(g\) 的定义域内： - \(5 - \sqrt{x-2} > 0\)（分母根号内为正） - \(\sqrt{x-2} < 5 \Rightarrow x-2 < 25 \Rightarrow x < 27\) - \(5 - \sqrt{x-2} \neq 0\) 已由 \(>0\) 保证

    取交集：\(2 \leq x < 27\)。

    验证 \(\text{Domain}(gf) \subseteq \text{Domain}(f)\)： \(\text{Domain}(f) = [2, \infty)\)，\(\text{Domain}(gf) = [2, 27) \subset [2, \infty)\)。\(\checkmark\)

    复习建议：函数是 IGCSE 0606 附加数学的基石——微分、积分、曲线草图、运动学都建立在函数概念之上。本章的重点是：

    1. 熟练掌握定义域和值域的计算（尤其是根号、分母、对数同时出现时）
    2. 深刻理解指数与对数的互逆关系（\(a^{\log_a x} = x\)，\(\log_a(a^x) = x\)）
    3. 掌握对数运算法则的灵活运用（特别是换底公式 \(\log_a M = \dfrac{\log_b M}{\log_b a}\)）
    4. 熟练求反函数和复合函数，注意定义域的变化
    5. 能够画出 \(|f(x)|\) 的变换图形（线性、二次、三次、三角 \(a\sin bx + c\)、\(a\cos bx + c\)、\(a\tan bx + c\)）
    6. 能用文字准确解释函数没有反函数的原因（考纲 1.5）
    7. 理解 \(\text{Domain}(gf) \subseteq \text{Domain}(f)\) 和 \(\text{Range}(gf) \subseteq \text{Range}(g)\)（考纲 1.2）
