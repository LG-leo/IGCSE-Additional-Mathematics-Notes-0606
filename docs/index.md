## 每章怎么用 / How to use each chapter

每一章都按同一个结构编写，方便对照复习：

1. **考纲对照（Syllabus mapping）** — 列出本章对应的考纲编号与英文原文，先确认「考什么」；
2. **定义与推导** — 公式不是凭空出现的，每一步都写出来；
3. **典型例题** — 按题型分类：识别 → 步骤 → 易错点；
4. **常见错误** — 直接对应考试丢分点，例如定义域、增根、弧度制、积分常数。

!!! tip "学习顺序建议"
    按章节顺序学（1 → 10）最稳；如果时间紧，优先 **第 3、5、7、8 章**（二次函数、函数、微分、积分），
    它们是 0606 的核心工具，也和其他章节综合出题最多。

## 常见问题 / FAQ

??? question "这套笔记真的免费吗？"
    是。永久免费、开源，没有付费墙、没有注册、没有邮箱收集。你可以直接在线阅读、下载 Markdown 源码，或自己 fork。

??? question "它和官方教材（Coursebook）有什么区别？"
    教材按「书的章节」组织，容易跳步、超纲或漏考点；这套笔记按 **考纲的 learning objectives** 组织，
    每一步推导都写全，并且标注了对应的考纲条目与常见易错点。教材可以当解释工具，但**考纲才是边界**。

??? question "公式显示不出来怎么办？"
    本站使用 MathJax 渲染公式，需要浏览器允许 JavaScript。若在 GitHub 网页或本地编辑器里看到原始 `$...$` 源码，
    那是正常的——请使用本站（Pages）在线阅读，或在 VS Code 中安装 Markdown 数学插件。

??? question "发现有错误 / 想补充内容？"
    欢迎在 [GitHub 仓库](https://github.com/LG-leo/IGCSE-Additional-Mathematics-Notes-0606/issues) 提 issue 或 PR。
    开源的意义就是可以一起修正。

??? question "可以转载 / 用于教学吗？"
