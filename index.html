    IGCSE Additional Mathematics (0606) Notes¶

    Free · Open source · Bilingual (中文 / English) · Aligned with the Cambridge 0606 syllabus

    这是一套面向 剑桥 IGCSE 附加数学（Cambridge IGCSE Additional Mathematics, 0606） 的完整笔记： 按考纲（syllabus）而不是教材目录重新组织，包含完整推导、逐步解答与常见易错点，永久免费、开源、无付费墙。

    This is a complete, free and open-source set of notes for Cambridge IGCSE Additional Mathematics (0606). It is reorganised around the official syllabus — not the coursebook — with full derivations, step-by-step worked solutions and the traps that cost marks in the exam.

    为什么会有这套笔记？ / Why these notes exist¶

    官方教材（Cambridge IGCSE™ Additional Mathematics Coursebook）存在三个问题：内容覆盖不全、章节顺序与考纲不一致、步骤跳跃。 很多第三方资料沿用旧考纲、复制教材，甚至把「基础覆盖」放在付费墙后面。

    这套笔记的定位：把 0606 的基础覆盖做成免费、完整、可验证的公共资源。

    项目 说明
    覆盖范围 0606 考纲全部 10 个章节（数列与二项式、向量、二次函数、方程与不等式、函数、三角、微分、积分、几何、综合应用）
    考纲版本 2028–2030（主）· 2025–2027（兼容）
    语言 中文 + English（逐章对应）
    许可 CC BY-NC-SA 4.0 — 可自由分享、非商业改编
    价格 免费，无需注册，无需邮箱
    源码 github.com/LG-leo/IGCSE-Additional-Mathematics-Notes-0606

    每章怎么用 / How to use each chapter¶

    每一章都按同一个结构编写，方便对照复习：

    1. 考纲对照（Syllabus mapping） — 列出本章对应的考纲编号与英文原文，先确认「考什么」；
    2. 定义与推导 — 公式不是凭空出现的，每一步都写出来；
    3. 典型例题 — 按题型分类：识别 → 步骤 → 易错点；
    4. 常见错误 — 直接对应考试丢分点，例如定义域、增根、弧度制、积分常数。

    学习顺序建议

    按章节顺序学（1 → 10）最稳；如果时间紧，优先 第 3、5、7、8 章（二次函数、函数、微分、积分）， 它们是 0606 的核心工具，也和其他章节综合出题最多。

    关于考纲 / About the syllabus¶

    • 本笔记以 Cambridge IGCSE Additional Mathematics (0606) 2028–2030 考纲为主线编写，同时兼容 2025–2027 版本。
    • 考纲原文 PDF 存放在仓库中： 2025–2027 syllabus · 2028–2030 syllabus
    • 真题与评分方案（past papers & mark schemes）请以 Cambridge International 官网 为准。
    • 记忆优先级：考纲（考什么）> mark scheme（怎么给分）> 真题（怎么问）> 教材/笔记（怎么理解）。

    常见问题 / FAQ¶

    这套笔记真的免费吗？

    是。永久免费、开源，没有付费墙、没有注册、没有邮箱收集。你可以直接在线阅读、下载 Markdown 源码，或自己 fork。

    它和官方教材（Coursebook）有什么区别？

    教材按「书的章节」组织，容易跳步、超纲或漏考点；这套笔记按 考纲的 learning objectives 组织， 每一步推导都写全，并且标注了对应的考纲条目与常见易错点。教材可以当解释工具，但考纲才是边界。

    公式显示不出来怎么办？

    本站使用 MathJax 渲染公式，需要浏览器允许 JavaScript。若在 GitHub 网页或本地编辑器里看到原始 $...$ 源码， 那是正常的——请使用本站（Pages）在线阅读，或在 VS Code 中安装 Markdown 数学插件。

    发现有错误 / 想补充内容？

    欢迎在 GitHub 仓库 提 issue 或 PR。 开源的意义就是可以一起修正。

    可以转载 / 用于教学吗？

    可以，遵循 CC BY-NC-SA 4.0：署名、非商业用途、相同方式共享。 商业使用（包括机构售卖资料）需要单独授权。
